### 1.5 状态色（标签）规范

原型中标签为“6px 圆点 + 文字 + 浅色底”。实际使用的 8 组配色（文字色 / 底色）：

| 语义 | 文字色 | 底色 | 原型中的典型状态 |
|------|--------|------|------------------|
| 进行中 / 已提交（蓝） | `#0071e3` | `rgba(0,113,227,.12)` | 进行中、审批中、已提交、待处理 |
| 完成 / 正常（绿） | `#1e8e3e` | `rgba(52,199,89,.12)` | 启用、已完成、已通过、已发布、成功、使用中 |
| 待办 / 警示（橙） | `#c46a00` | `rgba(255,149,0,.12)` | 待审核、待确认、待配置、中风险 |
| 失败 / 严重（红） | `#d70015` | `rgba(255,59,48,.12)` | 失败、已过期、已退回、高风险、超时、迟交 |
| 中性 / 终止（灰） | `#6d6d72` | `rgba(142,142,147,.12)` | 草稿、停用、已取消、已归档、已结束 |
| 信息（青） | `#0e7fb8` | `rgba(90,200,250,.12)` | 资料类型（文档/链接/视频）、学时达标 |
| 分类（紫） | `#8944ab` | `rgba(175,82,218,.12)` | 多选题、自测问卷等分类标签 |
| 等级（黄） | `#a07d00` | `rgba(255,204,0,.12)` | 黄级预警、中等级 |

**统一规则（我可裁定，落到字典 `color` 属性）**：
- 状态 → 语义组的映射写入字典（每个字典值带 `colorType`），StatusTag 只读字典，页面不得自配颜色；
- 原型中同一状态出现多种颜色的，按下表统一（问题详见 04 清单 C-05）：

| 状态 | 原型中出现的颜色 | 统一为 |
|------|------------------|--------|
| 已归还 | 蓝、青 | 灰（终态） |
| 冻结 | 蓝、橙 | 橙 |
| 闲置 | 蓝、灰 | 灰 |
| 停用 | 灰、橙 | 灰 |
| 草稿 | 灰、橙 | 灰 |
| 维修中 | 橙、灰 | 橙 |
| 「全部」Tab 计数徽标为红 | 红 | 去掉颜色语义（中性） |
| 资产状态「在用」 | 绿 | 文案改「使用中」（【裁定】BUG-022/075） |

- 预警等级统一三档：高（红）/ 中（橙）/ 低（黄）（【裁定】C056；原型 `alertRule.html` 的「黄/橙/红级」与【全局规范】§4 `AlertLevel` L1/L2/L3 的中文名需对齐，见 04 清单 B-10）。

### 1.6 文案与格式规范

| 项 | 规则 | 依据 |
|----|------|------|
| 页面不得出现 | 英文枚举码、接口路径、BR/ADR/模块代号、`platformType`/`CONNECTED` 之类英文 | 【裁定】B025；原型多处违例见 04 清单 C-04 |

| 金额 | 右对齐、¥ 前缀、千分位、两位小数；负数红色（`.neg`） | FIN 页面规格「通用 UI 约定」；`shared.css .neg` |
| 百分比 | 输入与显示均按百分数（5 表示 5%），存储小数 | 【裁定】BUG-070、BUG-045 |
| 编号列 | 等宽字体 `.mono` | `shared.css` |
| 时间 | `YYYY-MM-DD HH:mm`；统计「截至」时间显示到时分 | 【裁定】B090 |
| 脱敏 | 后端返回脱敏值，前端只做显示（不做“拿明文再遮盖”） | 【全局规范】§5.2 |
