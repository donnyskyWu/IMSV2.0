## 一、结论

原型的所有用户操作已可完整还原。原先以「仅弹一句 toast」占位的交互点全部替换为**真实的 UI 状态变更、数据变更或二级/三级抽屉**；历史上 3 个「点击无响应」的死按钮全部修复并纳入自动检测。

| 指标 | 补全前 | 补全后 |
|------|--------|--------|
| 纯 toast 占位按钮（点击后无界面变化） | 104 | **1**（且为合理的只读提示） |
| 死按钮（onclick 目标未定义） | 3 | **0** |
| 页面 Tab 键 | 49 | 50（全部有渲染分支） |
| 可打开的二级 / 三级抽屉 | 30 | **>70**（新增选择器、预览、详情、确认等） |
| 交互探针覆盖模块 | 仅 CONTENT | **全模块** |

## 二、新增交互基础设施

为使每次点击都产生真实反馈，先扩建了一层可复用的交互原语（全部复用既有 CSS 类，**零新增样式**，无视觉回归）：

| 设施 | 说明 |
|------|------|
| `kvDrawer(title, pairs, foot, w)` | 只读详情抽屉（键值栅格） |
| `formDrawer(title, fields, saveLabel, cb, opts)` | 编辑表单抽屉（含必填校验、banner、warn） |
| `listDrawer(title, heads, rows, foot, w)` | 只读子列表抽屉 |
| `pickDrawer(title, items, cb, {multi, search, banner, heads})` | 选择器抽屉（单选 / 多选 + 搜索），单选举 `pickOne`、多选举 `pickConfirm` |
| `timelineDrawer(title, events, foot, w)` | 时间线抽屉 |
| `uploadDrawer(title, scene, cb, opts)` | 真实文件选择 + 回显（替代假上传） |
| `openModal / closeModal` | 居中弹窗（复用 `cfwrap` 样式） |
| `simTask(msg, done, ms)` | 异步任务模拟（处理中 → 完成），用于探活 / 重同步 / 生成 / 发布 |
| `copyText(txt, ok)` / `downloadText(file, text, mime)` | 真实写剪贴板 / 真实文件下载（CSV / JSON / 清单） |
| `setTxt / showEl / toggleDisp` | 局部 DOM 定位更新（避免整页重绘丢失输入） |
| `PLAN_MATCH_POOL / PLAN_USER_POOL / WT_ACCOUNT_POOL` | 赛事池 / 人员池 / 账号池（供各选择器复用） |

### 交互探针的能力扩展

`_verify_interactive.mjs` 已从「仅覆盖 CONTENT」升级为**全模块矩阵**：

1. **Tab 矩阵**：从源码自动提取全部 `setTab(key,label)` 与 `state.tab.X='label'` 组合（当前 30 组），逐组设置并渲染所有相关页面，断言返回字符串且无异常；
2. **抽屉冒烟**：50 个二级 / 三级页抽屉与弹窗（跨系统权限 / 资产 / 协同 / 数据决策 / 内容 / AIR / 财务 / 采集）逐个调用，断言不抛异常；
3. **死按钮静态检测**：扫描全部 1,203 个 `onclick/onchange/oninput` 属性，比对函数定义表，未定义即报 FAIL（当前 0）。
