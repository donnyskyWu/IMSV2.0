## 3. 角色摘要与协作关系

```mermaid
flowchart TB
  subgraph 主管
    M[运营主管: 计划/SOP/矩阵/二级审/报表]
  end
  subgraph 执行
    O[运营: 账号/登记/执行/发布]
    E[编辑: 写稿/排版/AI]
  end
  subgraph 资产与财务
    A[账号管理员: 主数据]
    F[财务人员: 成本]
  end
  A --> O
  M --> O
  M --> E
  O --> E
  F --> M
```

| 问题 | 谁负责 |
|------|--------|
| 谁创建中长期多节点排期？ | 运营主管 · **计划管理** |
| 谁做日登记 confirm？ | IP 组长（常为运营/编辑兼任）· **工作任务管理** |
| 谁审内容？ | 一级 IP 组长、二级运营主管（**系统参数** 可配置） |
| 谁维护公司/实名人/手机？ | 账号管理员 |
| 谁录账号成本？ | 财务人员 |

**内容审核当前默认（Greenfield）**：一、二级均开启；一级角色 `ip_group_leader`（本组范围），二级 `ops_manager`。生产以 **系统参数 → 内容审核** 为准。
