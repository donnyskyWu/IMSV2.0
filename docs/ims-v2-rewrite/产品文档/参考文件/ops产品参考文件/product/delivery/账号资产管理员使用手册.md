> **详细步骤 SSOT**：[`../产品使用操作手册.md`](../产品使用操作手册.md) 第 7、11 章；PRD M4 [`../../product/PRD-M4-账号管理.md`](../../product/PRD-M4-账号管理.md)  

---

## 1. 你能做什么

维护 **公司 → 实名人 → 手机/手机卡 → 平台账号/个人账号 → IP 组** 关联链路，以及：

- 公司管理、实名人、手机、手机卡
- 平台账号 / 个人账号、三方关联统计
- 平台账号详情中的 **采集 Tab**（账号级绑定/探活，非全量 M10 调度）

---

## 2. 推荐建档顺序

```text
公司主体 → IP 组（大组/小组）→ 手机卡/手机 → 实名人
→ 各平台账号并关联 IP 组 → 微信-视频号-企微三方关联（如适用）
```

业务规则见 PRD BR-019~BR-023（IP 层级、容量管理、三方关联）。

## 4. 与采集的边界

- **配置管理** 可维护外部账号/关键词等台账（§15）。

- 日常账号级操作使用 **平台账号 · 采集 Tab**（§11）。
