## 1.1 冻结 V1 PRD 冲突句

**冲突根因**：`产品PRD/IMS第一期PRD-V1.md`（V1 分册，早于完整版）仍保留「已完成模块只增量/不重复建设」口径。该口径隐含「**仅增量消费、不承接整体功能**」，与下列已冻结基线冲突：

| 冲突基线 | 冲突点 |
|----------|--------|
| ADR-IMS-001 §1/§2 | 同库**共享读写**；主键 `system_users.id`；IMS 为业务数据唯一出口 |
| ADR-IMS-006 §1/§2 | **一次性交付、不得缩小**已列模块与功能点；OPS M0~M10 须在 IMS 内等价提供（IR-03） |
| 完整 PRD v2.6.34 §3.1/§3A | 16/18/07/08/06/17/19 均在 In Scope；停 OPS 后能力不可缺 |

> **结论**：V1 分册残留句**必须逐处订正**为「**表结构沿用（只加列） + 能力等价接管（共享读写） + 不缩小功能**」，而非「只做增量消费」。

### B. 交付要求（DoD）

1. **1:1 完备**：AUTH/SYS 域涉及的每张源表与 IMS 自建表**各占一行**，不得合并省略。
2. **加列可执行**：加列清单须可直接生成 `ALTER TABLE ... ADD COLUMN`（含可空/默认值，保证 OPS 仍运行时兼容）。
3. **改名有据**：任何改名须附 ADR/规范依据（如 ADR-IMS-002 §4「SYS 用 `ims_sys_*`」）。
4. **隔离无遗漏**：每行必须确认 `tenant_id` 存在且读取路径进 B9 中间件（ADR-IMS-007 §2）。
5. **冲突显式**：命名/口径冲突**不得静默择一**，须标 `冲突` 并列入 §三·待确认问题。
6. **不写 SQL 明细入库**：登记册只登记「表/列/路径/依据」，建表与 seed 脚本由架构/工程另出。

## 2.3 B9 统一权限中间件（横切 · 本轮首批必落）

> **决策口径**（用户 2026-10-05 拍板 · 《SYS-系统管理-页面规格》**§P2A**）：AUTH 定义「**谁有哪些权限**」（角色权限载体），中间件负责「**权限如何执行**」（数据范围落地）。**统一在一处执行，各业务模块禁止自实现。**

| # | 规则 | 可验收点 | 边界 & 说明 | SSOT |
|---|------|----------|-------------|------|
| B9-1 | **全业务表 `tenant_id` 行级隔离** | 所有 `ims_*` 及并入 OPS 业务表访问自动追加 `WHERE tenant_id = ctx.tenantId` | 业务代码**不得手写** `tenant_id` 条件、**不得绕过**；共享库只读表同样过滤（ADR-IMS-007 §2） | §P2A-1；ADR-IMS-007 |
| B9-2 | **BR-305 四级数据范围** | `ALL` / `DEPT` / `IP_GROUP` / `SELF`（=全部 / 本部门 / IP 组 / 仅本人，**「本部门」不含下级**），**取自用户所绑角色**；判定与 SQL 注入**仅中间件执行** | SYS-002 角色页仅**配置** `dataScope` 值，**不落执行逻辑**；入参非法/未配置 → **fail-closed** | §P2A-2；ADR-IMS-008；完整 PRD BR-305 |
| B9-3 | **BR-212 发布/分享双重过滤** | 含「发布态/分享链接」数据访问须满足 **创建者数据范围 ∩ 查看者数据范围**；任一不满足即不可见 | 对读路径统一施加交集谓词；含成本/利润数据发布须 **R4 审批**（BIS-R3） | §P2A-3；FR-BI-031 · BR-212 |
| B9-4 | **fail-closed** | 权限为空 / 数据范围未配置 / 角色 `PENDING_CONFIG` / 上下文缺失 → **一律视为无权**（**空权限 ≠ 放行**） | 中间件**默认拒绝**而非默认放行；对齐 ADR-IMS-008 **G1** 与 G3 | §P2A-4；ADR-IMS-008 G1/G3 |
| B9-5 | **跨租户返回 1504** | 目标 `tenant_id` ≠ 上下文 → 中间件统一拦截返回 **1504** | **不得泄露目标数据存在性**；并入 OPS 租户校验语义保留 | §P2A-5；错误码附录 §3 |
| B9-6 | **禁止各模块自行实现数据范围过滤** | AUTH/ASSET/ACCT/CERT/LIVE/CONTENT/… 页面与契约**不得**自写 `tenant_id`/`dataScope`；新增数据源由中间件**注册过滤规则** | 违者禁旁路；可 CI 扫描（与 B5 §7A 同法）校验 | §P2A-6 |

| 方向 | 内容 |
