### US-CORP-A01 登记公众号平台账号

- **角色**：资产管理员 R4  
- **业务目标**：维护 公众号 账号主数据供直播/采集/上报选择。  
- **前置条件**：CORP 菜单；强关联公司/实名人可选。  
- **主路径**：公司资产 → 账号管理 → **公众号** → 新建 → 填主字段 → 详情无采集 Tab（规格）。  
- **成功结果**：AccountSelect 可选；采集类平台 Cookie 仅详情采集 Tab。  
- **异常**：手输 companyId 1500；跨租户 1504。  
- **追溯**：P-M4-008；TC-IMS-CORP-A01-01-01（P0）

### US-COST-01 查看账号 ROI 与成本

- **角色**：财务 R3  
- **业务目标**：按账号查看营收与成本，与场次利润菜单分离（BR-302）。  
- **前置条件**：COST 规格；Football page-for-ops authorId。  
- **主路径**：**财务 → 账号财务**（`cost`）→ 选账号/周期 → 查看 ROI 表。  
- **成功结果**：金额 ¥ 两位；与 FIN 场次利润不混显。  
- **异常**：Football 订单 WebAPI 未映射 → 部分指标「—」。  
- **追溯**：COST-001～003；TC-IMS-COST-01-01（P0）

### US-FIN-01 场次成本核算

- **角色**：财务 R3  
- **业务目标**：核准单场成本项，为利润反查提供输入。  
- **前置条件**：FIN-001；场次 seed。  
- **主路径**：**场次财务 → 成本核算**（`finCost`）→ 选场次 → 录入/核准成本。  
- **成功结果**：核准态写入；与 LIVE 下播 GMV 口径标注。  
- **异常**：无核准权限只读。  
- **追溯**：FIN-001、FR-DC；TC-IMS-FIN-01-01（P0）

### US-FIN-02 利润反查链路

- **角色**：财务 R3  
- **业务目标**：从场次/利润视角反查成本与分成。  
- **前置条件**：DC-002 API grounding。  
- **主路径**：**利润反查** → 输入场次/条件 → 查询 → 查看构成与下钻。  
- **成功结果**：权限 ims:fin:profit-trace:query；脱敏矩阵生效。  
- **异常**：无核准场次空态。  
- **追溯**：DC-002；TC-IMS-FIN-02-01（P0）
