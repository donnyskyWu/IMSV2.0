### US-CONTENT-01 工作任务到审核通过闭环

- **角色**：策划 R10 → 执行 R10 → 审核 R8  
- **业务目标**：从工作任务下发到提审、审核通过，形成可发布内容。  
- **前置条件**：SOP/计划已配置；CONTENT-OPS 补充规格。  
- **主路径**：**工作任务登记** 创建并指派 → **我的任务** → **任务执行全页** 填玩法与附件 → **提审** → **内容审核** LayoutViewer 只读 → 通过/打回。  
- **成功结果**：任务已审；内容管理可见终稿；打回待办再现。  
- **异常**：审核回避禁用；无权限仅见指派任务。  
- **追溯**：CONTENT-100、FR-CONTENT；TC-IMS-CONTENT-01-01（P0）

### US-CONTENT-02 维护 SOP 模板

- **角色**：内容管理员 R2  
- **业务目标**：沉淀可复用的 SOP，供计划与任务引用。  
- **前置条件**：CONTENT SOP 菜单可见。  
- **主路径**：**内容生产 → SOP 管理** → 新建/编辑 SOP → 发布或停用。  
- **成功结果**：SOP 列表状态正确；计划页可引用已发布 SOP。  
- **异常**：未发布不可被计划引用；1501 校验。  
- **追溯**：CONTENT-100；TC-IMS-CONTENT-02-01（P0）

### US-CONTENT-03 制定内容计划

- **角色**：策划 R10  
- **业务目标**：按周期编排内容计划并关联 SOP/作者。  
- **前置条件**：存在已发布 SOP。  
- **主路径**：**计划管理** → 新建计划 → 填周期与条目 → 保存/提交。  
- **成功结果**：计划列表可见；可下发工作任务。  
- **异常**：跨租户作者 1504。  
- **追溯**：CONTENT-102；TC-IMS-CONTENT-03-01（P0）

### US-CONTENT-04 执行人处理我的任务

- **角色**：执行人 R10  
- **业务目标**：在「我的任务」列表定位指派任务并进入执行。  
- **前置条件**：存在待执行工作任务。  
- **主路径**：**内容生产 → 我的任务**（`contentTask`）→ 打开行 → **进入执行**。  
- **成功结果**：跳转任务执行全页；列表状态为执行中/待提审。  
- **异常**：无 execute 权限不可见执行入口。  
- **追溯**：CONTENT-103；TC-IMS-CONTENT-04-01（P0）

### US-CONTENT-08 任务执行全页填写并提审

- **角色**：执行人 R10  
- **业务目标**：在全页完成玩法区与附件填写并提交审核。  
- **前置条件**：从 my task 进入；CONTENT 执行页规格 ADR-IMS-003 §5。  
- **主路径**：**任务执行全页**（`contentTaskExecute`）→ 填玩法区 → **附件**（IMS 上传 API）→ **提审**。  
- **成功结果**：任务 status=待审；审核队列可见。  
- **异常**：未填必填项拦截；Football 写路径未联调时保存 IMS 草稿。  
- **追溯**：CONTENT-103、CONTENT-109；TC-IMS-CONTENT-08-01（P0）

### US-CONTENT-05 内容库维护终稿

- **角色**：内容运营 R10  
- **业务目标**：管理已审核通过的内容条目与版本。  
- **前置条件**：至少一条已审内容 seed。  
- **主路径**：**内容管理** → 筛选 → 打开详情 → 只读/有限编辑（规格允许字段）。  
- **成功结果**：列表分页；状态与审核结果一致。  
- **异常**：未审内容默认不在发布态列表。  
- **追溯**：CONTENT-104；TC-IMS-CONTENT-05-01（P0）

### US-CONTENT-06 公推模板库选用版式

- **角色**：策划 R10  
- **业务目标**：为任务选择公推版式模板，保证出片规范。

### US-CONTENT-07 审核员队列处理

- **角色**：审核 R8  
- **业务目标**：按队列完成内容审核，保证合规发布。  
- **前置条件**：待审任务存在。  
- **主路径**：**内容审核** → 打开任务 → LayoutViewer 只读 → 通过/打回并填意见。
