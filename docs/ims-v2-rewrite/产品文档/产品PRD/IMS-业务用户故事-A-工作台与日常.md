# IMS 业务用户故事 — A · 工作台与日常运营
> 分册 · 索引见《IMS-业务用户故事.md》

### US-HOME-01 运营看板总览

- **角色**：管理层 R1  
- **业务目标**：一屏掌握今日运营关键数与快捷入口，决定是否下钻模块。  
- **前置条件**：已登录且套餐含首页；HOME-001 seed。  
- **主路径**：侧栏 **工作台 → 运营看板**（`home`）→ 浏览 KPI 卡片与趋势区 → 点击卡片跳转对应 L3（如账号、直播、预警）。  
- **成功结果**：卡片数值与 seed 一致；跳转 `go()` 到达目标页且侧栏高亮正确。  
- **异常**：无套餐菜单时卡片隐藏或灰显；无权限模块卡片不可点。  
- **追溯**：HOME-001、AUTH-004；TC-IMS-HOME-01-01（P0）

### US-HOME-02 个人工作台待办与消息

- **角色**：任意运营用户 R5  
- **业务目标**：在一个入口处理今日待办与系统消息，不必逐模块找队列。  
- **前置条件**：钉钉 SSO 已绑手机（BR-308）；AUTH-004。  
- **主路径**：**个人工作台** → 待办中心/消息中心各前 10 条 → 点条目深链（日报待审、内容审核、上报审核等）→ 或 **查看更多** 进二级列表页。  
- **成功结果**：待办在业务页处理后回到工作台预览减少；消息已读态同步。  
- **异常**：无权限模块待办不展示；MEET 与 REPORT 审核分接口聚合，禁止混单接口。  
- **追溯**：AUTH-004、HOME-001；TC-IMS-HOME-02-01（P0）

### US-IPG-01 建立 IP 组并绑定成员与作者

- **角色**：运营总监 R4  
- **业务目标**：建立可授权、可统计的 IP 组，供内容/账号/人效共用。  
- **前置条件**：组织与用户已同步；IPG P1。  
- **主路径**：日常运营 → **IP 组** → 新建组 → 详情 **成员管理**、**关联作者**、**账号绑定** Tab → 查看统计卡。  
- **成功结果**：组启用；下游 AccountSelect / 数据范围可用（BR-305）。  
- **异常**：重复组名/非法层级 1501；跨租户 1504。  
- **追溯**：FR-M1-001～006、IPG-002；TC-IMS-IPG-01-01（P0）

### US-LIVE-01 登记直播场次并完成 Football 同步

- **角色**：直播运营 R5  
- **业务目标**：登记一场直播并同步 Football 直播间基本信息，完成风控与台账。  
- **前置条件**：公司资产账号/设备可选；LIVE-001～002。  
- **主路径**：**直播管理 → 直播场次** → 新建 → 详情 Drawer：**基本信息** → **直播数据** 触发 football-sync → **风控登记** → **下播与 GMV** 录入。  
- **成功结果**：列表 19 位场次 ID；直播数据 Tab 展示 sync 态；GMV 不在直播数据 HTTP 冒充。  
- **异常**：Football 未关联 → sync「未关联」；无 API 字段显示「—」。  
- **追溯**：LIVE-001～004；TC-IMS-LIVE-01-01（P0）

### US-MON-01 维护 IP 主题与行业监测维度

- **角色**：IP 运营 R5  
- **业务目标**：配置作品监测用的主题/行业标签，供 MON 与内部分析筛选。  
- **前置条件**：MON P1；M7 阈值只读 COLLECT。  
- **主路径**：日常运营 → **作品监测** → 维护主题/行业字典 → 保存。  
- **成功结果**：列表可筛；与内部分析/竞品阈值引用一致。  
- **异常**：无写权限 403；跨租户 1504。  
- **追溯**：MON-001、MON-002；TC-IMS-MON-01-01（P0）
