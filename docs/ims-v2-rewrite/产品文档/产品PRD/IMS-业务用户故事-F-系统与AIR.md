### US-AIR-04 维护知识库与知识分类

- **角色**：AI 资产管理员 R11  
- **业务目标**：维护知识库与「库内两级树」知识分类，把知识放到不同分类  
- **前置条件**：AIR 知识库 In Scope（v2.6.31）；`ims_kb` / `ims_kb_category` 就绪；**本期仅知识库文件管理**（v2.6.34 语义检索已移除）。  
- **主路径**：AI 资源中心 → 知识库 → 新增知识库（密级四选 + Provider 固定 LOCAL，IMS 服务端文件目录）→ 分类管理（新增/重命名/排序/删除）→ 点选库/分类节点联动条目过滤。  
- **成功结果**：知识库与分类树落库；分类路径用于 **模块内条目筛选**（本期）；语义检索（`knowledge.search`）已移除。  
- **异常**：删除含条目的分类须二次确认（条目改挂根）；分类同名 fail；超出两级深度 fail。  
- **追溯**：KNOW-001/005；FR-AIR-017；TC-IMS-AIR-04-01-01（P0）

### US-AIR-05 从系统资料转入知识库 / 手动上传资料

- **角色**：AI 资产管理员 R11 / 运营 R5  
- **业务目标**：把系统的 **培训资料 / 绩效考核模板 / 内容记录** 转入知识库，或手动上传资料入库  
- **前置条件**：AIR 知识库 In Scope；TRAIN/PERF/CONTENT 源模块可读（源 SSOT）；**本期仅文件管理，不含检索/向量化**。  
- **主路径**：知识库 → [从系统转入] 720px 抽屉向导（选来源 → 按条目勾选 → 目标库+分类+密级 → 提交）；或 [上传资料]（文件 / URL / 粘贴文本）→ 提交入库。  
- **成功结果**：转文档落 `source_type=TRAIN/PERF/CONTENT`（上传落 FILE/URL/TEXT）+ `source_ref` 溯源；文件正文存 IMS 服务端文件目录（落 `file_key/file_size/content_type`）；状态 `PENDING` 进入入库审批（KNOW-002），审批通过即 `PUBLISHED`。  
- **异常**：未勾选条目不可提交；重复转入以 clientToken 幂等去重（提示"已存在是否覆盖"）；密级低于目标库密级拦截（BR-027）。  
- **追溯**：KNOW-002/006；FR-AIR-018/019；TC-IMS-AIR-05-01-01（P0）

> **语义检索移除说明（v2.6.34）**：本期 AIR 知识库仅做**文件管理**（元数据/分类/审批/授权/转入/上传）。**KNOW-003 知识检索**与 **KB-001 RAGFlow 自建底座** **已移除（不做）**，`KnowledgeProvider` 抽象仅保留切换位、不挂接检索；MCP 工具固定为**四工具**（skills.list / skills.get / experts.list / experts.assemble），`knowledge.search` / `knowledge.get` 已移除。

### US-AUTH-02 岗位-角色供给规则与权限预览

- **角色**：平台管理员 R1  
- **业务目标**：维护「钉钉岗位 → 角色」供给规则；钉钉同步岗位无对应角色时自动建角色并到待办配置权限（ADR-IMS-008）  
- **前置条件**：AUTH 规格；SYS-002 角色（权限明细载体）。  
- **主路径**：权限管理 → 岗位-角色供给规则 → 新建/编辑规则（选钉钉岗位 + 授予角色）→ 保存新版本。  
- **成功结果**：岗位角色映射更新、版本 +1；保留 `PENDING_CONFIG`/自动建角色护栏；**角色权限在 SYS-002 维护**；非 R1 操作 403。  
- **异常**：钉钉岗位已绑启用规则 → 二次确认替换（POS-R1）；授予 `PENDING_CONFIG` 角色 → fail-closed 提示（1002）。  
- **追溯**：AUTH-003；FR-AUTH-019~022；TC-IMS-AUTH-02-01-01（P0）

### US-SYS-02 配置角色权限（角色 = 权限唯一载体）

- **角色**：平台管理员 R1  
- **业务目标**：维护角色 —— 菜单权限码 + 功能点 R/W/D + 数据范围 + 钉钉岗位绑定（ADR-IMS-008）  
- **前置条件**：SYS 规格；tenant 对齐 ADR-IMS-007。  
- **主路径**：系统管理 → 角色 → 编辑（菜单权限 / 功能点 R/W/D / 数据范围 / 钉钉岗位）→ 保存；可 [权限预览] / [一键从岗位生成角色]。  
- **成功结果**：角色权限变更生效；用户权限按**角色并集**判定；变更生效。  
- **异常**：钉钉自动建角色 `PENDING_CONFIG` 未配权限 → 用户无权限（fail-closed）；无 `ims:sys:role:*` → 403。  
- **追溯**：SYS-002；FR-AUTH-019；TC-IMS-SYS-02-01-01（P0）
