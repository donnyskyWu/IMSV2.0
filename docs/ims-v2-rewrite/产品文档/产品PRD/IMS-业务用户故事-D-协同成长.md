### US-MEET-01 预约并记录会议

- **角色**：主管 R4  
- **业务目标**：创建会议并关联参与人，与日报域分离。  
- **前置条件**：MEET 会议菜单。  
- **主路径**：协同 → **会议** → 新建会议 → 邀请参与人 → 保存纪要（规格字段）。  
- **成功结果**：会议列表可见；参与人收到待办（若配置）。  
- **异常**：跨租户用户 1504。  
- **追溯**：MEET-001；TC-IMS-MEET-01-01（P0）

### US-REPORT-01 填报并提交运营数据

- **角色**：填报人 R5  
- **业务目标**：填报并提交运营数据  
- **前置条件**：REPORT 三叶；author+account 必填。  
- **主路径**：数据上报 → 选模板 → AuthorSelect → AccountSelect → 填指标 → 提交

- **追溯**：FR-REPORT-011～014；TC-IMS-REPORT-01-01-01（P0）
