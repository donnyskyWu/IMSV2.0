# IMS 一体化管理系统 — 模块 20 AI 资源中台（AIR）PRD

> 版本 V1.2.3 · 编写日期 2026-09-19 · 状态：三层规格已补建（2026-09-28）
> 模块定位：组织级 AI 资产（技能/专家/知识）统一管理与按权限分发，通过 MCP 连接器接入任意外部工具
> 本期范围：知识库 = **文件管理期**（仅元数据/分类/审批/授权/转入/上传，底座为 IMS 服务端文件目录）；**知识检索（KNOW-003）与 RAGFlow 底座（KB-001）已移出范围（不做）**
> **v2.6.34（2026-10-05）**：AIR 知识库的**语义检索已整体移出范围（不做）**——KNOW-003 检索、KB-001 RAGFlow 底座、`knowledge_context`、错误码 5007/5008 全部**移除**（非延后）；范围锁定为**文件管理**，底座 `KbProvider=LOCAL`，MCP 固定四工具。

## 0. 决策记录（2026-09-19 评审定稿；2026-10-04 V1.2.3 修订 D1）

| # | 决策点 | 结论 |
|---|--------|------|
| D1 | 知识底座 | **本期（文件管理期）底座 = IMS 服务端文件目录（`KbProvider=LOCAL`）**：知识文档正文存 IMS 侧服务端文件目录，IMS 侧管元数据/分类/审批/授权/转入/上传，**不做向量化、不做检索**。**知识检索（KNOW-003）与 RAGFlow 自建底座（KB-001）已整体移除（不做）**，`KbProvider` 值域仅 `LOCAL`（RAGFLOW 已作废）。网关侧 **KnowledgeProvider 抽象保留**（KB-002，仅保留切换位、不挂接检索），MCP 工具契约固定四工具、对底座无感知。经评估 ima OpenAPI 为个人账号维度（无组织级治理），企业版需商务洽谈、价格与 SLA 不透明——不作为交付项；ima 仅作为员工个人辅助工具，不进系统交付边界 |

| D4 | R11 角色 | 独立角色（AI 资产管理员），不并入 R2，职责单一 |

## 1. 背景与目标

### 1.1 业务背景
- 公司 AI 能力资产（Skill 技能包、Expert 专家角色、Knowledge 知识文档）目前散落在个人环境，无法统一管理、无法按人分发、无法审计
- 同事在 Cursor / Claude Desktop / 自建 Agent 等外部工具中工作时，拿不到公司沉淀的技能与知识，各自重复配置
- 无统一密钥体系：外部接入无认证、无权限边界、无用量控制

### 1.2 产品目标（10 层）
1. 技能/专家/知识三类 AI 资产统一入库、版本化管理
2. 与钉钉组织架构打通：按部门/角色/人员三维授权，事件驱动同步
3. 人员 Key 一键生成/吊销，离职自动失效
4. MCP 连接器网关：单端点对外，按人鉴权，仅返回权限内资源
5. 外部工具（Cursor/Claude/WorkBuddy/自建 Agent）零改造接入
6. 调用全量审计留痕，用量可统计、可限额
7. 机密级知识不出库，防外泄
8. 技能上架前强制安全审核
9. 复用 IMS 01 权限管理主数据，禁止重复建设组织模型
10. 为 15 内容生产（ComfyUI 自动化）与 12 数据中心提供 AI 资产底座

### 1.3 用户角色
| 角色 | 编号 | 说明 |
|------|------|------|
| 系统管理员 | R1 | 模块全局配置、系统参数（含 Key 白名单开关）、网关运维 |
| AI 资产管理员 | R11（新增，独立角色） | 技能/专家/知识的入库、审核、分发；不承担行政职责 |
| 部门主管 | R4/R5 | 本部门授权审批 |
| 普通员工 | R8 | 领取 Key、在外部工具中使用 |
| 安全审计员 | R9 | 调用审计、Key 异常监控 |

## 3. 业务规则（BR-019~BR-035）

| 编号 | 规则 |
|------|------|
| BR-019 | 一人默认一把 Key；设备维度最多 3 把；每把 Key 绑定唯一人员 |
| BR-020 | Key 生成后仅一次明文展示（服务端只存哈希）；丢失只能换新 |
| BR-021 | Key 认证为动态鉴权：每次调用实时校验人员在职状态与资源授权（缓存 60s），不使用权限快照 |
| BR-022 | Key 90 天未使用自动冻结，冻结前 7 天消息中心提醒 |
| BR-023 | 钉钉离职事件触发 Key 立即吊销（与 BR-015 离职归还同批事件处理） |
| BR-024 | 权限变更（调岗/角色变更）事件驱动同步至连接器，生效延迟 < 5 分钟 |
| BR-025 | 技能须通过安全审核方可分发；P0 风险技能永久拒绝并记录 |
| BR-026 | 技能安装到可分发全流程 < 10 分钟（含审核自动项） |
| BR-027 | 机密/绝密级知识不通过连接器返回全文，仅返回标题 + 100 字摘要 + 库内链接 |
| BR-028 | 连接器每次调用全量审计留痕（人员/Key/工具/参数摘要/结果），日志保留 180 天 |
| BR-029 | 默认 QPM 限额 60 次/分钟/人，超限返回 429 并告警；限额可按人调整 |
| BR-030 | `experts.assemble` 组装包内的知识片段同样走密级过滤（专家引用了机密知识库时，片段自动降级为摘要）。**本期（文件管理期）无检索，不返回 `knowledge_context` 字段**；该规则已随检索功能移除而不再生效 |
| BR-031 | 组织/授权数据一律以 01 权限管理（钉钉同步源）为准，本模块禁止独立维护人员主数据 |
| BR-032 | 多主体预留：技能/知识/授权/Key 表均含 tenant_id/entity_id 字段（BR-016 口径） |
| BR-033 | Key 认证失败连续 10 次（10 分钟内）自动冻结该 Key 并通知本人与安全审计员 |
| BR-034 | 网关不执行 LLM 与 Skill：experts.assemble 只做 Prompt 组装下发，执行一律在客户端完成 |
| BR-035 | Key IP/设备白名单受系统参数 `air.key.ip_whitelist.enabled` 总开关控制（默认关闭）；开启后白名单外调用返回 403 并告警 |

## 4. 核心流程

### 4.1 管理员分发流程
```
技能安装/专家创建/知识入库 → 安全审核（技能强制）→ 三维授权（部门/角色/人员）
→ 钉钉事件驱动同步 → 人员在 IMS 领取 Key → 复制 MCP 配置到外部工具
→ 外部工具调用 → 网关鉴权（动态）→ 返回权限内资源 → 审计留痕
```

### 4.2 Key 生成流程（页面级）
组织人员详情 → 「生成 AI 连接 Key」→ 选择设备用途（默认「个人通用」）→ 二次确认（风险提示）→ 弹窗一次性展示 Key + 各客户端配置卡片 → 关闭后仅可见掩码（`air-****…****9f2c`）

### 4.3 连接器调用流程（D2：组装下发）
外部工具发起 MCP 请求（Header `Authorization: Bearer air-xxx`）→ 网关验签（查 Key 哈希；白名单开启时校验 IP/指纹）→ 查人员状态（离职即 403）→ 查资源授权（缓存 60s）→ 执行工具 → 密级过滤输出 → 写审计日志 → 返回。
专家调用时：`experts.assemble` 在服务端完成「系统提示词 + 绑定技能清单」的组装，**组装包下发后由客户端 LLM 执行**，网关不运行任何模型。**本期（文件管理期）无检索，不返回 `knowledge_context` 字段**；语义检索（KNOW-003）已移除，不再填充「知识检索片段」。

### 4.4 知识入库流程（IMS 服务端文件目录底座）
员工上传文件/URL/**粘贴文本** → KNOW-002 入库审批 → 审批通过 → **正文写入 IMS 服务端文件目录（生成 `file_key`）** → ims_kb_doc 元数据落库（content_hash/**file_key/file_size/content_type**/密级/**分类 category_id**）→ 授权后**可在模块内浏览/下载/管理**。存量知识（历史文档/共享盘资料）通过 16 数据采集通道批量导入；**系统内资料（培训资料/绩效考核模板/内容记录）经 KNOW-006「从系统转入」按条目勾选转入**（落 `source_type` + `source_ref` 溯源）。**本期不做解析与向量化**（无 `PARSING` 态），检索能力已移除。

> 与 V1.2.2（RAGFlow 底座）的差异：原流程在「审批通过」后有「RAGFlow 建档 + 文档解析 + 向量化（bge-m3）→ 可被 knowledge.search 检索」两步；本期文件管理期**删除这两步**，审批通过即 `PUBLISHED`。

### 4.5 知识分类与转入流程（v2.6.31）
- **分类管理（KNOW-005）**：知识库页左树选中库 → 分类管理抽屉维护「库内两级树」（新增/重命名/排序/删除）；知识条目可归入某分类，删除含条目的分类须二次确认或改挂根。
- **系统资料转入（KNOW-006）**：知识库页 → 「从系统转入」→ 720px 抽屉向导：① 选来源模块（培训资料 TRAIN-001 / 绩效考核模板 PERF / 内容记录 CONTENT）→ ② 按条目勾选（关键词/分类筛选 + 全选当页）→ ③ 选目标知识库 + 目标分类 + 密级 → ④ 提交入库审批；转文档 `source_type` 记 `TRAIN`/`PERF`/`CONTENT`。**转入不复制正文外的敏感属性**，密级以操作人选择为准（默认取源资料密级）。

## 8. 边界与依赖

- **依赖**：01 权限管理（人员/角色/钉钉事件、系统参数中心）、13 预警中心（限额/异常告警）、16 数据采集（存量知识批量导入通道）、消息中心（Key 提醒）、**IMS 服务端文件目录（知识文档正文，本期文件管理底座）**
- **不做**：技能/模型服务端执行（D2 明确排除）；外部技能市场对接（P2 再议）；计费（仅统计）；**ima 集成（不作为交付项，员工个人自行使用不影响系统边界）**；**本期不做知识检索与向量化（KNOW-003 / KB-001 已移除）**
- **已知风险**：① Cursor 等客户端对自定义 Header 支持差异 → URL key 兼容方案；② Key 泄漏 → 限额 + 审计 + 异常告警兜底；③ **检索功能已整体移出（原「检索期底座选型尚未锁定」风险消除）**；④ 服务端文件目录容量增长 → 接入 13 预警中心容量监控 + 文件目录生命周期策略
