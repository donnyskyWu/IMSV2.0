# IMS 一体化管理系统 — 查询工具（QT）PRD 摘要

> 版本 0.3 · 2026-10-04 · 走查 **#18** + 模板闭环 + **IA 改造（管理优先：列表 + 抽屉向导）**

## 定位

**数据分析** 下新增 L3 **「查询工具」**：同一套 **QueryResult 壳** + **QueryPlan 编排**，支持 **分级下钻（DRILL）** 与 **穿透（TRACE）**；**不替代** 自定义查询 / 预览与下钻 / 穿透查询 三个既有 L3。

## P0 范围

| 项 | 内容 |
|----|------|
| 路由 | `/ims/analysis/query-tool`（**列表为默认落地**）；执行页 `/ims/analysis/query-tool/run/{templateCode}` |
| 页面形态 | **管理优先**：默认 = 查询模板列表；新增/编辑 = **720px 抽屉 6 步向导**（选类型→基本信息→配置载荷→展示与来源→预览试跑→完成）；执行 = 执行视图 |
| 可见类型 | DRILL + TRACE（**FLAT 不在选类型**，避免 M6 重叠） |
| 元数据 | 只读 COLLECT P4m 已映射实体 |
| TRACE 执行 | **单次 run**；服务端逐步 DC trace（前端不轮询） |
| DRILL | **`POST …/query-tool/run`** 同步多层（无 1262 job） |
| 模板管理 | 列表 `templates[]`（类型/状态/更新时间/菜单路径）+ 行操作 执行/编辑/发布/取消发布/发布到侧栏/删除；**已发布模板编辑 = 直接改**（PUT 覆盖，不另存草稿） |

## BLOCKED（实现前）

- FLAT 与 M6 单入口合并（P1 评估）  
- run 超时的产品降级（**禁止** QT 1262；仅 1181/同步超时提示）
