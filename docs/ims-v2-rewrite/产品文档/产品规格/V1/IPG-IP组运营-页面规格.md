## P1 IP 组管理 — 布局（对齐 UX-M1 §3.1）

| 区块 | 组件 | 说明 |
|------|------|------|
| 页头 | 标题「IP 组运营」+ 次要「导出」（可选） | IMS 模块页头；**主按钮「+ 新建大组」在左侧树标题栏**（与现网截图一致） |
| 左栏 | 「IP 组结构」+ 搜索「搜索组名」+ 可展开树 | 大组 → 小组；节点文案：`组名 (成员数/账号数/作者数)`；有等级时后缀 `[S/A/B/C级]` |
| 右栏（选中节点） | 详情头 + Tab | 未选中：空态「请从左侧选择 IP 组」 |
| 详情头 | 类型 Tag（大组/小组）、组名、元信息「组长 \| 上级 \| 创建于」、操作「编辑 / 停用 / 删除」 | 无新建权限时隐藏/置灰操作 |
| 详情 Tab | **基本信息 \| 成员管理 \| 关联作者 \| 统计** | 与现网默认 Tab 文案一致；**账号绑定**在 OPS UX 为独立 Tab「账号」，IMS 切片实现须补全（见 §差异） |

### 详情 Tab 内容

| Tab | 内容 | FR |
|-----|------|-----|
| 基本信息 | 双列信息栅格：组名、组类型、上级组、组长、等级、状态、排序、备注、创建时间、更新时间 | FR-M1-001 |
| 成员管理 | 成员表（姓名、岗位 `dict_position`、主/兼、是否组长）+「+ 添加成员」抽屉（UserSelect + 岗位） | FR-M1-001 / IPG-002 |
| 关联作者 | 作者表（作者名、类型、主推号、绑定用户）+「+ 添加作者」抽屉（**作者下拉**，非 UserSelect） | FR-M1-001 / ADR-051 |
| 统计 | 粉丝/作品/账号/内部内容/ROI 等聚合卡片；大组为子组求和（BR-M1-004） | FR-M1-001、`GET .../stats` |

**规则**：大组不直接绑定账号（错误码 1203）；小组方可绑账号、关联作者。

### 弹窗 / 抽屉

| ID | 触发 | 字段（与 D-M1-001 一致） |
|----|------|---------------------------|
| 新建/编辑大组或小组 | 新建大组、选中大组时「+ 新建小组」、编辑 | 组名、组类型、上级（小组必填 TreeSelect 仅 BIG）、组长 UserSelect、等级 DictSelect、描述/备注 |
| 添加成员 | 成员 Tab | 用户、岗位、主/兼 |
| 添加关联作者 | 关联作者 Tab | 作者（已建作者列表）、作者类型 |

### 状态与校验

- 空树：左栏空态 +「新建大组」
- 删除：存在成员/账号/关联作者时禁止（AC-M1-001-3）
- 同父级组名唯一（1002）
- 数据范围：全部 / 部门 / 本组（`accessible-tree` + 列表过滤，见 OPS RBAC 文档）

## 与 OPS UX 的差异（IMS 原型/实现须跟踪）

| 项 | OPS UX 文档 | 现网截图 / IMS P1 |
|----|-------------|-------------------|
| 详情 Tab「账号」 | UX §3.1 含「账号」Tab | 截图主路径为 4 Tab；**账号绑定能力仍属 FR-M1-001**，实现时在 P1 增加「账号绑定」Tab 或等价入口，不得省略 API |
| 作者独立页 | P-M1-002 列表页 | IMS 菜单保留；组内「关联作者」Tab 与 OPS 一致 |
| 分析页 | 独立菜单 4 页 | IMS 路由见上表；不在 P1 树页内嵌 |
