## 1. 通用规则

- **0**：成功。
- **1001~1999**：业务错误，按业务域分段（见 §2）。
- **401 / 403**：沿用 HTTP 语义（未认证 / 无权限）。
- **5001~5999**：系统错误（见 §4）。
- **响应包裹**：`{ code, msg, data }`。
- **裁决顺序**：PRD > 共享技术规范 > 全局开发规范 > 页面规格。

## 3. 1500~1504 权威语义

| 错误码 | 含义 |
|--------|------|
| 1500 | 关联的实体不存在 |
| 1501 | 关联的实体已停用/注销 |
| 1502 | 关联的实体已被其他记录引用 |
| 1503 | 字典值不合法 |
| 1504 | 跨租户访问禁止 |

**使用注意（2026-10-03 裁决）**：**1500~1504 为跨域通用「关联 / 字典 / 租户」类错误码**，各域通用，可与 §2 专段并存。并入域（M2 内容/任务门禁等）在 OPS 现网中把 **1500** 用作通用业务校验失败（如「请填写工作说明」）；依据 BR-307「并入模块保持 1500～1504 语义，前端提示不倒退」，**并入域保留该现网用法**。IMS 自建域（直播/培训/上报/查询工具等）一律按权威语义使用：**1500 不存在 / 1501 已停用 / 1502 已被引用 / 1503 字典非法 / 1504 跨租户**；域内业务错误另用 §2 对应专段承载。
