## 1. 建设铁律（实现层）

| 编号 | 实现约束 |
|------|----------|
| IR-01 | 独立应用与 `/admin-api/ims/`；数据源 **指向现网 OPS 业务库**，禁止复制业务表双向同步 |
| IR-02 | 调用 Football 仅 `FootballWebApiClient`（HTTP）。禁止 OpenFeign、RPC、`@DS` 指向 member/pay/match/system |
| IR-03 | 禁止调用 OPS 服务；IMS 验收后停 OPS，无长期双写 |
| IR-04 | 现网表 **只加列/从表/索引，禁止删列或减字段** |
| IR-06 | **用户在 `ims.ims_sys_user`**；`userId` = 该表主键 = 业务人员 FK。上线导入保留来源 ID。钉钉 userid / 手机号在本地表幂等 upsert。角色菜单字典参数用 IMS 自有表 |

> **CI 硬门禁（B5 · 2026-10-05 决策）**：IR-02 / IR-03 的工程侧强制落地见《全局开发规范.md》**§7A CI 硬门禁（禁 OPS HTTP）**；源码禁 OPS HTTP 依赖、白名单仅 Football WebAPI、切流纪律与「切流前必修项」均以该节为准。

## 2. 表命名补充

| 类别 | 规则 | 示例 |
|------|------|------|
| OPS 并入 | **使用现网表，不建副本** | `oa_production_content`、`oa_work_task_assignment` |
| 用户 | IMS 本地主表 | `ims_sys_user`；`ding_user_id`、手机号、密码哈希 |
| IMS SYS | 角色菜单字典参数分表 | `ims_sys_role` 等，FK → 共用用户 id |
| IMS 新建 | `ims_` 前缀 | `ims_live_session`、`ims_train_task` |
| 扩展列 | snake_case，可空或有默认 | `author_article_id`、`football_room_id`（业务表加列，非搬库） |

接口字段仍 **camelCase**（全局规范 1.1）。

## 3. Football WebAPI Client

```
football.webapi.base-url
football.webapi.app-token
football.webapi.connect-timeout-ms = 3000
football.webapi.read-timeout-ms = 5000
football.webapi.max-retries = 3
```

写操作必须带幂等键；失败写入 `ims_fb_sync_outbox`（或同构 outbox 表），后台补偿。业务保存 IMS 成功不得因 Football 超时而整体回滚（内容同步类，见 BR-303）。

### 3.1 钉钉开放平台 / ComfyUI·jingcai 配置键（2026-10-05 增）

> 三者同属《全局开发规范.md》**§7A.1 外部 HTTP 白名单（三类）**；宿主目录**仅限** `internal/pkg/{football,dingtalk,comfyui,jingcai}/**`，其余一律阻断。

```
dingtalk.app-key / dingtalk.app-secret / dingtalk.agent-id   # SSO 换票 + 组织事件订阅/增量同步（AUTH-001/002）

```

## 5. 分页与响应

仍用全局规范 `pageNo/pageSize`、`CommonResult`。并入 OPS 接口若历史为 `pageNo` 已对齐则保持；禁止新接口使用 `pageNum`。

## 6. OPS 配置管理（M8）在 IMS 的落点

完整 PRD 已要求 M8 **全部并入**，禁止再保留独立「配置管理」一级菜单。页面按用户作业拆到已有模块：

| OPS 配置页 | IMS 落点 | 路径（迁入后） |
|------------|----------|----------------|
| 内部采集配置 | 数据采集 · 内部配置 | `/admin-api/ims/collect/internal/{platform}` |
| 外部采集 / 关键词 | 数据采集 · 外部配置 | `/collect/external` |
| 外部数据配置 | 数据采集 · 外部配置（数据源行） | 同外部配置扩展行，禁止新造一级菜单 |
| 订单采集配置 | 数据采集 · 订单采集 | `/collect/order-config`（禁止 JDBC） |
| 阈值规则配置 | 数据采集 · 阈值规则 | `/collect/threshold` |
| 元数据维护 | 指标报表 · 元数据 | `/admin-api/ims/bi/metadata` |
| AI 模型 | AI 资源中台 · 模型与提示词 | 原 `oa_ai_model_config` 扩展为 AIR 连接器；内容生成默认 jingcai 环境变量 |
| AI 提示词 | 同上 · 提示词 Tab | 原 `oa_ai_prompt_config`；与 AIR Key **禁止两套** |

系统参数（审核级数、钉钉、jingcai 开关）仍在 **系统管理 · 参数**，不回到配置管理。

## 7. 实现栈（ADR-IMS-002）

- 后端 **Go**（`cmd/api` + `cmd/worker`）+ sqlc；前端 Vue3 Vite 轻量壳。
- 禁止芋道、Spring Boot、OpenFeign、`@DS` 作为 IMS 实现。
- jingcai / 现成 Python 仅旁路进程；IMS HTTP 主进程必须是 Go。
- **外部 HTTP 白名单三类**（见 §3/§3.1 与《全局开发规范.md》§7A.1）：**Football WebAPI**（`football.webapi.*`）+ **钉钉开放平台**（`dingtalk.*`）+ **ComfyUI·jingcai**（`comfy.*` / `jingcai.*`）；配置键名与语言无关，白名单制不变、其余一律阻断。
