# 云 MySQL 联调（开发 / E2E）

## 概览

主机、端口、库名、账号和密码只放在本机环境变量（`IMS_DB_URL` 或部署环境注入的等价变量），不写入仓库。`.env` 已 gitignore。

pytest 不要指向共享云库。

## 切换

1. 在本机 `.env` 设置连接变量。不要把值提交进 git。
2. 启动 API 时由进程读取这些环境变量。
3. 切回本地时，改的是本机环境变量，不是仓库文件。

## E2E

跑会写库的 E2E 之前，确认当前环境变量指向的库可以接受种子写入。

## 安全

聊天或邮件里出现过的数据库密码视为泄露。只在本机环境变量里轮换，不要写回仓库。
