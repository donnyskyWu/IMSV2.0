## 总判定

**不能进入「完整 V1 开发」.** 业务目标与铁律已写清，原 20 模块增量规格大体可执行，但 **OPS 全量并入 + Football 仅 WebAPI** 这一层仍停留在目录级，且与未改写的 V1 PRD / 共享规范 **互相打架**。按本仓规则，开发会在表名、用户 ID、接口字段上被迫推断。

| 维度 | 判定 |
|------|------|
| 产品逻辑 | 目标态闭环（资产→账号→任务→内容→采集→ROI）在完整 PRD 第 6 章成立；两套财务粒度、SOP≠FLOW 已声明 |
| 数据完整性 | 业务不搬库已冻结；缺人员映射规则与 Football 现网路径；共享规范 7.7 仍写迁库（过期） |
| 开发可实现性 | 原 LIVE/ACCT 增量等有六小节规格；并入域 API **无请求/响应体**；无 IMS 切片 / CHECKLIST / P0 用例包 |

允许并行启动的只有 **Sprint 0 冻结包**（见 §5）。冻结完成前，禁止宣称「按完整 PRD 3A 开写代码」。

### 3.2 并入 API 具体缺陷（阻塞编码）

- **SYS**：仅 GET 菜单树 / 字典 list；SYS-003/004 要求管理，无 POST/PUT/DELETE。
- **MASTER**：选择器只有 company/person/ip-group；铁律要求平台账号强关联公司/实名人/手机/卡/IP 组，缺 phone/sim/account 选择器契约。
- **IPG**：分析接口仍写 `GET /ops/account-analysis`，与 IR-03「禁止打到 OPS」文档冲突。
- **CONTENT**：原契约 36 个接口（选题/ComfyUI/审核单号）与并入补充（工作任务/排版/fb-sync）**两套 SOP 模型未声明以谁为准、节点 JSON 长什么样**。并入补充无 body schema，按规则 **不得推断**。
- **COLLECT**：外部数据源无独立资源，仅「扩展行」；订单禁止 JDBC 有错误码 1243，但配置字段未列。
- **HOME**：`HomeDashboardVO` 注释「见页面规格」，页面规格亦未给出指标字段。
- **BI0**：报表 `code` 枚举「8 张」未列出 code；编号从 6 跳到 8。

### 3.3 过程文档缺口（本仓铁律）

`一体化管理/` **没有** 对应完整版的：`SLICES-*`、`CHECKLIST-*`、`TESTCASES-*` P0、`PHASE` Gate。测试补充只有 ST-/ET- 编号和一句话。  
按 `PHASE-DEV-METHOD` / `AI-IMPL-GUIDE`：**不能开 Slice**。

2019-09-19 P0：AIR 规格、FIN 移 V3、API 前缀、ALERT FIN_COST_MISS 占位 —— **大部分已补**。仍未关：共享规范/V1 PRD 正文未删除 Feign 替代说明以外的「已完成只增量」；CONTENT 枚举冲突；AIR PRD 仍无与三期同构的 5.x 六小节（规格已有，PRD 层偏清单）。

## 5. Sprint 0（开发前必须关闭，建议顺序）

1. **冻结冲突句**：V1 PRD / 共享规范 7.1、7.7、规划完成度 改为「OPS 同构迁入 IMS，原完成度不计 IMS 代码」；7.7 成本改为「M5 同构迁入，场次 FIN 从 0」。
2. **表映射登记册**：OPS 业务表全量 1:1；实名人 ≠ 用户映射；加列清单（`ding_user_id`、`author_article_id`、`football_room_id`…）。
3. **用户 ID 写入规范**（IMS 版 ADR）：存什么、选择器从哪读、与钉钉同步顺序。
4. **Football WebAPI 对照表**：路径、鉴权、是否够用、OpenAPI 缺口、账号外部 id。
5. **并入域升格规格**：MASTER 五选择器；SYS 菜单/字典写接口；CONTENT 合并一份契约（含 DAG 节点 DTO）；IPG 去掉 `/ops`；AIR `/air/model` `/air/prompt` 或明确仍用 SYS 参数+环境变量（写入 ADR）。
6. **错误码映射表** 写入完整 PRD 附录。
7. **过程包**：V1 并入批次 SLICES + CHECKLIST + TESTCASES P0（可从 OPS 对应文档改前缀复制，禁止口说「开发时看 OPS」而不登记）。
8. **拍板 L3/L5**：双财务入口页面；删除已上架内容的运营规则。

关闭 1～7 后，才能把完整 PRD 状态从「待评审冻结」改为「开发就绪」，并按切片开工。
