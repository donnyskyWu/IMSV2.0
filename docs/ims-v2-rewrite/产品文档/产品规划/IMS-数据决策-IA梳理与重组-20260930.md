## 2. 重叠矩阵（Overlap）

| 能力 | 出现位置 | 定性 | #17 处置 |
|------|----------|------|----------|
| 八张标准报表 / 经营 KPI | bi0·标准报表；bi·报表总览树 | **重复入口** | 仅 **BI0·标准报表** 为 SSOT；BI 只消费已发布数据集做自助 |
| 多维下钻 / 单元格穿透 | bi·多维下钻；BI0·指标分析；DC·关联下钻 | **场景不同** | BI0=指标趋势；BI=自助报表下钻；DC=主数据链路图（禁止合并为一 Tab） |
| 场次 GMV/利润明细 | bi·场次明细；dc·明细表；11 FIN | **重复** | 废止 bi 场次 Tab → **穿透查询** / 场次财务深链 |
| 作品/账号监测 | bi·作品监测；MON；内部分析；竞品分析 | **越界** | 废止 bi 作品 Tab → **作品监测** / 内部分析 / 竞品分析 |
| IP 组 CRUD | eff·IP 组 Tab；日常运营·IP 组 `ipg` | **重复** | 废止 eff IP 组 Tab → **19a IP 组** |
| 账号异常 / 阈值 | bi0·account-alert 报表；COLLECT·阈值；ALERT·规则 | **分层** | 阈值 **配置**在采集；**告警实例**在预警中心；报表 **只读展示** |
| 全链路经营看板 DC-003 | 曾挂数据中心；PRD 默认 BI0 大屏 | **已迁出** | 维持 #13：入口 **BI0·数据大屏** |
| 利润反查 DC-002 | 曾挂数据中心 | **已迁出** | 入口 **11 场次财务**（子叶命名 **BLOCKED**） |
| 人效总览报表 | bi·报表树「绩效/人效总览」；EFF·看板 | **部分重复** | BI 树 **移除**人效类预制（或链至 EFF）；人效 SSOT=**组织人效** |
| 资产正/反向穿透 | 公司资产 ASSET-001/002 | **不同产品** | V1 资产台账穿透 **保留**；DC 为 V3 聚合宽表，菜单不合并 |

## 3. 目标 IA（To-Be）

### 3.0 v2（走查 #17 深化 · v2.6.13 · **当前 SSOT**）

**侧栏 L1**：数据决策 · **四 L2**（先报表 → 指标 → 分析 → 异常）

```
数据决策
├── 数据报表 [17b BI + M6 报表/大屏 · 可展开 L2]
│   ├── 报表管理          /ims/bi/report/list      （原报表目录 · biList）
│   ├── 报表设计          /ims/bi/report/designer
│   ├── 标准报表          /ims/bi/report           （bi0Report · 兼容 bi0Standard）
│   └── 大屏配置          /ims/bi/screen-config    （bi0Screen · 兼容 bi0ScreenConfig）
├── 数据指标 [17a BI0 · 可展开 L2]
│   ├── 指标管理          /ims/bi/metric
│   └── 指标分析          /ims/bi/metric-analysis
├── 数据分析 [17b + 12 + 19b + M6 查询 · 可展开 L2]
│   ├── 预览与下钻        /ims/bi/report/preview
│   ├── 穿透查询          /ims/dc/trace            （页内无 Tab · #13）
│   ├── 组织人效          /ims/eff/*               （单叶 eff · 页内 Tab：归属/盘点/看板）
│   └── 自定义查询        /ims/bi/query            （bi0Query）
└── 预警中心 [13 ALERT · 可展开 L2]
```
