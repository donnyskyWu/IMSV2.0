# 神鱼体育 一体化管理系统（IMS）产品规划（整体版）

> **文档用途**：面向公司管理层与各业务负责人。用一份骨架回答六个问题 —— 总体目标是什么、产品价值有哪些（按什么排序）、三期规划分别做什么、总体要花多少钱、怎么推进、风险在哪。
> **覆盖范围**：19 项核心需求 · 3 期交付 · 10 类用户角色 · 23 项量化指标
> **编制依据**：《一体化管理系统产品需求说明书 v1.1.0》
> **配套文档**：《IMS 产品规划方案》（分期详版，含每期角色价值表与"上线前 vs 上线后"效果对比）、《IMS 产品规划方案-架构复核意见》

## 一、总体目标

**总目标：IMS 以钉钉为组织底座、以虚拟资产为管理主线、以直播业务为价值核心，用约 40–52 周分三期建成一条从「实名人」到「利润」的可溯源数据链 —— 让人、岗、权实时对齐，让资产、账号、直播、成本利润全程留痕，让管理动作由系统驱动、经营决策由数据支撑。**

### 1.1 分层目标（九个目标层）

| 层级 | 目标描述 | 支撑模块 |
|---|---|---|
| 组织层 | 实现"人岗权限"零延迟、零遗漏、零手工干预闭环 | 01 权限管理 |
| 知识层 | 岗位知识从个人经验转化为组织资产，培训从"师傅带徒弟"变为"系统驱动" | 02 培训管理 / 03 会议管理 / 04 竞品管理 |
| 考核层 | 绩效与考试从"人工核算"变为"系统自动取数 + 自动计算"，结果透明可信 | 05 绩效考试 |
| 资产层 | 虚拟资产全链路可溯源 —— 正向从实名人穿透到所有资产，反向从利润反查到责任人 | 06 证件档案 / 07 资产管理 / 08 账号管理 / 12 数据中心 |
| 业务层 | 每场直播有完整留痕和数据沉淀，从"凭感觉做"变为"看数据做" | 09 数据上报 / 10 直播管理 / 11 财务核算 |
| 风控层 | 构建"全自动、全场景、零遗漏"的风险预警体系 | 13 预警中心 |
| 协作层 | 跨岗位协作从"群聊 + 人盯"变为"系统编排流程 + 超时自动提醒"，进度与责任透明 | 14 工作流管理 |
| 内容层 | 内容生产全流程标准化、SOP 化、可复用，优秀方法论沉淀为组织资产 | 15 内容生产 / 18 作品监测 |
| 数据层 | 多平台数据从"手工导出"变为"自动采集 + 自助分析"，报表搭建与取数零代码 | 16 数据采集 / 17 数据分析 / 18 作品监测 |

### 1.2 阶段性总目标

| 阶段 | 周期 | 到该阶段末，公司达到的状态 |
|---|---|---|
| **第一期（V1）** | 第 1–12 周 | 到第 12 周，公司第一次拥有统一的"人员—权限—资产—账号—直播"台账：**入职即开权限、账号资产可溯源、每场直播全程留痕**。 |
| **第二期（V2）** | 第 13–32 周 | 到第 32 周，培训 / 会议 / 绩效 / 财务 / 内容 / 采集 / 预警全部上线并形成闭环：**该做的事系统自动提醒、自动统计，单场成本利润当场可见，风险自动预警**。 |
| **第三期（V3）** | 第 33–46 周 | 到第 46 周，公司实现全链路穿透查询、零代码自助报表、爆款识别与人效盘点：**管理决策从"凭感觉"变为"看数据"**。 |

## 二、产品价值（按优先级排序）

> **排序依据**：按价值类型分三段递进 —— **先止血 / 安全（堵住失控与资产流失）→ 再效率（把人从重复盯办中解放）→ 后决策增值（用数据创造新价值）**。排序反映价值的重要性，不等同于上线顺序；上线期次按数据链路依赖并行推进。

1. **V-01 权限零手工**（安全 · 首现：第一期 V1）— 解决"后台与钉钉脱节、人员变动后权限靠手工配、岗位职责与权限未标准化"的痛点和安全风险 → 带来**入职即开通权限、离职自动回收**：权限同步延迟 **< 5 分钟**、SSO 登录成功率 **> 99.5%**，权限变更零遗漏、全程可审计。**受益**：全员、IT、高管。
2. **V-02 资产可溯源**（安全 · 首现：第一期 V1）— 解决"数百个账号 / 手机号 / 执照散落在 Excel、关联关系无记录、封号后无法定位责任人" → 资产**集中上账、正向 / 反向穿透查询**，资产关联完整率 **> 98%**，封号时分钟级定位到责任人与设备。**受益**：高管、运营、财务、IT。
3. **V-03 账号不流失**（安全 · 首现：第一期 V1）— 解决"账号领用靠口头和 Excel、离职不归还、责任界定困难" → 领用 / 流转 / 离职归还**全程线上留痕**，账号领用线上化率 **= 100%**，离职流程自动触发归还，资产不再"发出去就失联"。**受益**：人事、部门负责人、高管。
4. **V-04 直播可留痕**（合规 · 首现：第一期 V1）— 解决"开播前无留痕、下播数据散落、封号无法溯源到人 / 设备 / 账号" → 开播风控登记 + 下播数据录入闭环，直播台账留痕率 **= 100%**，为成本与利润核算打好数据底。**受益**：运营 / 主播、IT、高管。
5. **V-05 风险自动预警**（合规 / 安全 · 首现：第二期 V2.3）— 解决"各类风险与待办靠人记忆、无主动提醒、被遗漏" → 预警规则可配置、定时巡检、三级升级、去重合并，预警送达率 **> 99%**、响应率 **> 90%**，风险监控从"靠人记"变"系统盯"。**受益**：各部门负责人、高管、IT。
6. **V-06 管理动作系统驱动**（效率 · 首现：第二期 V2.1）— 解决"培训、日报、数据上报靠人催，会议决议无人跟，跨岗位协作靠群聊 + 口头" → 任务**自动分派 + 超时提醒 + 完成率自动统计**，日报按时提交率 **> 95%**、工作流节点超时率 **< 10%**，管理从"人盯"变"系统驱动"。**受益**：部门负责人、人事、所有员工。
7. **V-07 内容标准化**（效率 · 首现：第二期 V2.2）— 解决"选题 / 脚本 / 剪辑 / 审核无标准 SOP，素材与版本散落、返工多" → **SOP 节点化 + 在线审核 + 驳回理由留痕**，内容 SOP 覆盖率 **> 90%**、一次审核通过率 **> 70%**，优秀方法论可复制复用。**受益**：内容创作者、审核人员、运营负责人。
8. **V-08 数据自动采集**（效率 · 首现：第二期 V2.2）— 解决"多平台数据靠人工逐个导出 Excel 再手工汇总，耗时滞后、口径不一" → 多平台数据**自动采集入库 + 质量校验 + 手工补录兜底**（先接 2 个主力平台），自动采集率 **> 80%**（手工收集工作量下降 80%）、采集及时率 **> 95%**。**受益**：数据分析师、运营、财务。
9. **V-09 成本利润可见**（成本 / 决策 · 首现：第二期 V2.2）— 解决"直播成本散落、无法归集到场次，不知道每场赚不赚钱" → **单场成本录入 → 利润自动计算 → 利润看板**，成本录入完整率 **> 95%**，每场直播"赚多少"当场可见，为经营决策提供依据。**受益**：财务、高管、运营负责人。
10. **V-10 分成透明**（成本 / 决策 · 首现：第二期 V2.2）— 解决"分成靠人工计算、口径不透明、争议多" → **分成规则引擎自动计算、口径统一、计算留痕可追溯**，减少财务与运营扯皮，激励更可信。**受益**：财务、主播 / 运营、高管。
11. **V-11 数据自助分析**（决策 · 首现：第三期 V3）— 解决"数据分散、取数要写 SQL / 拼 Excel，需求响应慢，全链路对不上账" → **零代码自助报表 + 多维下钻 + 看板订阅 + 全链路穿透（从实名人穿透到资产 / 从利润反查到责任人）**，报表查询 **< 30 秒**，取数从天级变分钟级。**受益**：数据分析师、高管、各部门负责人。
12. **V-12 人效可量化**（决策 · 首现：第三期 V3，IP 组组织模型前置 V2.2）— 解决"团队人效是黑箱、说不清谁在创造价值" → 按 IP 组 / 人员聚合**任务完成率、内容产出、ROI** 的人效盘点，人效盘点覆盖率 **= 100%**，高潜识别与公平激励有据。**受益**：高管、运营负责人、人事、员工。

## 三、产品规划（三阶段）

### 3.1 第一期（V1）：系统基座 —— 把"人"和"资产"管起来

**定位与周期**：打通「人—岗—权」与「资产—账号—直播」两条主线，建立全系统主数据底座并**定版全链路数据模型**；不追求功能多，只追求**数据准、权限通、台账全、模型对**。周期 **10–12 周**，全部 P0。

**产品功能范围**

| 编号 | 模块 | 本期交付的二级功能 | 优先级 |
|---|---|---|---|
| 01 | 权限管理 | 单点登录（SSO）、组织架构同步、岗位模板管理、个人工作台 | P0 |
| 07 | 资产管理 | 资产档案录入、正向穿透查询、反向穿透查询 | P0 |
| 08 | 账号管理 | 账号领用、账号流转 / 收回、离职归还、领用记录时间线 | P0 |
| 10 | 直播管理 | 开播风控登记、下播数据录入、直播风险告警、历史台账查询 | P0 |
| — | **数据模型设计（独立交付物）** | 账号—资产—实名人—场次—成本—利润 的 ER 关系、主键 / 外键字典、**多主体字段预留**、场次 ID 编码规则 | P0 |

**产品价值**

| 角色 | 上线前痛点 | 上线后变化（可感知效果） |
|---|---|---|
| 普通员工 | 入职后逐个找人开权限，平均等 1–3 天才能干活 | 钉钉登录即用，权限随岗位模板自动到位，**入职当天即可开工** |
| 部门负责人 / 直属上级 | 手下权限靠手工配，人员变动常漏配；账号发放靠口头 | 权限与组织架构**自动同步（延迟 < 5 分钟）**，团队账号资产一屏尽览 |
| 人事管理员 | 入离职手工整理权限清单与资产归还，离职账号常收不回 | 离职流程自动触发**权限回收 + 账号归还提醒**，交接有清单、资产不流失 |
| 运营 / 主播 | 开播不登记，封号后不知是哪台设备、哪个账号、谁负责 | 开播前 1 次登记（约 1 分钟），**分钟级定位责任人 + 设备** |
| 财务负责人 | 账号、资产不清晰，成本归集不到场次 | 建立干净台账与数据模型，为"单场利润"核算铺好勾稽关系 |
| IT / 系统管理员 | 手工配权工作量巨大、出错率高、审计无依据 | 权限矩阵可配置、SSO 集中管理，从"手工配权"转为"规则运维" |
| 高管 / 老板 | 看不到公司有多少账号资产、在谁手上、风险在哪 | 资产总览 + 账号持有人看板 + 直播台账，**第一次"看清家底"** |

**量化验收指标**

| 指标 | 目标值 | 对应模块 |
|---|---|---|
| 权限同步延迟 | **< 5 分钟** | 01 权限管理 |
| SSO 登录成功率 | **> 99.5%** | 01 权限管理 |
| 资产关联完整率 | **> 98%** | 07 资产管理 |
| 账号领用线上化率 | **= 100%** | 08 账号管理 |
| 直播台账留痕率 | **= 100%** | 10 直播管理 |

**交付物与里程碑**：第 12 周完成 **SSO 上线、资产 / 账号台账入库、全链路数据模型定版、开播登记闭环跑通**。

### 3.2 第二期（V2）：管理闭环 —— 把日常动作沉淀下来

**定位与周期**：把「培训、会议、绩效、证件、数据上报、财务、预警、协作、内容、采集」十大日常动作搬进系统、形成闭环；让"该做的事"自己会提醒、自己会统计。周期 **16–20 周**，全部 P1，再切 **V2.1 / V2.2 / V2.3** 三子批次分批上线。

**产品价值**

| 角色 | 上线前痛点 | 上线后变化（可感知效果） |
|---|---|---|
| 普通员工 | 培训资料散落、日报不知怎么写、任务靠群聊催 | 岗位资料库直达（每周更新率 100%）；日报模板化逐级推送；工作流自动分派任务 + SOP，超时自动提醒 |
| 部门负责人 / 直属上级 | 培训靠问、日报靠催、决议无人跟、审核靠传文件 | 提交率 / 完成率自动统计、会议决议到期自动催办、内容在线审核留痕，**一次通过率 > 70%** |

### 4.6 降本建议

1. **分期投入、按需扩容**：V1 先用最小云档，随数据量与并发增长再升档；云资源优先包年/预留实例。
2. **采集范围收敛**：二期仅接 **2 个主力平台**，其余走"半自动导出 + 补录"，省第三方服务费与联调工期。
3. **边缘能力后置**：AI 脚本（LLM）、竞品库、大屏等可降级或延后，用现成工具（如 Quick BI）替代初期自研。
4. **复用钉钉现有能力**：组织/IM/审批/推送/电话 DING 尽量复用，减少自建 IM 与短信支出。
5. **存储成本治理**：图片压缩 + OSS 生命周期 + 签名访问，避免高清图片堆积导致费用失控。

### 5.5 验收与上线节奏

- **灰度期**：每期上线设 **1–2 周灰度**，先小范围试用再全员放开，灰度期内保留人工兜底通道。
- **分批推广**：由部门负责人（种子用户）先行，再带动一线；V2 按 V2.1 → V2.2 → V2.3 分批上线、即上线即推广。
- **验收判据**：SSO 成功率 > 99.5%、同步延迟 < 5 分钟、迁移关联完整率达标（含"无法补全清单"口径）、查询 P95 < 3 秒、预警送达率 > 99%、10 万行导出 < 30 秒。

### 6.5 风险等级汇总

| 等级 | 数量 | 主要分布 |
|---|---|---|
| 🔴 高 | **10** | 技术 2、集成 2、业务 4、进度 3 |
| 🟡 中 | **12** | 技术 4、集成 2、业务 4、进度 2 |
| 🟢 低 | **1** | 集成 1 |

**最需管理层关注的前 5 项：**

1. **业务决策延迟**（成本口径/分成规则/绩效指标未拍板）——不产生于开发、却会阻塞开发，是最大工期变量。
2. **数据迁移质量与关联关系完整性**——决定全链路溯源的成败，V1 一次做对即可省去三期返工。
3. **8+ 平台采集 API 与个微第三方接口**——二期最大集成风险，须以"2 平台 + 半自动兜底"收敛承诺。
4. **证件隐私泄露**——直接触及合规与法律风险，须权限分级 + 水印 + 访问留痕。
5. **钉钉 API 强依赖 + 数据模型预留不足**——决定"基座是否稳固"与"三期能否穿透"，属一期必须做对的两件事。
