## 二、总体目标

**总目标：IMS 以钉钉为组织底座、以虚拟资产为管理主线、以直播业务为价值核心，在已完成的数据底座之上，用约 32–39 周分三期补齐"管理闭环 + 数据智能"，建成一条从「实名人」到「利润」的可溯源数据链 —— 让人、岗、权实时对齐，让资产、账号、直播、成本利润全程留痕，让内容生产由"人工逐条"转为"标准 + AI 自动化"，让管理动作由系统驱动、经营决策由数据支撑。**

## 三、产品价值（按优先级排序）

> **排序依据**：按价值类型分三段递进 —— **先止血 / 安全（堵住失控与资产流失）→ 再效率（把人从重复盯办中解放）→ 后决策增值（用数据创造新价值）**。排序反映价值的重要性，不等同于上线顺序；上线期次按数据链路依赖推进。
>
> **本规划调整**：①每条价值更新"首现期次"以匹配本规划三阶段口径（内容生产前移至第一期、直播移入第二期）；②新增 **V-13 短视频自动化生产**，并将 V-07 明确为"执行标准级"；③已完成能力（16 / 18 等）以"已上线"标注首现。

1. **V-01 权限零手工**（安全 · 首现：第一期 V1）— 解决"后台与钉钉脱节、人员变动后权限靠手工配、岗位职责与权限未标准化"的痛点和安全风险 → 带来**入职即开通权限、离职自动回收**：权限同步延迟 **< 5 分钟**、SSO 登录成功率 **> 99.5%**，权限变更零遗漏、全程可审计。**受益**：全员、IT、高管。
2. **V-02 资产可溯源**（安全 · 首现：第一期 V1）— 解决"数百个账号 / 手机号 / 执照散落在 Excel、关联关系无记录、封号后无法定位责任人" → 资产**集中上账、正向 / 反向穿透查询**，资产关联完整率 **> 98%**，封号时分钟级定位到责任人与设备。**受益**：高管、运营、财务、IT。
3. **V-03 账号不流失**（安全 · 首现：第一期 V1）— 解决"账号领用靠口头和 Excel、离职不归还、责任界定困难" → 领用 / 流转 / 离职归还 / 冲话费**全程线上留痕**，账号领用线上化率 **= 100%**，离职流程自动触发归还，资产不再"发出去就失联"。**受益**：人事、部门负责人、高管。
4. **V-04 直播可留痕**（合规 · 首现：第二期 V2.1）— 解决"开播前无留痕、下播数据散落、封号无法溯源到人 / 设备 / 账号" → 开播风控登记 + 下播数据录入闭环，直播台账留痕率 **= 100%**，为成本与利润核算打好数据底。**受益**：运营 / 主播、IT、高管。
5. **V-05 风险自动预警**（合规 / 安全 · 首现：第二期 V2.3）— 解决"各类风险与待办靠人记忆、无主动提醒、被遗漏" → 预警规则可配置、定时巡检、三级升级、去重合并，预警送达率 **> 99%**、响应率 **> 90%**，风险监控从"靠人记"变"系统盯"。**受益**：各部门负责人、高管、IT。
6. **V-06 管理动作系统驱动**（效率 · 首现：第二期 V2.1）— 解决"培训、日报、数据上报靠人催，会议决议无人跟，跨岗位协作靠群聊 + 口头" → 任务**自动分派 + 超时提醒 + 完成率自动统计**，日报按时提交率 **> 95%**、工作流节点超时率 **< 10%**，管理从"人盯"变"系统驱动"。**受益**：部门负责人、人事、所有员工。
7. **V-07 内容标准化（执行标准级）**（效率 · 首现：第一期 V1）— 解决"选题 / 脚本 / 剪辑 / 审核无标准、素材与版本散落、返工多" → **SOP 升级到执行标准级（节点标准 + 交付物 + 质量清单）+ 在线审核 + 驳回理由留痕**，内容标准化覆盖率 **> 90%**、一次审核通过率 **> 70%**，优秀方法论固化为可复制的组织标准。**受益**：内容创作者、审核人员、运营负责人。
8. **V-13 短视频自动化生产**（效率 · 首现：第一期 V1）— 解决"短视频生产仍靠人工写脚本、拍 / 剪、配封面，产能受限于人力，标准难以规模化落地" → 在**执行标准级 SOP + 内容要求**之上，由 **AI 技能链自动产出**（AI 选题/脚本 → AI 分镜与素材匹配 → AI 数字人/配音 → AI 剪辑合成 → AI 封面/标题 → 人工终审），单条制作耗时从**数小时降至十几~几十分钟**（估算），同等人力产出**提升数倍**（估算），内容**按统一标准稳定达标**。**受益**：内容创作者、运营负责人、高管。
9. **V-08 数据自动采集**（效率 · 首现：**已上线**，前置于整体规划）— 多平台数据**自动采集入库 + 质量校验 + 手工补录兜底**已就绪，自动采集率 **> 80%**（手工收集工作量下降 80%）、采集及时率 **> 95%**，为后续自助分析与穿透打好进水管。**受益**：数据分析师、运营、财务。
10. **V-09 成本利润可见**（成本 / 决策 · 首现：第二期 V2.2）— 解决"直播成本散落、无法归集到场次，不知道每场赚不赚钱" → **单场成本录入 → 利润自动计算 → 利润看板**，成本录入完整率 **> 95%**，每场直播"赚多少"当场可见，为经营决策提供依据。**受益**：财务、高管、运营负责人。
11. **V-10 分成透明**（成本 / 决策 · 首现：第二期 V2.2）— 解决"分成靠人工计算、口径不透明、争议多" → **分成规则引擎自动计算、口径统一、计算留痕可追溯**，减少财务与运营扯皮，激励更可信。**受益**：财务、主播 / 运营、高管。
12. **V-11 数据自助分析**（决策 · 首现：第三期 V3；指标管理 / 自定义查询已上线）— 解决"数据分散、取数要写 SQL / 拼 Excel，需求响应慢，全链路对不上账" → **零代码自助报表 + 多维下钻 + 看板订阅 + 全链路穿透（从实名人穿透到资产 / 从利润反查到责任人）**，报表查询 **< 30 秒**，取数从天级变分钟级。**受益**：数据分析师、高管、各部门负责人。
13. **V-12 人效可量化**（决策 · 首现：第三期 V3；IP 组管理已上线）— 解决"团队人效是黑箱、说不清谁在创造价值" → 按 IP 组 / 人员聚合**任务完成率、内容产出、ROI** 的人效盘点，人效盘点覆盖率 **= 100%**，高潜识别与公平激励有据。**受益**：高管、运营负责人、人事、员工。

### 4.5 重点专题：内容生产从"流程级 SOP"到"AI 自动化生产"（第一期 V1）

> 本节为**第一期（V1）★ 用户点名重点**。目标：把内容生产从"人工逐条制作"升级为"**定标准 + 做终审，重复劳动交给 AI**"。

#### 4.5.1 问题现状

| 现状 | 具体表现 | 后果 |
|---|---|---|
| SOP 只有**流程粒度** | 目前 15 内容生产已建流程级 SOP —— 有"步骤"，但没有"**做到什么程度算合格**" | 标准不落地，质量全凭个人经验 |
| 生产仍靠**人工** | 短视频仍需人工写脚本、拍 / 剪、配封面 | **产能受限于人力**，规模难以放大 |
| 标准不**结构化** | 无节点交付物、无质量清单 | 新人上手慢、返工多、优秀方法论难复制 |

#### 4.5.2 升级路径（关键链路）

**第一步：SOP 升级为「执行标准级」** —— 每个节点明确"**输入 → 交付物 → 质量标准 / 验收清单**"：

| 节点 | 输入 | 交付物 | 质量标准 / 验收清单 |
|---|---|---|---|
| 选题 | 选题计划 / 数据反馈 | 选题单 | 与账号定位一致、有数据或热点支撑 |
| 脚本 | 选题单 | 分镜脚本 | 结构完整（钩子/主体/转化）、口播合规 |
| 素材 | 脚本 | 素材清单 | 画质/时长/版权达标 |
| 剪辑 | 脚本 + 素材 | 成片 | 节奏、字幕、BGM、时长符合规范 |
| 封面 / 标题 | 成片 | 封面 + 标题 | 点击要素齐备、无违规词 |
| 审核 / 归档 | 成片 + 封面 | 审核记录 + 归档 | 通过审核、理由留痕、可追溯 |

**第二步：在标准之上，由「标准 + 内容要求」驱动 AI 技能链自动生产** —— 关键链路：

```
制定标准 + 内容要求
        │
        ▼
AI 选题/脚本生成 → AI 分镜与素材匹配 → AI 数字人/配音 → AI 剪辑合成 → AI 封面/标题生成
        │
        ▼
     人工终审（标准来自执行标准级 SOP） → 发布归档
```

#### 4.5.3 人的角色变化

- **上线前**：内容创作者"**逐条制作**"——写脚本、找素材、剪、配封面，人力即产能上限。
- **上线后**：人转为"**定标准 + 做终审**"——负责制定执行标准与内容要求、把关键节点、把控最终质量；**重复性劳动交给 AI 技能链**。

#### 4.5.4 可感知效果（估算）

| 维度 | 上线前 | 上线后 | 说明 |
|---|---|---|---|
| 单条短视频制作耗时 | **数小时**（人工） | **十几~几十分钟**（AI 生成 + 人工终审） | 估算 |
| 产能 | 人力即上限 | 同等人力下产出**提升数倍** | 估算 |
| 质量 | 因人而异、返工多 | 脚本 / 封面 / 标题**符合统一标准**，返工减少 | 估算 |
| 新人上手 | 靠师傅带、周期长 | **标准 + AI 技能**使新人也能产出达标内容 | 估算 |

#### 4.5.5 为什么必须放在第一阶段（V1）

- **标准与内容要求是 AI 自动化的前提**：SOP 越早结构化，AI 技能越早能"按标准批量产出"。
- **若标准不定**：AI 只能生成"**不达标**"的内容 —— 自动化反而放大返工。
- 因此把 15 内容生产**由原二期前移到第一期**，并**同步升级到执行标准级 + AI 自动化生产**，与数据模型设计并列为 V1 的两项"地基工程"。

#### 4.5.6 与「在线审核 / 发布归档」的关系

AI 产出后**仍需人工终审**，审核标准同样来自执行标准级 SOP：审核**驳回须填理由、记录可追溯**；通过后进入**发布归档**，形成"标准 → AI 生产 → 人工终审 → 归档 → 数据回流（18 作品监测）"的闭环。

### 6.4 关键路径与依赖

- **决定总工期的链**：钉钉对接 → 数据模型定版 → **已有登记数据关联补全** → 07 穿透/08 领用流转/06 档案治理 → **15 内容生产（含 AI 短视频）** →（V2）10 直播台账 → 11 财务核算 →（V3）12 数据中心穿透。
- **非开发关键工作（须提前启动）**：成本口径/分成规则拍板、绩效指标与权重、**内容执行标准与质量清单、AI 短视频工具链选型、内容素材版权合规**、多主体字段决策——**不由开发产生，却会阻塞开发**。

### 6.5 验收与上线节奏

- **灰度期**：每期上线设 **1–2 周灰度**，先小范围试用再全员放开，灰度期内保留人工兜底通道；**V1 的 AI 短视频生产链先在内测素材上跑通再放开**。
- **分批推广**：由部门负责人（种子用户）先行，再带动一线；V2 按 V2.1 → V2.2 → V2.3 分批上线、即上线即推广；V1 的 15 内容生产按"选题 → 脚本 → AI 生成 → 审核"顺序逐环节放开。
- **验收判据**：SSO 成功率 > 99.5%、同步延迟 < 5 分钟、关联补全完整率达标（含"无法补全清单"口径）、穿透查询 P95 < 3 秒、预警送达率 > 99%、10 万行导出 < 30 秒、**内容 SOP 覆盖率 > 90% + 一次通过率 > 70% + AI 产出合规率 = 100%（无版权/肖像/违规内容）**。
