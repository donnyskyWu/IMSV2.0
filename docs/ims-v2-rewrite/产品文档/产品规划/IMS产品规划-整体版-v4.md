## 三、产品价值（按优先级排序）

> **排序依据**：按价值类型分三段递进 —— **先止血 / 安全（堵住失控与资产流失）→ 再效率（把人从重复盯办中解放）→ 后决策增值（用数据创造新价值）**。排序反映价值的重要性，不等同于上线顺序；上线期次按数据链路依赖推进。
>
> **本规划调整**：① 新增 **V-14 AI 资产可分发**（模块 20，第二期 V2 交付），置于排序第 9 位（效率段，与 AI 类 V-13 相邻）；② **V-09 成本利润可见、V-10 分成透明的"首现期次"由第二期 V2.2 改为第三期 V3**（模块 11 后移）；③ 其余条目沿用上一版口径（V-13 短视频自动化生产、V-04 直播留痕前移至第一期等）。

1. **V-01 权限零手工**（安全 · 首现：第一期 V1）— 解决"后台与钉钉脱节、人员变动后权限靠手工配、岗位职责与权限未标准化"的痛点和安全风险 → 带来**入职即开通权限、离职自动回收**：权限同步延迟 **< 5 分钟**、SSO 登录成功率 **> 99.5%**，权限变更零遗漏、全程可审计。**受益**：全员、IT、高管。
2. **V-02 资产可溯源**（安全 · 首现：第一期 V1）— 解决"数百个账号 / 手机号 / 执照散落在 Excel、关联关系无记录、封号后无法定位责任人" → 资产**集中上账、正向 / 反向穿透查询**，资产关联完整率 **> 98%**，封号时分钟级定位到责任人与设备。**受益**：高管、运营、财务、IT。
3. **V-03 账号不流失**（安全 · 首现：第一期 V1）— 解决"账号领用靠口头和 Excel、离职不归还、责任界定困难" → 领用 / 流转 / 离职归还 / 冲话费**全程线上留痕**，账号领用线上化率 **= 100%**，离职流程自动触发归还，资产不再"发出去就失联"。**受益**：人事、部门负责人、高管。

### 4.5 重点专题：内容生产从"流程级 SOP"到"标准 + AI（ComfyUI）自动化生产"（第一期 V1）

> 本节为**第一期（V1）★ 用户点名重点**。目标：把内容生产从"人工逐条制作"升级为"**定标准 + 写提示词 + 做终审，重复性生成劳动交给"技能 + ComfyUI"**"。

#### 4.5.1 问题现状

| 现状 | 具体表现 | 后果 |
|---|---|---|
| SOP 只有**流程粒度** | 目前 15 内容生产已建流程级 SOP —— 有"步骤"，但没有"**做到什么程度算合格**" | 标准不落地，质量全凭个人经验 |
| 生产仍靠**人工** | 短视频仍需人工写脚本、拍 / 剪、配封面 | **产能受限于人力**，规模难以放大 |
| 标准不**结构化** | 无节点交付物、无质量清单 | 新人上手慢、返工多、优秀方法论难复制 |

#### 4.5.2 升级路径（关键链路）

**第一步：SOP 升级为「执行标准级」** —— 每个节点明确"**输入 → 交付物 → 质量标准 / 验收清单**"：

| 节点 | 输入 | 交付物 | 质量标准 / 验收清单 |
|---|---|---|---|
| 选题 | 选题计划 / 数据反馈 | 选题单 | 与账号定位一致、有数据或热点支撑 |
| 脚本 | 选题单 | 分镜脚本 | 结构完整（钩子/主体/转化）、口播合规 |
| 素材 | 脚本 | 素材清单 | 画质/时长/版权达标 |
| 剪辑 | 脚本 + 素材 | 成片 | 节奏、字幕、BGM、时长符合规范 |
| 封面 / 标题 | 成片 | 封面 + 标题 | 点击要素齐备、无违规词 |
| 审核 / 归档 | 成片 + 封面 | 审核记录 + 归档 | 通过审核、理由留痕、可追溯 |

**第二步：在标准之上，以「标准 + 内容要求 → 生成提示词 → 技能调用 ComfyUI 工作流 → 人工终审 → 发布归档」的方式自动生产** —— 关键链路如下：

```
执行标准级 SOP + 内容要求
        │
        ▼
生成提示词（由标准 + 内容要求驱动：题材 / 结构 / 画面风格 / 时长 / 封面·标题要素等）
        │
        ▼
AI 技能（Skill）调用 ComfyUI 工作流执行生成 → 产出短视频素材 / 成片
        │
        ▼
人工终审（终审标准同样来自执行标准级 SOP） → 发布归档
```

**关于 ComfyUI**：ComfyUI 是**开源、可自部署**的**节点式（工作流）生成引擎**，通过可视化的节点图编排生成流程。本次由 **AI 技能（Skill）以"标准 + 内容要求 → 生成提示词 → 调用 ComfyUI 工作流"的方式驱动它批量产出短视频素材 / 成片**。表述要点：**"提示词"由人 / 标准驱动，"执行"由技能调用 ComfyUI 完成**；人只做**定标准、写提示词模板、终审**。

#### 4.5.3 人的角色变化

- **上线前**：内容创作者"**逐条制作**"——写脚本、找素材、剪、配封面，人力即产能上限。
- **上线后**：人转为"**定标准 + 写提示词 + 做终审**"——负责制定执行标准与内容要求、维护提示词模板、把控最终质量；**重复性生成劳动交给"AI 技能 + ComfyUI"**。

#### 4.5.4 可感知效果（估算）

| 维度 | 上线前 | 上线后 | 说明 |
|---|---|---|---|
| 单条短视频制作耗时 | **数小时**（人工） | **十几~几十分钟**（AI 生成 + 人工终审） | 估算 |
| 产能 | 人力即上限 | 同等人力下产出**提升数倍** | 估算 |
| 质量 | 因人而异、返工多 | 脚本 / 封面 / 标题**符合统一标准**，返工减少 | 估算 |
| 新人上手 | 靠师傅带、周期长 | **标准 + AI 技能（ComfyUI）** 使新人也能产出达标内容 | 估算 |

#### 4.5.5 为什么必须放在第一阶段（V1）

- **标准与内容要求是 AI 自动化的前提**：SOP 越早结构化，AI 技能越早能"按标准批量产出"。
- **若标准不定**：AI 只能生成"**不达标**"的内容 —— 自动化反而放大返工。
- 因此把 15 内容生产**由原二期前移到第一期**，并**同步升级到执行标准级 + AI 自动化生产**，与数据模型设计并列为 V1 的两项"地基工程"。

#### 4.5.6 与「在线审核 / 发布归档」的关系

AI 产出后**仍需人工终审**，审核标准同样来自执行标准级 SOP：审核**驳回须填理由、记录可追溯**；通过后进入**发布归档**，形成"标准 → 生成提示词 → 技能调用 ComfyUI 产出 → 人工终审 → 归档 → 数据回流（18 作品监测）"的闭环。

5. **复用钉钉现有能力**：组织/IM/审批/推送/电话 DING 尽量复用；钉钉事件订阅走重试队列 + 全量对账，降低自研补偿成本；**20 的离职 Key 吊销复用同一批次事件**，不另建离职监听。
6. **存储成本治理**：证件图压缩 + OSS 生命周期 + 签名访问（证件禁下载）；**内容素材（含 ComfyUI 生成的中间产物）按项目归档**，避免高清素材与中间帧堆积导致费用失控。

### 6.4 关键路径与依赖

- **决定总工期的链**：钉钉对接 → 数据模型定版 → 已有登记数据关联补全 → **10 直播台账（V1：开播登记 + 下播录入 + 历史补录）** → 07 穿透 / 08 领用流转 / 06 档案治理 → **15 内容生产（含 ComfyUI 生产链）** →（V2）**V2.1 管理闭环与 20 AI 资源中台并行** →（V3）**11 财务核算 → 12 数据中心"利润反查" / 19 组织人效"ROI"**。
- **本次重排的关键链变化**：
  1. **11 由 V2 移至 V3**：V2 不再承载 11，**V2 关键路径维持"V2.1 → 绩效观察期 → V2.3"，周期不变（11~13 周）**；但其原占的池位由 **20 顶替**，且**必须配独立资源**，否则 V2 延至 16~19 周。
  2. **V3 新增"11 → 12 利润反查 / 19 ROI"串行链**：V3 由 **9~11 周升至 13~15 周**。
  3. **V1 关键路径不变**（12~14 周）。
  → **三处合计：总工期由 32~38 周上移约 4 周至 36~42 周。** 增量来源不是 20（并行专项），而是 **11 后移后与 12 / 19 形成的串行前置链**。
- **非开发关键工作（须提前启动）**：成本口径/分成规则拍板（**已由第 14 周前改为第 28 周前**）、绩效指标与权重、内容执行标准与质量清单、ComfyUI 环境与 GPU 算力就绪、**RAGFlow 环境与算力池扩容决策**、**AI 资产清单与四级密级口径**、**技能安全审核标准**、首批工作流与提示词模板、素材与模型 License 合规、直播场次 ID 编码规则与历史补录口径、多主体字段决策——**不由开发产生，却会阻塞开发**。

### 6.5 验收与上线节奏

- **灰度期**：每期上线设 **1~2 周灰度**，先小范围试用再全员放开，灰度期内保留人工兜底通道；**V1 的 10 直播管理先在小范围主播试点"开播登记 + 下播录入"；ComfyUI 生产链先在内测素材上跑通再放开**；**20 AI 资源中台先以"AI 资产管理员 + 1~2 个试点部门"灰度（先开技能与知识检索，再放开专家组装包与全公司 Key 发放）**。
