## 2. 交付要求（DoD · 6 条）

1. **1:1 完备**：AUTH/SYS 域涉及的每张源表与 IMS 自建表**各占一行**，不得合并省略（本册共 **22 行** + 3 加列；含 D-13 `ims_auth_user_dept` / BR-212 `ims_user_scope` 两张支撑表）。
2. **加列可执行**：加列清单须可直接生成 `ALTER TABLE ... ADD COLUMN`（含可空/默认值，保证 OPS 仍运行时兼容）。
3. **改名有据**：任何改名须附 ADR/规范依据（如 ADR-IMS-002 §4「SYS 用 `ims_sys_*`」）。
4. **隔离无遗漏**：每行必须确认 `tenant_id` 存在且读取路径进 B9 中间件（ADR-IMS-007 §2）。
5. **冲突显式**：命名/口径冲突**不得静默择一**，须标 `冲突`/`作废`（本册冲突②已裁决为 `作废`，见 §5）。
6. **不写 SQL 明细入库**：登记册只登记「表/列/路径/依据」，建表与 seed 脚本由架构/工程另出。
