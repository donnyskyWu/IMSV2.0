## 4. 推荐设计（分能力）

### 4.1 指标管理（17a · P1 · FR-M6-001）

**用户目标**

- **数据分析师 / 运营总监**：维护平台统一指标口径（编码、类型、MetricBuilder SQL），预览后发布供标准报表、大屏、17b 数据集引用。
- **非目标**：在此页做趋势对比（→ **指标分析** P2）、拖拽报表（→ **17b 报表设计**）。

**页面结构**

- **单叶、无 L3 Tab**（禁止与标准报表等同页 Tab 混排）。
- 主区：QueryBar（名称/编码/类型/状态）+ **TBL-METRIC**。
- 新建/编辑：**Drawer 或全屏表单** — F-NAME、F-CODE、F-METRIC-TYPE、**F-BUILDER**（非 COMPOSITE）、F-FORMULA（COMPOSITE 手输）、F-DESCRIPTION（前端可选，UX 注明未持久化则 IMS 不写入）。
- **BTN-PREVIEW** → `POST /admin-api/ims/bi/metric/preview`（契约 #1 族）。
- 删除：引用保护（被查询/大屏/17b 引用时阻断）。

**数据 / API SSOT**

| 项 | SSOT |
|----|------|
| CRUD / preview | `BI0-指标查询报表-API契约.md` · `/admin-api/ims/bi/metric` |
| 交互控件 | `UX-M6` §3 P-M6-001 |
| 行级权限 | BR-305 |

**与 DW 差异**：DW 强调分析师自建指标 + 调度落库；IMS **优先 OPS 现网行为**，V3 预计算/cache（BIR-R3）在 **消费侧（17b）** 约束口径，不在 P1 复制 DW 全套调度 UI。

---

### 4.2 自定义查询（17a · P4 · FR-M6-005）

**用户目标**

- 分析师对 **已映射实体** 做 ad-hoc 探索，保存模板并 **发布** 供大屏 widget（QUERY 数据源）及 17b `CUSTOM_QUERY` 数据集使用。
- **非目标**：元数据字段映射维护（→ **16 数据采集 · 元数据维护** `/ims/collect/metadata`）。

**页面结构（L3 Tab — 仅此页允许 Tab）**

```
[ 自定义查询 ] [ 我的查询 ]
```

| Tab | 内容 |
|-----|------|
| 自定义查询 | 可折叠 QueryBuilder（实体/字段/过滤/聚合/排序）→ [预览] [保存]；**QueryResultPanel**（摘要 + 结果列表 \| 图表 + 分页 + 导出） |
| 我的查询 | 已保存列表：名称、**dict_query_status**、更新时间；执行 / 编辑 / 删除 / **发布** |

**关键交互**

- 实体下拉：仅 **COLLECT 已映射** 实体；未映射 → **1261** + 按钮「元数据维护」。
- 发布态：发布后可供 P-M6-015 组件数据源「已发布查询」下拉（UX-M6 §8.2 QUERY）。
- 超时：契约 **1262** 异步导出（若 OPS 已支持则对齐 UX；否则 BLOCKED 至 M6 切片核验）。

**数据 / API SSOT**

| 项 | SSOT |
|----|------|
| query CRUD / run / publish | `BI0-指标查询报表-API契约.md` #4~#6 |
| 元数据实体 | `/admin-api/ims/bi/metadata`（1261）+ COLLECT P4m |
| 交互 | `UX-M6` §6 P-M6-013 |

**与 DW 差异**：DW 含「公共模板 + 定时邮件」；IMS P4 **首期对齐 M6**（发布 + 执行 + 导出）；定时邮件若 M6 无则 **non-goal** 或归 17b 订阅（BI-003），不并入 P4 Tab。

---

### 4.3 报表设计（17b · BI-001 · 非 BI0）

**用户目标**

- 财务/运营/内容角色基于 **已发布数据集** 自助搭建 **可版本化、可分享、可下钻** 的报表（非 OPS 八张固定 slug）。
- **非目标**：重新定义指标口径（→ P1）；替代标准报表（→ P3a~h）；全屏暗色经营模板（→ 17a 数据大屏 M6）。

**页面结构**

- **L2 单叶**：`/ims/bi/report/designer`（列表「+ 新建」进入工作台）。
- 工作台：**左数据集 + 中拖拽（行/列/值/筛选）+ 下预览**（见《BI-数据分析-页面规格》P1 ASCII）。
- **报表目录** 为 sibling 路由 `/ims/bi/report/list`（非设计器内 Tab）。

**数据集 SSOT（三种来源，均已存在能力）**

| datasetSource | 含义 | 上游 |
|---------------|------|------|
| METRIC_LIB | 指标库字段 | **17a 指标管理** 登记口径 |
| CUSTOM_QUERY | 已发布查询 | **17a 自定义查询** 发布态 |
| DWS_AGGREGATION | V3 宽表 | DC/加工层（字段级 BLOCKED 见原型 hint） |

**关键交互**

- `POST /admin-api/ims/bi/report/query` 预览；V3-B6 同步/异步双态；BIR-R3 禁止自造口径。
- 与 **标准报表**：八张 slug **无** 设计器入口；名称/筛选/布局 SSOT = UX-M6 §4。
- 与 **指标分析**：P2 为 **单指标** 趋势/对比（M6 分析视图 `GET …/metric/{id}/analyze`），无拖拽多维。

**数据 / API SSOT**

| 项 | SSOT |
|----|------|
| 设计器 / 查询 | `BI-数据分析-API契约.md`（20 接口） |
| 页面 | `BI-数据分析-页面规格.md` P1 |

### 4.4 数据大屏（17a · P5/P5b · FR-M6-006/007）

**用户目标**

- 管理层 **只读全屏** 查看 KPI/图表/列表（暗色、自动刷新）；管理员在 **大屏配置** 维护模板与 widget。
- **非目标（17a）**：穿透链路图（→ **12 穿透查询** DC-001）；拖拽自由布局大屏编辑器（DW 式 — 17a 仍为 **模板 + 固定布局区**）；**注 v2.6.26**：自由拖拽画布与发布链接已改判**采纳**，但落点为 **17b 报表设计**（非 17a 大屏）。

**页面结构**

| 路由 | 角色 |
|------|------|
| `/ims/bi/screen-config` | **P5b 配置**：工具栏（模板/保存/预览大屏）+ 左 widget 配置 + 右 **ScreenPreviewPanel**（筛选与全屏一致） |
| `/ims/bi/screen/:id` | **P5 全屏**：顶栏全局筛选 + KPI 网格（≤6）+ STAT/CHART/LIST 行 |

**Widget 数据源（UX-M6 §8.2）**

- **BUILTIN** — 内置键  
- **METRIC** — 17a 指标  
- **QUERY** — 17a **已发布** 自定义查询  

**DC-003 关系**

- 若产品需「全链路经营看板」数据：API 走 `/admin-api/ims/dc/dashboard/*`（DC-003），**菜单入口仍在 17a 数据大屏**（PRD §17a、BI0 §0）。
- M6 原生大屏与 DC-003 **不合并为同一配置 UI**；是否同一 `id` 映射 **BLOCKED**（需 M6/DC 联调决策）。默认：OPS 大屏模板为主，DC-003 为可选数据源/内置 BUILTIN 扩展。

**数据 / API SSOT**

| 项 | SSOT |
|----|------|
| M6 大屏 | OPS UX-M6 §7~§8；IMS 前缀 `/admin-api/ims/bi/*`（大屏相关路径以 M6 切片 openapi 为准，本文不枚举未登记 path） |

## 5. 能力边界与重叠规避

### 5.1 四能力 + 相邻模块定位表

| 能力 | 回答的问题 | 输出物 | 勿做 |
|------|------------|--------|------|
| **指标管理** | 指标是什么、如何算 | 指标定义 + preview SQL | 趋势 UI、八张报表、拖拽报表 |
| **指标分析** | 单指标随时间/维度表现 | 分析图表 | QueryBuilder、自助多维 |
| **标准报表** | 运营固定八张经营视图 | slug 报表 + 导出 | 自定义 SQL、设计器 |
| **自定义查询** | 灵活探索 + 发布查询 | 查询模板/发布态 | 元数据 CRUD |
| **报表设计** | 自助多维报表 | BR 编号报表、版本 | 改 M6 指标定义 |
| **数据大屏** | 全屏 KPI 监控 | 全屏 + 模板配置 | DC 穿透画布 |
| **自助分析·浏览与下钻** | 已发布报表交互 | 下钻/单元格穿透 | 场次链路图（→ DC） |
| **穿透查询** | 主数据链路 | 图/表关联 | 大屏/widget 配置 |
| **组织人效** | 人效归属与看板 | EFF 三叶 | 报表设计、IP 组 CRUD |

### 5.2 Non-goals（四能力范围内）

1. **指标管理**：不做 COMPOSITE 以外类型的 Builder 扩展（除非 UX-M6 变更）；不做 DW 式指标计算调度配置 UI（除非 FR-M6 增补）。  
2. **自定义查询**：不做 SQL 自由文本入口（M6 QueryBuilder only）；不做 COLLECT 映射编辑。  
3. **报表设计**：不做 OPS 八张 slug 的可视化改版；不做 M6 大屏模板编辑。  
4. **数据大屏**：17a 不做 Lite DW 自由布局 50 组件大屏（**归 17b 报表设计**，v2.6.26 采纳）；17a 不做业务化外网发布链接（**归 17b P3**，v2.6.26 采纳）。  
5. **四能力均不承载**：预警规则配置、人效算分、场次利润反查（FIN DC-002 BLOCKED）。

> **v2.6.26 修订说明**：上列第 4 条原为「不做 LW 自由布局 50 组件大屏 / 不做外网发布链接」；经用户走查 #20 判定 DW 该链路「链路完整且可实现」，**改判为采纳**，落点 **17b 报表设计**（《BI-数据分析-页面规格》§10），本文件 §4.4 已同步订正。**仍为 non-goal**：多租户报表模板市场、iframe 内嵌携带登录态、TV 自动轮播、告警推大屏。
