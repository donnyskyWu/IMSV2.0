## 1. 指标管理

### 1.1 参考产品功能（DW-PRD §9.7）

- **指标定义**（§9.7.1）：名称、编码、分类、数据源表、度量/维度、公式、计算频率、单位、描述；编码全局唯一；公式四则+聚合+条件、`{{field}}` 引用、嵌套指标 ≤2 层；每次保存 **版本 +1**；启用/禁用。
- **指标计算与调度**（§9.7.2）：实时 / 定时 / **依赖加工成功后触发**；结果落库；手动触发；失败预警；实时模式查询时计算、不落库。
- **指标结果查询**（§9.7.3）：按维度、时间、版本查历史；版本对比；导出 CSV；供查询与 BI 引用。
- **指标分类管理**（§9.7.4）：最多 3 级树；同级名称唯一；删分类校验关联指标。

**DW 侧栏/页面**（`DW-UI-Prototype-Phase1.html`）：`mt-list`（列表 hub）、`mt-form`（定义表单）、`mt-result`（结果查询）、`mt-category`（分类）、`mt-schedule`（计算调度）。

### 1.2 业务逻辑 / 流程

| 步骤 | 角色 | 动作 | 规则/状态 |
|------|------|------|-----------|
| 1 | 分析师 | 从数据字典确认已发布表口径 | 未发布表不可选（DW §9.2） |
| 2 | 分析师 | 新建/编辑指标 → 选表、维度、公式 | 试算/语法校验失败 → 阻断保存 |
| 3 | 分析师 | 保存 | 版本递增；可选启用计算调度（DW） |
| 4 | 系统/分析师 | 定时或依赖触发计算 | 结果写入指标结果库（DW） |
| 5 | 消费方 | 标准报表 / 大屏 METRIC / 17b METRIC_LIB | IMS：口径 SSOT 在 P1，消费侧禁止自造口径（BIR-R3） |

IMS 对齐 **OPS P-M6-001**：MetricBuilder + `POST …/metric/preview`；**不在 P1 复制** DW 全套「结果落库 + 调度 UI + 分类树」（见 §1.4）。

### 1.3 原型设计要点（DW HTML）

| 页面 id | 布局与控件 |
|---------|------------|
| **`mt-list`** | 搜索栏；工具栏「＋定义指标 / 计算调度 / 分类管理 / 结果查询」；宽表（编码、名称、分类、数据源表、维度、公式、频率、单位、版本、状态）；行内试算、详情 Drawer、删除确认 |
| **`mt-form`** | 分区表单：编码/名称/分类/数据源表（映射表时效 hint）、度量与维度、公式编辑器、频率、描述；底部「试算」「保存」 |
| **`mt-result`** | 指标与时间筛选；工具栏查询/版本对比/导出；结果表含环比、版本、状态 |
| **`mt-category`** | 左分类树 + 右「分类下指标」列表 |
| **`mt-schedule`** | （菜单入口）与 DAG 中指标节点联动示意 |

**交互深度**：试算弹窗（采用结果）、详情 Drawer（引用报表清单）、版本对比弹窗。

### 1.4 IMS 采纳 / 裁剪

| 采纳（本期 17a · P1） | 裁剪 / 差异 |
|------------------------|-------------|
| QueryBar + 指标列表 CRUD；Drawer 编辑（名称、编码、类型、Builder/公式）；**BTN-PREVIEW** | DW「分类树」「结果查询」「计算调度」独立页 — **non-goal**（无 DW 指标结果库） |
| 引用保护删除；供大屏 METRIC、17b 数据集 | DW 嵌套指标 2 层、依赖加工触发 — 以 **UX-M6 + FR-M6-001** 为准，不扩 DW 规则 |
| 单叶路由 `/ims/bi/metric`，无与标准报表混 Tab | 趋势分析 → **P2 指标分析** |

**原型对齐**：`IMS-完整系统-UI原型.html` · `bi0Metric` — 搜索 + 工具栏 + 列与 DW `mt-list` 同构（无 toast-only 占位）。

## 2. 自定义查询

### 2.1 参考产品功能（DW-PRD §9.8）

- **查询配置**（§9.8.1）：可视化 QueryBuilder — 表、字段、WHERE（AND/OR 嵌套 ≤3 级）、聚合/分组/排序、LIMIT；**实时 SQL 预览**（T-SQL）；仅已注册元数据表。
- **查询执行**（§9.8.2）：参数化 SQL；表格 + 图表（柱/饼/折线等）；超时 60s；导出 CSV/Excel；执行记录 30 天；可作 BI 数据源。
- **查询模板**（§9.8.3）：个人/团队/公开；版本；复制；BI 引用。
- **定时查询与通知**（§9.8.4）：Cron + 邮件/钉钉 + 附件。

**DW 页面**：`qy-list`、`qy-editor`（双栏）、`qy-templates`、`qy-schedules`。

### 2.2 业务逻辑 / 流程

| 步骤 | 角色 | 动作 | IMS 状态 |
|------|------|------|----------|
| 1 | 分析师 | 选已映射实体（COLLECT） | 未映射 → **1261** + 深链元数据维护 |
| 2 | 分析师 | 配置字段/过滤/聚合 → 预览 SQL → 执行 | preview → execute |
| 3 | 分析师 | 保存查询 | 草稿 |
| 4 | 分析师 | **发布** | `dict_query_status` 已发布；大屏 QUERY、17b CUSTOM_QUERY 可选 |
| 5 | （DW） | 存模板 / 定时推送 | IMS P4：**对齐 M6**；定时邮件 → **17b 订阅或 non-goal**（见四能力分析 Q2） |

IMS **页级 Tab**（唯一 L3）：**自定义查询 | 我的查询**（UX-M6 P-M6-013）— 对应 DW 的「编辑器 + 列表」，**不**并列 DW 的「模板库 / 定时计划」为第三、四 Tab（能力可后续单列或归 17b）。

### 2.3 原型设计要点（DW HTML）

| 页面 id | 布局与控件 |
|---------|------------|
| **`qy-list`** | 搜索（名称、表、创建人）；工具栏「新建 / 查询模板 / 定时计划」；列表含字段数、条件数、最近执行、耗时 |
| **`qy-editor`** | **grid2**：左 — ①数据源+字段 checkbox ②WHERE 表格式条件行+条件组 ③分组/排序/LIMIT+名称；右 — SQL `code-block`、结果 Tab「表格|图表」、图表类型/维度切换 |
| **`qy-templates`** | 模板列表（可见范围、标签、使用次数）；Drawer 详情含参数占位 `{{bizDate}}` |
| **`qy-schedules`** | Cron、关联模板、通知方式 |

### 2.4 IMS 采纳 / 裁剪

| 采纳 | 裁剪 |
|------|------|
| QueryBuilder 分区（实体/字段/过滤/聚合）；SQL 预览区；结果 **列表 | 图表**；我的查询列表 + 发布/执行/删除 | DW「公共模板库」「定时计划」**不进 P4 Tab** |
| 1261、1262（异步导出以 OPS 为准） | 自由 SQL 文本入口 — **禁止**（M6 QueryBuilder only） |
| 元数据维护在 **16 数据采集** | DW 模板可见范围「公开/团队」— IMS 用 **发布态** 对齐 M6 |

**原型对齐**：`bi0Query` — L3 Tab + 左 Builder / 右 SQL+结果 mock（对标 `qy-editor`）。

## 3. 报表设计

### 3.1 参考产品功能（DW-PRD §9.9.1~§9.9.4）

- **报表管理**：类型普通报表 / **数据大屏**；栅格 vs 自由布局；私有/团队/公开；分类树、标签；导入导出 JSON；缩略图。
- **拖拽设计器**（§9.9.2）：图表 / 查询条件 / 容器 / 交互组件；画布栅格或自由；属性：基础 / 数据源 / 交互；草稿自动保存 + 手动发布。
- **组件数据源**（§9.9.3）：元数据表、查询模板、指标结果、自定义 SQL、外部 API；静态+动态条件 `${component_id.field}`；刷新策略（加载/参数变化/定时 ≥30s）。
- **联动**（§9.9.4）：点击/选择/范围联动；全局参数；跳转；循环依赖检测。

**DW 页面**：`bi-list`（左分类树 + 卡片/列表视图）、`bi-designer`（三栏 + 图层面板）、`bi-preview`、`bi-publish`、`bi-published`。

### 3.2 业务逻辑 / 流程

| 步骤 | 角色 | 动作 | IMS |
|------|------|------|-----|
| 1 | 分析师 | 报表目录「新建」或从列表进入 | 17b：`/ims/bi/report/designer` |
| 2 | 分析师 | 选数据集 **METRIC_LIB / CUSTOM_QUERY / DWS**（宽表 BLOCKED） | BIR-R3 |
| 3 | 分析师 | 拖拽维度和度量 → 预览 | `POST …/report/query` |
| 4 | 分析师 | 保存版本、分享 | sibling 路由 `report/list` |
| — | — | **OPS 八张标准 slug** | **无设计器** → 17a P3a~h |

DW 将「报表 + 大屏」同一模块；IMS **拆分**：自助拖拽 = **17b 报表设计**；经营全屏模板 = **17a 数据大屏（M6）**。

### 3.3 原型设计要点（DW HTML）

| 页面 id | 布局与控件 |
|---------|------------|
| **`bi-list`** | 左 230px 分类树；右搜索+「新建报表/新建大屏/导入」+ 卡片/列表切换；卡片含类型 badge、预览/大屏快捷 |
| **`bi-designer`** | **designer-top**：返回、标题、草稿 tag、撤销/重做、栅格·设备、保存/预览/发布；**dsn-left** 组件库分组拖拽；**dsn-canvas** 网格底；**dsn-right** 基础/数据源/交互折叠面板；**layer-bar** |
| 弹窗 | `biFieldDlg`、`biFilterDlg`、`biLinkDlg` — 字段、动态参数、联动目标 |

### 3.4 IMS 采纳 / 裁剪（**v2.6.26 更新：原裁剪项升级为采纳**）

| 采纳（17b · BI-001 · v2.6.26 全量落地） | 仍裁剪 |
|------------------------------------------|--------|
| **三栏拖拽骨架**：左「数据集/字段/**组件库四类 21 组件**」· 中「**画布 40px 栅格 + 图层面板**」· 右「**属性三区** 基础/数据源/交互」 | 地图 / 3D / 轮播等**重资产组件**（除非 V3 规格增补） |
| **组件级数据源 + 动态参数 `${compId.field}` + 输出参数 + 刷新 ≥30s** | DW **自定义 SQL / 外部 API** 数据源 — **BLOCKED**（须 BI API 登记） |
| **组件联动（点击/选择/范围）+ 循环依赖检测 + 跳转四类目标** | DW **多租户报表模板市场** |
| **报表管理**：分类树 + 卡片/列表双视图 + 自动缩略图 + 复制 + **导入/导出 JSON 模板** + 分类管理 | DW **结果历史/版本对比**（无指标结果库） |
| **发布链路**：方式/可见范围/**密码 + 有效期 7~30 天**/展示刷新 + **版本快照** + 访问统计（P3 §7.4） | DW **iframe 内嵌携带登录态**（安全评估未过） |
| **全屏大屏多终端**（PC/TV/移动） | DW **TV 端自动轮播切页** / **告警推大屏** |
| 版本化、分享、下钻（BI 规格） | DW「报表类型=大屏」**同一设计器** — IMS 大屏走 **M6 模板**（17a），17b 承载自由画布报表 |

**原型对齐（v2.6.26 重写）**：`biDesign` · `biDesignerTab()` — 完整对标 `bi-designer`：顶栏（撤销/保存并发布/设备预览）+ 三栏（左 198px / 中画布 1060×600 / 右 272px）+ 图层面板 + 属性三区 + 组件库四类 21 组件（可拖）；`biList` 对标 `bi-list`（分类树 + 卡片/列表 + 缩略图）；`biShare` 三 Tab 对标 `bi-publish`；`biFullscreen` 对标 `biFullscreen`。

## 4. 数据大屏

### 4.1 参考产品功能（DW-PRD §9.9.1 + §9.9.5）

- **类型**：`type=dashboard` 与普通报表同列表，**全屏、自动刷新、发布链接**（§9.9.5）。
- **展示**：预览 / 发布只读链接（密码、有效期）/ 浏览器全屏隐藏导航；刷新最小 30s；PC / TV / 移动适配；发布快照与回滚。
- **设计态**：与报表共用 **拖拽设计器** + 深色 thumb（`bi-list` 卡片）。

### 4.2 业务逻辑 / 流程

| 步骤 | 角色 | 路由/动作 | IMS |
|------|------|-----------|-----|
| 1 | 管理员 | 大屏配置：选模板、配 widget | `/ims/bi/screen-config`（P5b） |
| 2 | 管理员 | 每 widget：BUILTIN / METRIC / **已发布 QUERY** | UX-M6 §8.2 |
| 3 | 管理员 | 保存 → 预览全屏 | 预览参数 = 全屏 `buildDashboardDataQuery` |
| 4 | 管理层 | 只读全屏 | `/ims/bi/screen/:id`（P5）暗色顶栏筛选 |
| （可选） | — | 全链路经营数据 | DC-003 API；**入口仍在 17a 大屏** |

**17a 大屏**（M6 模板式）：**无** DW 式「50 组件自由布局编辑器」——自由画布归 **17b 报表设计**（v2.6.26 采纳）；**无** 外网枚举发布链接（17a 不开放，**发布链接密码/有效期归 17b P3**）。

### 4.3 原型设计要点（DW HTML）

| 页面 id | 要点 |
|---------|------|
| **`bi-list`** | `type=dashboard` 卡片、`biFullscreen()`、深色缩略图 |
| **`bi-designer`** | 大屏草稿同样三栏（KPI 顶栏 + 图表区 + 日期筛选组件）|
| **`bi-preview` / `bi-published`** | 全屏预览、发布链接访问（DW P2 统计）|

IMS **17a** 原型应对标 **M6 P-M6-015/014**：**左 widget 配置 + 右 ScreenPreviewPanel**，而非完整 DW 画布；**17b** `biDesign` 承载**自由拖拽画布**（v2.6.26），`biFullscreen` 承载**多终端全屏**。

### 4.4 IMS 采纳 / 裁剪

| 采纳（17a · P5/P5b） | 裁剪 |
|----------------------|------|
| KPI ≤6 + STAT/CHART/LIST 模板区；顶栏 scope/日期/IP 组/平台/刷新 | DW 与报表共用自由拖拽大屏 → **归 17b**（v2.6.26 采纳，非 17a） |
| seed-analytics 非空（Gate S6） | DC-003 与 M6 模板 ID 是否统一 — **BLOCKED**（Q1） |
| 穿透链路 → **12 穿透查询**，非大屏画布 | DW 发布链接密码/有效期 → **v2.6.26 改判采纳**，归 **17b P3 §7.4** |

**原型对齐**：`bi0Screen` — 配置/全屏切换 + 左 widget 表单 + 右暗色 widget 网格 mock。
