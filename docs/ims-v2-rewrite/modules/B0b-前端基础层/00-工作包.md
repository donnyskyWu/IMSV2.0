### 2.1 手机适配规格（产品裁定 2026-10-12，对应 02-验证用例 Q1～Q21；who kong 可推翻）
| Q | 裁定 |
|---|---|
| Q1 | 断点 Token 共两档：`--bp-mobile: 768px`。宽度 <768px 用手机布局，≥768px 用桌面布局；不设平板档 |
| Q2 | 手机下侧栏改为左侧抽屉，宽 240px，带遮罩，点菜单项后自动收起。触控设备上，原来靠悬停触发的交互一律改为点击，包括面包屑折叠、脱敏 tooltip、部门树的"⋯" |
| Q3 | 顶栏高度保持 56px，只保留菜单按钮、页面标题、未读消息和用户菜单；"统计范围"移到用户菜单里 |
| Q4 | DataTable 保持表格形式，横向滚动，不做卡片化；首列和操作列固定，操作列只留"更多"下拉。Tabs 超出一屏时横向滚动，不换行 |
| Q5 | FormField 改成单列，标签放在输入框上方；DescriptionList 统一按 `cols=1` 显示，标签也放上方 |
| Q6 | FormDrawer 的 S/M/L 三档和 DetailDrawer 在手机下都改为 100% 宽的全屏抽屉，从右侧滑入 |
| Q7 | Modal 宽度 = `min(档位, 100vw - 32px)`，左右各留 16px 边距 |
| Q8 | 手机下 Pagination 只显示上一页、"当前页/总页数"和下一页，隐藏每页条数和跳页 |
| Q9 | QueryBar 默认只显示 1 个条件，其余收进"筛选"按钮，点开后用全屏抽屉选择 |
| Q10 | 最小触控尺寸 44×44px，适用于所有可点击元素；视觉尺寸可以更小，但热区要用 padding 或伪元素扩大到 44px，相邻目标间距至少 8px。26px 小号按钮和 30px 控件保持原视觉尺寸，只扩大热区 |
| Q11 | 横屏 844×390 宽度 ≥768px，按桌面布局处理；不在验收视口内，不写用例 |
| Q12 | 手机下最小字号 12px，原来 11px 和 11.5px 的地方统一提到 12px；输入框字号 ≥16px；viewport 允许用户缩放；放大到 200% 时只要求主内容区不出现横向溢出，表格自带的横滚除外 |
| Q13 | Toast 放在顶部居中，最大宽度 `100vw - 32px` |
| Q14 | PageHeader 标题改为 20px；`actions` 只保留主按钮，其余收进"更多" |
| Q15 | UI-L03 左侧树在手机下改为点"部门"按钮弹出的抽屉，不支持拖拽；UI-L06 和 C41 在手机下只读，只能查看，显示"请在电脑端编辑"；StepsWizard 改为只显示"第 n/N 步"；日期区间只显示单月面板；底部操作栏固定在底部，内容区留出等高的底部空白 |

| Q18 | 手机下内容区内边距 12px 16px |

### 2.2 手机适配冲突裁定（对应 02-验证用例"冲突与歧义"第 1～11 条）
| # | 裁定 |
|---|---|
| 1 | 写死桌面数值的原用例在 390×844 下豁免，以 VC-M 为准（见 §5） |
| 2 | 手机下 PageHeader 不显示统计范围，统一放到用户菜单里 |
| 3 | 8px 指视觉框之间的间距；热区允许重叠，重叠部分归离点击点更近的目标 |
| 4 | 保留"共 N 条"；`total=0` 时整个分页组件不显示，只显示空态 |
| 5 | 左树抽屉宽 280px（不超过 `100vw - 56px`），选中节点后自动关闭 |
| 6 | 手机下只显示画布，左右栏隐藏，点击节点后用全屏抽屉显示详情；画布支持单指拖动和双指缩放 |
| 7 | 200% 指浏览器页面缩放，Playwright 里用 `document.documentElement.style.zoom = 2` 模拟；主内容区不包括顶栏 |
| 8 | 本期不做横屏，需求方以本裁定为准，记入 ADR |
| 9 | 登录页不在 B0b 冒烟范围内。`/__routes` 作为新增功能点 FP-R-09，只在 test 构建里提供，不需要鉴权，返回 `[{path, name, meta}]`。test 构建中权限码格式错误降级为 `console.warn`，不算冒烟失败 |
| 10 | 手机下首列宽度不超过 120px，超出部分省略并提供 tooltip |
| 11 | 只保留第一个 primary 按钮，其余收进"更多"；一个 primary 都没有时，所有按钮收进"更多" |
