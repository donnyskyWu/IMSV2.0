**部门树**（`qa_admin` 视角，括号内为"含下级去重人数 / 直属人数"）

```
全部
待分配（系统）                         2
星河传媒（钉钉）                       21 / 1
├─ 市场部（钉钉）                       9 / 3
│  ├─ 市场一组（钉钉）                   4 / 4   ← 其中 1 人同时属市场部
│  └─ 市场二组（本地）                   3 / 3

├─ 运营部（本地）                       4 / 2
│  └─ 直播运营组（本地）                 2 / 2
├─ 临时项目组（本地，待确认）            2 / 2
└─ 旧项目组（本地，已停用）              0 / 0
```

（人数为造数脚本固定值；离职人员不计入人数。`qa_admin`、`qa_viewer`、`qa_none` 归属技术部，`qa_dept` 归属市场一组，均已计入上表人数。市场一组另有 1 名离职人员（不计人数）；除"王五（主部门市场一组，兼属市场部）"外无其他兼属。）

## 移动端 390×844 视口验证

> 依据：`00-工作包.md` 补充决策 D1，以及 §2.1 手机适配规格（产品裁定 2026-10-12，Q1～Q21；who kong 可推翻）。本节预期中的数值都取自 §2.1，引用写作「§2.1 Qx」。

> - `expectNoHOverflow(page, w = 390)`：`expect.poll(() => page.evaluate(() => Math.max(document.documentElement.scrollWidth, document.body.scrollWidth))).toBeLessThanOrEqual(w)`；
> - `expectInViewport(locator)`：`boundingBox()` 满足 `x >= 0 && x + width <= 390 + 0.5`；
> - `collectErrors(page)`：收集 `pageerror` 和 `console` 中 `type()==='error'` 的条目，warning 不收集（§2.1 Q17），用例结束时断言为空；
