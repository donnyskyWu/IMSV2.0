**部门树**（`qa_admin` 视角，括号内为"含下级去重人数 / 直属人数"）

```
全部
待分配（系统）                         2
星河传媒（钉钉）                       21 / 1
├─ 市场部（钉钉）                       9 / 3
│  ├─ 市场一组（钉钉）                   4 / 4   ← 其中 1 人同时属市场部
│  └─ 市场二组（本地）                   3 / 3

├─ 运营部（本地）                       4 / 2
│  └─ 直播运营组（本地）                 2 / 2
├─ 临时项目组（本地，待确认）            2 / 2
└─ 旧项目组（本地，已停用）              0 / 0
```
（人数为造数脚本固定值；离职人员不计入人数。`qa_admin`、`qa_viewer`、`qa_none` 归属技术部，`qa_dept` 归属市场一组，均已计入上表人数。市场一组另有 1 名离职人员（不计人数）；除"王五（主部门市场一组，兼属市场部）"外无其他兼属。）
