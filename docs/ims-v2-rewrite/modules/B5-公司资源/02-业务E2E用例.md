## 1. 公司管理（CO）

### E2E-B5-CO-01 进入页面与列表元素
- **功能点**：CO-01、BG-02
- **步骤**：`test_xz` 登录 → 侧栏 公司资产 → 资源管理 → 公司管理。
- **预期**：侧栏“公司资产”在“权限管理”之后，下有“资源管理”4 项；页头〔导出〕〔新建公司〕；筛选 名称、信用代码、状态；表头 公司 ID、名称、信用代码、公众号容量、状态、操作。

### E2E-B5-CO-02 新建公司与必填、重复
- **功能点**：CO-02
- **步骤**：1. 〔新建公司〕不填保存；2. 建 CO-A `TC公司A` 容量 1、CO-B `TC公司B` 容量 10；3. 再建 `TC公司A`；4. 信用代码填 `123`。
- **预期**：1 “公司名称”标红“必填项，请填写”；2 列表显示 `0 / 1`、`0 / 10`，状态启用；3 提示“公司名称已存在”（1001）；4 提示信用代码格式不正确。

### E2E-B5-CO-03 详情与扩容
- **功能点**：CO-04、CO-05
- **步骤**：1. CO-A〔详情〕；2. 〔扩容〕新容量 2、原因 `测试扩容`；3. 再扩容到 0（模拟 B7 已登记 1 个公众号：造数写入关联）。
- **预期**：1 容量卡 总量 1 / 已注册 0 / 剩余 1，关联账号空状态；2 容量 `0 / 2`，扩容记录 1 条（原 1 → 新 2、操作人姓名）；3 提示容量不能小于已注册数（1222）。

### E2E-B5-CO-04 停用后不可被选
- **功能点**：CO-03、BG-01
- **步骤**：1. CO-B〔停用〕→ 确认；2. 接口核对 `GET /corp/resource/company/simple-list`；3. 〔启用〕恢复。
- **预期**：1 确认文案含“已关联账号不受影响”，状态停用；2 不含 CO-B；3 恢复后出现。

### E2E-B5-CO-05 容量紧张标签
- **功能点**：CO-01
- **步骤**：看 CO-A（剩余 2）与 CO-B（剩余 10）。
- **预期**：CO-A 显示黄色“容量紧张”，CO-B 无（Q-B11，裁定不同则改用例）。

### E2E-B5-CO-06 筛选与导出
- **功能点**：CO-01、CO-06
- **步骤**：状态=启用 → 查询 →〔导出〕→ 下载文件；〔重置〕。
- **预期**：导出行数与列表一致，法人身份证为脱敏（Q-B6）。

## 2. 实名人管理（RN）

- **预期**：1 姓名、证件类型、证件号必填；2 提示身份证号不合法；3 列表 4 人，证件号形如 `320***********1234`，手机 `138****5678`；库内 `id_card_enc` 为密文。
