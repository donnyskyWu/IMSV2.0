## 6C. 后端集成与 SSRF 用例（引用）
- 反向错误码 1008 / 1504 / 1001 / 1500 / 1501 / 1503：后端接口集成测试 `IT-B10-AUTH/RES/PARAM/REF-*`（真实 MySQL，44 个接口每个都覆盖），清单见 `01-功能点清单.md` §8；E2E 每类只保留 1～2 条代表（BG-02、BG-08～10、SK-02、SK-06 等）。
- 1502：本批无场景（01 §0.4），无用例。
- **SSRF 本地化执行**（IT-B10-SSRF-01～09）【已决策（按建议）】：
  - 私有网段（10/8、172.16/12、192.168/16）、169.254.169.254、非 http(s) 协议：在发请求前即被拒，**只断言 1001 与无条目，不需要任何服务**；
  - 302 跳转内网、超时、超 10MB：用同一个本地模型桩（`e2e/stubs/model-stub`）新增路由 `/redirect-internal`（302 到 `http://10.0.0.1/`）、`/slow`（挂起不响应）、`/big`（流式返回 >10MB），**不连公网**；
  - 超时用例通过仅测试环境生效的 `E2E_FETCH_TIMEOUT_SEC=1` 缩短抓取超时（生产配置忽略并告警，同 `E2E_SSRF_ALLOWLIST`），不等待默认 10 秒；
  - 桩的 host:port 在 `E2E_SSRF_ALLOWLIST` 中，故第 1 跳放行；`/redirect-internal` 的跳转目标必须是**不在白名单的内网地址**（`http://10.0.0.1/` 或 `127.0.0.1` 的其他端口），**不得跳回桩自身**；断言两点：① 返回 1001；② 桩日志中无对跳转目标的请求（目标未被访问）；
  - 白名单只按 host + 端口精确匹配，单写 host 不放行；同 host 换端口 → 1001（UT-B10-BG-SSRF-09、IT-B10-SSRF-10）。
