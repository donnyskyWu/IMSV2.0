## 2. 技能库（SK）

### FP-B10-SK-01 列表
- **页面线框**：统计卡；分类页签 全部 / 内容生产 / 数据分析 / 运营支持 / 财务 / 人事行政；筛选 名称、状态、审核状态、责任人；〔新增技能〕；表头 编号、名称、分类、版本、状态、审核状态、风险等级、责任人、授权人数、累计调用、操作。
- **规则**：操作按状态：PENDING_AUDIT〔审核〕；PUBLISHED〔编辑〕〔授权〕〔停用〕；DISABLED〔启用〕；“待修改”行〔编辑〕；分页 20。
- **接口**：★ `GET /skill/page`。
- **依据**：【AIR 规格】P1 §2、§5、§6；TC AIR-SKL-01。

### FP-B10-SK-02 新增并提交审核
- **角色权限**：`create`。
- **规则**：必填：名称（≤128）、分类、初始版本（语义化版本）、责任人、来源（市场标识 / 上传文件 / URL 三选一联动）、能力说明、SKILL.md 内容；提交即 `PENDING_AUDIT`，同步执行 SK-03 扫描；`clientToken` 幂等。
- **错误码**：1001、1500、1503。
- **接口**：★ `POST /skill`；○ 文件上传（`air_skill`）。
- **依据**：【AIR 规格】P1 §4.2 A、§7；TC AIR-SKL-02、03。

### FP-B10-SK-03 自动安全扫描
- **规则**：按 Q-D5 规则扫描，结果三清单（依赖 / 危险命令 / 外联）与风险等级写 `ims_skill_ver.scan_result`、`risk_level`；无命中为空（列表显示“—”）。
- **依据**：SKILL-002；【AIR 规格】P1 §4.2 A-3；Q-D5。

### FP-B10-SK-04 审核
- **角色权限**：`audit`。
- **规则**：审核抽屉展示基础信息、扫描结果、风险报告；P0 → 〔审核通过〕禁用，接口通过 → 1001；〔驳回〕意见必填 → `REJECTED` 永久；〔退回修改〕（仅 P1/P2）意见必填 → 待修改（Q-D6）；通过 → `PUBLISHED`；审核人 = 提交人 → 1008（Q-D7）；驳回 / 退回给提交人发消息。
- **错误码**：1001、1008、1504。
- **接口**：★ `POST /skill/{id}/audit`。
- **依据**：BR-025；【AIR 规格】P1 §4.2 A-4/5、§7；TC AIR-SKL-04～06。

### FP-B10-SK-05 版本更新
- **规则**：已发布或待修改技能〔编辑〕→ 新版本 `PENDING_AUDIT`；已发布技能新版本过审前，授权仍绑定旧版本，过审后自动切绑；`REJECTED` 技能不可编辑（1001）。
- **接口**：★ `PUT /skill/{id}`。
- **依据**：【AIR 规格】P1 §4.2 C。

### FP-B10-SK-06 停用 / 启用
- **规则**：已发布 → 停用确认 → `DISABLED`，授权记录保留，写事件；停用 → 启用回 `PUBLISHED`。
- **接口**：★ `PUT /skill/{id}/status`。
- **依据**：【AIR 规格】P1 §4.2 D。

### FP-B10-SK-07 授权与收回
- **角色权限**：`grant`。
- **规则**：未过审 →〔授权〕禁用并提示“未过审不得分发”，接口 1001；类型 部门 / 角色 / 人员 + 对象选择器（B2 主数据）+ 有效期（可选）；〔全员可见〕= 根部门授权（Q-D8）；同对象重复授权 → 更新有效期不新增；收回 → `REVOKED`；授权 / 收回写 `ims_air_event`；抽屉下方列出现有授权（对象、类型、状态、有效期，过期显示“已过期”）。
- **错误码**：1001、1500、1501、1504。
- **接口**：★ `POST /skill/grant`、`DELETE /skill/grant/{grantId}`。
- **依据**：SKILL-003；BR-025/031；TC AIR-SKL-07、08；授权 / 收回仅写事件表（Q-D9），BR-024（同步连接器）本批不验收（Q-B1）。

### FP-B10-SK-08 详情
- **规则**：抽屉 60%：基础信息、SKILL.md 只读预览、版本历史（版本、审核状态、风险、审核人、时间）、授权范围。
- **接口**：★ `GET /skill/{id}`。
- **依据**：【AIR 规格】P1 §7；TC AIR-SKL-09。

- **规则**：只读：System Prompt 源码块、技能 chip（编号 + 名称）、知识库 chip（含密级）；固定提示“仅下发组装包，网关不执行模型与技能；本期不返回知识片段”；〔授权管理〕内联切换到授权抽屉。

## 4. 知识库（KB，仅文件管理）

### FP-B10-KB-01 目录树与列表
- **页面线框**：页头〔新增知识库〕〔分类管理〕〔上传资料〕〔从系统转入〕；左树 228px（库名 + 密级 tag → 两级分类）；右侧筛选 关键词、密级、状态、来源；未选库为库粒度表（库编号、名称、分类、密级、文档数、大小、状态、来源、责任人、更新时间、授权、操作），选中库 / 分类后切换为条目粒度表（标题、分类、来源、密级、状态、更新时间、操作）；页面任何位置不出现检索入口，底部提示“本期为文件管理，不做检索与向量化”。
- **接口**：★ `GET /kb/tree`、`GET /kb/page`。
- **依据**：【AIR 规格】P3；FR-AIR-020；TC AIR-KB-01、02、10。

### FP-B10-KB-02 新建知识库
- **规则**：必填 名称（≤128）、密级（四值）、责任人；Provider 固定显示“本地文件目录”只读；新建不审批（Q-D12）。
- **接口**：★ `POST /kb`。
- **依据**：【AIR 规格】P3 §4.2 C、§7；TC AIR-KB-03。

### FP-B10-KB-03 分类管理
- **角色权限**：`category`。
- **规则**：库内至多两级；名称必填 ≤64，同级重名 → 1001；同级排序提交 `orderedIds`；删除空分类直接删，含条目二次确认“该分类下有 N 条知识，删除后条目将改挂根分类”；左树即时刷新。
- **接口**：★ 24～28。
- **依据**：KNOW-005、FR-AIR-017；TC AIR-KB-06。

### FP-B10-KB-04 上传资料（文件 / URL / 粘贴文本）
- **角色权限**：`upload`。
- **规则**：三 Tab 共用：目标库必选、分类可选、密级可选（缺省继承库密级，低于库密级 → 1001）；文件：PDF / DOCX / MD / HTML / Excel，B0a 场景 `air_kb` 单个 ≤50MB【本清单裁定】；URL：按 Q-D13 经安全请求封装抓取（只 http/https、DNS 解析后拒内网 / 回环 / 链路本地 / 元数据地址、每次重定向复检且最多 3 次、10 秒、≤10MB，拒绝 → 1001）；文本：标题 + 正文必填；提交后文档 `PENDING`（入库审批中），toast“已提交，进入入库审批”。
- **错误码**：1001、1504。
- **接口**：★ 21～23；○ 文件上传。
- **依据**：FR-AIR-019；【AIR 规格】P3 §7；TC AIR-KB-07。

### FP-B10-KB-05 从系统转入（4 步向导）
- **规则**：① 来源单选（培训资料 / 绩效考核模板 / 内容记录；未注册源显示“该模块尚未上线”不可选，Q-D10）；② 条目勾选（关键词、分类筛选、全选当页；已转入的显示“已转入”）；③ 目标库 + 分类 + 密级（缺省取源密级）；④ 提交 → `source_type`、`source_ref` 溯源，状态 `PENDING`；未选来源 / 未勾选 → 提示“请先选择来源模块”“请至少勾选 1 条来源条目”；重复按 Q-D14。
- **接口**：★ `GET /kb/transfer-source`、`POST /kb/doc/import-from`。
- **依据**：KNOW-006、FR-AIR-018；TC AIR-KB-08。

### FP-B10-KB-06 入库审批
- **角色权限**：`audit`。
- **规则**：〔审批〕抽屉：库信息 + 待入库文档清单；通过 → `PUBLISHED`（正文写入服务端文件目录）；驳回意见必填 → `DRAFT`，可修改后重提；提交人不能审自己（1008，Q-D7）。
- **接口**：★ `POST /kb/doc/audit`。
- **依据**：KNOW-002；TC AIR-KB-04（文档审批部分）。

### FP-B10-KB-07 条目详情与下载
- **规则**：抽屉：标题、分类、来源（TRAIN / PERF / CONTENT 显示来源模块 tag）、密级、责任人、正文预览（文本 / HTML / MD 在线显示，其他格式提供〔下载〕）；下载经 B0a 文件下载并记操作日志。
- **接口**：○ B0a 文件下载；数据来自 `GET /kb/page` 条目行。
- **依据**：【AIR 规格】P3 §4.2 B、§7；TC AIR-KB-09。

### FP-B10-KB-08 知识库授权
- **规则**：同 SK-07 三维授权与收回；对机密 / 绝密库授权需 `grant-secret`，否则 1008，抽屉提示“机密及以上库授权需专门权限”（Q-D11）。
- **接口**：★ `POST /kb/grant`、`DELETE /kb/grant/{grantId}`。
- **依据**：【AIR 规格】P3 §4.2 C-2、§6 grantsLimit 说明；TC AIR-KB-05。
