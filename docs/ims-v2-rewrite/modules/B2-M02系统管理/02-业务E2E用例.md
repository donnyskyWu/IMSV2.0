## 1. 用户与部门（U）

### E2E-B2-U-01 进入用户页与左树右表联动
- **功能点**：U-01、U-04
- **前置**：`test_admin` 登录。
- **步骤**：1. 侧栏 系统与权限 → 系统管理；2. 点部门树"市场一部"；3. 关闭"含下级"。
- **预期**：1 默认进入"用户"页，左树、右表、页头〔导出〕〔新建用户〕可见；表头含 用户 ID、用户名、姓名、部门、角色、钉钉绑定、手机、状态、最近登录；2 右表只列市场一部及下级人员；3 只列直属人员；手机均为 `138****5678` 形式。

### E2E-B2-U-02 本地新建子部门、改名、移动
- **功能点**：U-02
- **步骤**：1. 市场二部〔更多 → 新增下级〕填"测试小组A"保存；2. 再新增同名；3. 改名"测试小组B"；4. 拖到市场一部下；5. 尝试把市场一部拖到"测试小组B"下。
- **预期**：1 成功，节点来源标"本地"；2 提示"同一上级部门下已有同名部门"；3、4 成功；5 提示"部门不能移动到自身或下级部门之下"。

### E2E-B2-U-03 钉钉部门不能移到本地部门下 / 待分配不可改

- **步骤**：1. 把钉钉部门"行政部"拖到"测试小组B"下；2. 在"待分配"节点打开〔更多〕。
- **预期**：1 被拒，提示 1220 文案；2 无改名 / 移动 / 停用 / 删除项。

### E2E-B2-U-04 有人员的部门不能删除，停用后不可作归属

### E2E-B2-U-05 同步钉钉组织：本地部门不变、钉钉改名被覆盖

- **步骤**：1. 点〔同步钉钉组织〕→ 确认；2. 等待完成。
- **预期**：1 二次确认文案含"本地新建的部门不受影响"；同步中按钮不可点；2 toast 摘要；"市场一部X"恢复为"市场一部"；"测试小组B"仍在。
