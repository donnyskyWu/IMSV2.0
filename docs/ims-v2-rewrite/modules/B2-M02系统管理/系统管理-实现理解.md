#### 0.2.1 接口详细口径（v1.3 产品确认）

**1. `GET /auth/session/my` 响应结构**：
```json
{
  "code": 0,
  "data": {
    "list": [
      {
        "sid": "会话ID",
        "deviceName": "设备名称（如 Chrome/Windows）",
        "ip": "登录IP",
        "loginTime": "2026-10-13T10:00:00Z",
        "lastActiveTime": "2026-10-13T12:30:00Z",
        "current": true  // 当前会话为 true
      }
    ]
  }
}
```

**2. `/me` 扩展 UserInfo**（本 PR 新增字段）：
```typescript
interface UserInfo {
  // ... 现有字段 ...
  mobileMasked: string | null;  // 脱敏手机号，如 "138****1234"，无手机号时为 null
  roleNames: string[];          // 角色名称列表，如 ["租户管理员", "财务"]
}
```

**3. `POST /auth/password/set` 口径**（v1.6：复用 `AuthService.change_password`，不用 `_drop_sessions`）：
- 请求体只接受 `newPassword` 字段
- **静默忽略**：`roleIds`、`tenantId`、`status`、`deptId` 等字段一律忽略，不报错也不修改
- 成功后复用 `AuthService.change_password(user_id, new_password, keep_session_id=ctx.session_id)`：
  - 写入新密码哈希（bcrypt rounds=10）
  - 清除 `pwd_reset_required` 标记
  - **保留当前会话**（`keep_session_id` 参数），其他会话写入 `TOKEN_BLACKLIST_PREFIX`
- 测试须断言：
  - 请求夹带 `roleIds` 等字段时，数据库中对应值未变
  - **当前 token 可用**，其他 token 返回 1002

**4. `DELETE /auth/session/my?sid=` 口径**：
| 场景 | 返回码 | 说明 |
|------|--------|------|
| sid 为空 | 1001 | 参数校验失败 |
| 会话不存在 | 1504 | 统一返回，不泄露存在性 |
| 会话属于其他用户 | 1504 | 统一返回，不泄露存在性 |
| 删除当前会话 | 0 | 等同退出登录，返回成功 |
| 删除其他会话 | 0 | 正常下线 |

### 1.5 【小黑-5】Q1 `/me` 祖先目录补全

**要求**：`/me` 由后端补祖先目录；B1 的 visibleMenus 按 `/me` 返回的树原样过滤，前端不要再补祖先目录。

**实现方式**：

1. **后端 `_build_user_menu_tree` 重写**（修改 `app/services/auth.py` 的 `AuthService` 类）：

```python
async def _build_user_menu_tree(self, user_id: int, tenant_id: int) -> list[dict]:
    """Menu tree = tenant package menus ∩ enabled role menus，自动补祖先目录。
    
    规则（Q1 已决策）：
    - 一次查出全部菜单，内存中补祖先（无 N+1）
    - 任一祖先 visible=0 或 status!=ENABLED 则整枝剔除
    - 不带出同目录下未授权的兄弟菜单
    """
    from app.domains.sys.models import Menu, Role, RoleMenu, Tenant, TenantPackageMenu, UserRole
    session = get_db_session()
    
    # 1. 获取用户角色授权的菜单 ID
    role_ids = [
        row.role_id for row in session.query(UserRole).join(
            Role, Role.id == UserRole.role_id
        ).filter(
            UserRole.user_id == user_id,
            Role.status == "ENABLED",
            Role.deleted == 0,
        ).all()
    ]
    if not role_ids:
        return []
    
    role_menu_ids = {
        row.menu_id for row in session.query(RoleMenu).filter(
            RoleMenu.role_id.in_(role_ids)
        ).all()
    }
    
    # 2. 与租户套餐取交集
    tenant = session.query(Tenant).filter(Tenant.id == tenant_id).first()
    if tenant is not None and tenant.package_id:
        package_ids = {
            row.menu_id for row in session.query(TenantPackageMenu).filter(
                TenantPackageMenu.package_id == tenant.package_id
            ).all()
        }
        role_menu_ids &= package_ids
    
    if not role_menu_ids:
        return []
    
    # 3. 一次查出全部菜单（含目录），用于补祖先
    all_menus = session.query(Menu).filter(
        Menu.deleted == 0,
    ).all()
    menu_map = {m.id: m for m in all_menus}
    
    # 4. 收集授权菜单的全部祖先 ID
    def get_ancestors(menu_id: int) -> set[int]:
        ancestors = set()
        current = menu_map.get(menu_id)
        while current and current.parent_id:
            parent = menu_map.get(current.parent_id)
            if parent:
                ancestors.add(parent.id)
                current = parent
            else:
                break
        return ancestors
    
    all_needed_ids = set(role_menu_ids)
    for menu_id in role_menu_ids:
        all_needed_ids |= get_ancestors(menu_id)
    
    # 5. 过滤：visible=0 或 status!=ENABLED 的节点及其子树剔除
    def is_visible_chain(menu_id: int) -> bool:
        """从叶子到根，任一节点不可见则返回 False"""
        current = menu_map.get(menu_id)
        while current:
            if not current.visible or current.status != "ENABLED":
                return False
            if not current.parent_id:
                break
            current = menu_map.get(current.parent_id)
        return True
    
    visible_ids = {mid for mid in all_needed_ids if is_visible_chain(mid)}
    
    # 6. 构建树（只取 DIR 和 MENU，BUTTON 在 perm_codes）
    menus = [
        menu_map[mid] for mid in visible_ids
        if mid in menu_map and menu_map[mid].type in ("DIR", "MENU")
    ]
    
    return _nest_menu_tree(menus)
```

### 1.10 【小红-10】Q3 新租户

**要求**：初始管理员复制 R1 权限，之后改 R1 不影响已有租户；租户间角色、字典、用户互不可见，越权返回 1504。

**实现方式**（v1.5 技术复核：RolePermDetail 按套餐菜单过滤、perm_code 映射、tenant_id 说明、platform_r1 空返回 1001、复用 ensure_tenant_bootstrap、套餐新增同步 RoleMenu + RolePermDetail）：

1. **新建租户（同一事务）**：
   
   > **v1.6 说明**：新建租户时必须显式写 `tenant_id`，因为此时操作者在平台租户上下文（`ctx.tenant_id=1`），而新建的角色、部门、用户等数据应属于新租户（`tenant.id`）。中间件按 `ctx.tenant_id` 填充只适用于当前租户内的增删改，不适用于跨租户创建数据。
   
   ```python
   @transactional
   async def create_tenant(self, request) -> dict:
       session = get_db_session()
       
       # 1. 创建租户（tenant 表本身不需要 tenant_id 列，直接 add）
       tenant = Tenant(
           name=request.name,
           contact_name=request.contact_name,
           contact_mobile_enc=encrypt(request.contact_mobile),
           package_id=request.package_id,
           expire_time=request.expire_time,
           status="ENABLED",
       )
       session.add(tenant)
       session.flush()  # 获取 tenant.id
       
       # 2. 创建根部门和"待分配"部门
       # v1.6 阻塞修正：ensure_tenant_bootstrap(self) 按 ctx.tenant_id 工作
       # 方案：给 ensure_tenant_bootstrap 加可选参数 tenant_id，传入时用参数值而非 ctx.tenant_id
       # 这样可以在平台租户上下文中为新租户建部门，避免给平台租户重复建部门
       from app.services.dept import DeptService
       DeptService.ensure_tenant_bootstrap(session, tenant_id=tenant.id)
       # 单测：UT-B2-T-02-07（新建租户时不给平台租户建部门）
       
       # 3. 复制平台 R1 的菜单和功能点权限
       platform_r1 = session.query(Role).filter(
           Role.tenant_id == 1,
           Role.role_key == "R1",
           Role.deleted == 0,
       ).first()
       
       # v1.5：platform_r1 为空时返回 1001（平台初始化异常）
       if platform_r1 is None:
           raise BizError(1001, "平台租户管理员角色不存在，请检查初始化数据")
       
       # Q3 产品口径：data_scope 固定为 ALL（不从平台 R1 复制）
       new_r1 = Role(
           tenant_id=tenant.id,
           role_key="R1",
           name="租户管理员",
           status="ENABLED",
           source="MANUAL",
           data_scope="ALL",  # 固定为 ALL
       )
       session.add(new_r1)
       session.flush()
       
       # Q3 产品口径：菜单和功能点取 R1 与新租户套餐的交集
       # v1.5：RolePermDetail 按套餐菜单列表过滤
       package_menu_ids = {
           row.menu_id for row in session.query(TenantPackageMenu).filter(
               TenantPackageMenu.package_id == request.package_id
           ).all()
       }
       
       # 获取套餐菜单对应的 perm_code（用于过滤 RolePermDetail）
       package_menus = session.query(Menu).filter(Menu.id.in_(package_menu_ids)).all()
       package_perm_codes = {m.perm_code for m in package_menus if m.perm_code}
       
       # 复制 RoleMenu（只复制 R1 菜单 ∩ 套餐菜单）
       # v1.5：RoleMenu 和 RolePermDetail 的 tenant_id 都填新租户 ID，用于数据隔离
       copied_menu_ids = set()
       for rm in session.query(RoleMenu).filter(RoleMenu.role_id == platform_r1.id).all():
           if rm.menu_id in package_menu_ids:
               session.add(RoleMenu(tenant_id=tenant.id, role_id=new_r1.id, menu_id=rm.menu_id))
               copied_menu_ids.add(rm.menu_id)
       
       # 复制 RolePermDetail（只复制交集内菜单关联的功能点）
       # v1.5：main 的 RolePermDetail 字段是 perm_code/r/w/d
       # perm_code 与菜单关联：perm_code 前缀对应菜单 perm_code（如 ims:system:user:query 属于 ims:system:user）
       for rpd in session.query(RolePermDetail).filter(RolePermDetail.role_id == platform_r1.id).all():
           # 检查 perm_code 是否属于套餐菜单（前缀匹配）
           perm_code_prefix = ':'.join(rpd.perm_code.split(':')[:-1]) if rpd.perm_code else ''
           if perm_code_prefix in package_perm_codes or rpd.perm_code in package_perm_codes:
               session.add(RolePermDetail(
                   tenant_id=tenant.id,  # v1.5：填新租户 ID
                   role_id=new_r1.id,
                   perm_code=rpd.perm_code,
                   r=rpd.r,
                   w=rpd.w,
                   d=rpd.d,
               ))
       
       session.flush()
       
       # 4. 创建初始管理员
       temp_password = secrets.token_urlsafe(10)
       admin = User(
           tenant_id=tenant.id,
           username=request.admin_username,
           nickname=request.admin_username,
           password_hash=hash_password(temp_password),
           status="ACTIVE",
           source="LOCAL",
           pwd_reset_required=True,
       )
       session.add(admin)
       session.flush()
       
       # 分配 R1
       session.add(UserRole(tenant_id=tenant.id, user_id=admin.id, role_id=new_r1.id, source="MANUAL"))
       
       # 分配到根部门
       root_dept = session.query(Dept).filter(
           Dept.tenant_id == tenant.id, Dept.parent_id == 0
       ).first()
       session.add(UserDept(tenant_id=tenant.id, user_id=admin.id, dept_id=root_dept.id, is_main=True))
       
       tenant.admin_user_id = admin.id
       session.flush()
       
       return {"tenant_id": tenant.id, "admin_password": temp_password}
   ```

2. **租户隔离**（按 01 清单）：
   - 数据范围由中间件执行，代码不手写 `tenant_id` 条件
   - 字典全平台共用（`tenant_id=1`），非平台租户只读
   - 菜单页和租户页只有平台租户可见，其他租户返回 1008

3. **套餐新增菜单/功能点同步到租户 R1**（v1.5：同步 RoleMenu + RolePermDetail）：
   - **场景**：平台修改套餐，新增菜单或功能点
   - **实现**：`update_tenant_package` 时，将新增的菜单和对应功能点同步补进使用该套餐的全部租户的 R1
   - **效果**：初始管理员刷新后就能看到新菜单
   ```python
   async def update_tenant_package(self, package_id: int, request) -> None:
       # ... 更新套餐菜单 ...
       
       # v1.5：新增的菜单和功能点同步到使用该套餐的租户 R1
       new_menu_ids = set(request.menu_ids) - set(old_menu_ids)
       if new_menu_ids:
           # 获取新增菜单的 perm_code
           new_menus = session.query(Menu).filter(Menu.id.in_(new_menu_ids)).all()
           new_perm_codes = {m.perm_code for m in new_menus if m.perm_code}
           
           # 获取平台 R1 的对应功能点权限
           platform_r1 = session.query(Role).filter(
               Role.tenant_id == 1, Role.role_key == "R1", Role.deleted == 0
           ).first()
           platform_perm_details = []
           if platform_r1:
               for rpd in session.query(RolePermDetail).filter(
                   RolePermDetail.role_id == platform_r1.id
               ).all():
                   perm_prefix = ':'.join(rpd.perm_code.split(':')[:-1]) if rpd.perm_code else ''
                   if perm_prefix in new_perm_codes or rpd.perm_code in new_perm_codes:
                       platform_perm_details.append(rpd)
           
           tenant_ids = [t.id for t in session.query(Tenant).filter(Tenant.package_id == package_id).all()]
           for tenant_id in tenant_ids:
               r1 = session.query(Role).filter(
                   Role.tenant_id == tenant_id,
                   Role.role_key == "R1",
                   Role.deleted == 0,
               ).first()
               if r1:
                   # 同步 RoleMenu
                   for menu_id in new_menu_ids:
                       if not session.query(RoleMenu).filter(
                           RoleMenu.role_id == r1.id, RoleMenu.menu_id == menu_id
                       ).first():
                           session.add(RoleMenu(tenant_id=tenant_id, role_id=r1.id, menu_id=menu_id))
                   
                   # v1.5：同步 RolePermDetail
                   for rpd in platform_perm_details:
                       if not session.query(RolePermDetail).filter(
                           RolePermDetail.role_id == r1.id, RolePermDetail.perm_code == rpd.perm_code
                       ).first():
                           session.add(RolePermDetail(
                               tenant_id=tenant_id, role_id=r1.id,
                               perm_code=rpd.perm_code, r=rpd.r, w=rpd.w, d=rpd.d
                           ))
           
           # 触发权限版本更新（v1.5：递增 Redis perm_version）
           for tenant_id in tenant_ids:
               Cache.incr(f"ims:perm_ver:t:{tenant_id}")
   ```
