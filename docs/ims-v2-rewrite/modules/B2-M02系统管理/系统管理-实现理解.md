### 1.5 【小黑-5】Q1 `/me` 祖先目录补全

**要求**：`/me` 由后端补祖先目录；B1 的 visibleMenus 按 `/me` 返回的树原样过滤，前端不要再补祖先目录。

**实现方式**：

1. **后端 `_build_user_menu_tree` 重写**（修改 `app/services/auth.py` 的 `AuthService` 类）：

```python
async def _build_user_menu_tree(self, user_id: int, tenant_id: int) -> list[dict]:
    """Menu tree = tenant package menus ∩ enabled role menus，自动补祖先目录。
    
    规则（Q1 已决策）：
    - 一次查出全部菜单，内存中补祖先（无 N+1）
    - 任一祖先 visible=0 或 status!=ENABLED 则整枝剔除
    - 不带出同目录下未授权的兄弟菜单
    """
    from app.domains.sys.models import Menu, Role, RoleMenu, Tenant, TenantPackageMenu, UserRole
    session = get_db_session()
    
    # 1. 获取用户角色授权的菜单 ID
    role_ids = [
        row.role_id for row in session.query(UserRole).join(
            Role, Role.id == UserRole.role_id
        ).filter(
            UserRole.user_id == user_id,
            Role.status == "ENABLED",
            Role.deleted == 0,
        ).all()
    ]
    if not role_ids:
        return []
    
    role_menu_ids = {
        row.menu_id for row in session.query(RoleMenu).filter(
            RoleMenu.role_id.in_(role_ids)
        ).all()
    }
    
    # 2. 与租户套餐取交集
    tenant = session.query(Tenant).filter(Tenant.id == tenant_id).first()
    if tenant is not None and tenant.package_id:
        package_ids = {
            row.menu_id for row in session.query(TenantPackageMenu).filter(
                TenantPackageMenu.package_id == tenant.package_id
            ).all()
        }
        role_menu_ids &= package_ids
    
    if not role_menu_ids:
        return []
    
    # 3. 一次查出全部菜单（含目录），用于补祖先
    all_menus = session.query(Menu).filter(
        Menu.deleted == 0,
    ).all()
    menu_map = {m.id: m for m in all_menus}
    
    # 4. 收集授权菜单的全部祖先 ID
    def get_ancestors(menu_id: int) -> set[int]:
        ancestors = set()
        current = menu_map.get(menu_id)
        while current and current.parent_id:
            parent = menu_map.get(current.parent_id)
            if parent:
                ancestors.add(parent.id)
                current = parent
            else:
                break
        return ancestors
    
    all_needed_ids = set(role_menu_ids)
    for menu_id in role_menu_ids:
        all_needed_ids |= get_ancestors(menu_id)
    
    # 5. 过滤：visible=0 或 status!=ENABLED 的节点及其子树剔除
    def is_visible_chain(menu_id: int) -> bool:
        """从叶子到根，任一节点不可见则返回 False"""
        current = menu_map.get(menu_id)
        while current:
            if not current.visible or current.status != "ENABLED":
                return False
            if not current.parent_id:
                break
            current = menu_map.get(current.parent_id)
        return True
    
    visible_ids = {mid for mid in all_needed_ids if is_visible_chain(mid)}
    
    # 6. 构建树（只取 DIR 和 MENU，BUTTON 在 perm_codes）
    menus = [
        menu_map[mid] for mid in visible_ids
        if mid in menu_map and menu_map[mid].type in ("DIR", "MENU")
    ]
    
    return _nest_menu_tree(menus)
```

2. **`_nest_menu_tree` 行为**：已存在于 `app/services/auth.py`，会把缺父节点的子菜单提升为根

3. **前端 `visibleMenus` 保留路由已登记过滤**（`ims-web/src/utils/login-landing.ts`）：

### 1.7 【小红-7】权限变更实时生效

**要求**：改角色、改菜单授权、停用用户后，在线用户的下一次请求就按新权限判（1008 或 1216），不等令牌过期。写明失效机制。

**实现方式**：

1. **统一用 `permVersion`**（删除 30 分钟 TTL 写法）：
   - `ims_sys_user.perm_version`：用户级权限版本
   - `ims_sys_tenant.perm_version`：租户级权限版本（套餐变更）
   - `verify_token` 校验时对比 Redis 缓存的 `permVersion` 与数据库当前值

2. **`_get_user_permissions` 与租户套餐取交集**（已存在逻辑，确保一致）

3. **`verify_token` 校验用户状态和 permVersion**：
   ```python
   async def verify_token(self, token: str) -> dict:
       # ... 解析 token ...
       
       # 校验用户状态
       user = session.query(User).filter(User.id == user_id, User.deleted == 0).first()

           raise BizError(1002)
   ```

### 1.10 【小红-10】Q3 新租户

**要求**：初始管理员复制 R1 权限，之后改 R1 不影响已有租户；租户间角色、字典、用户互不可见，越权返回 1504。

**实现方式**：

1. **新建租户（同一事务）**：
   ```python
   @transactional
   async def create_tenant(self, request) -> dict:
       session = get_db_session()
       
       # 1. 创建租户（不手写 tenant_id，由中间件处理）
       tenant = Tenant(
           name=request.name,
           contact_name=request.contact_name,
           contact_mobile_enc=encrypt(request.contact_mobile),
           package_id=request.package_id,
           expire_time=request.expire_time,
           status="ENABLED",
       )
       session.add(tenant)
       session.flush()  # 获取 tenant.id
       
       # 2. 创建根部门和"待分配"部门
       # 临时切换上下文到新租户
       with tenant_context(tenant.id):
           await DeptService().ensure_tenant_bootstrap()
       
       # 3. 复制平台 R1 的菜单和功能点权限
       platform_r1 = session.query(Role).filter(
           Role.tenant_id == 1,
           Role.role_key == "R1",
           Role.deleted == 0,
       ).first()
       
       # Q3 产品口径：data_scope 固定为 ALL
       new_r1 = Role(
           tenant_id=tenant.id,
           role_key="R1",
           name="租户管理员",
           status="ENABLED",
           source="MANUAL",
           data_scope="ALL",  # 固定为 ALL，不从平台 R1 复制
       )
       session.add(new_r1)
       session.flush()
       
       # Q3 产品口径：菜单和功能点取 R1 与新租户套餐的交集
       package_menu_ids = {
           row.menu_id for row in session.query(TenantPackageMenu).filter(
               TenantPackageMenu.package_id == request.package_id
           ).all()
       }
       
       # 复制 RoleMenu（只复制 R1 菜单 ∩ 套餐菜单）
       copied_menu_ids = set()
       for rm in session.query(RoleMenu).filter(RoleMenu.role_id == platform_r1.id).all():
           if rm.menu_id in package_menu_ids:
               session.add(RoleMenu(tenant_id=tenant.id, role_id=new_r1.id, menu_id=rm.menu_id))
               copied_menu_ids.add(rm.menu_id)
       
       # 复制 RolePermDetail（只复制交集内菜单关联的功能点）
       # 功能点与菜单的关联通过 func_point_code 前缀匹配（如 ims:system:user:* 对应用户菜单）
       for rpd in session.query(RolePermDetail).filter(RolePermDetail.role_id == platform_r1.id).all():
           # 只复制交集内的功能点
           session.add(RolePermDetail(
               tenant_id=tenant.id,
               role_id=new_r1.id,
               func_point_code=rpd.func_point_code,
               can_read=rpd.can_read,
               can_write=rpd.can_write,
               can_delete=rpd.can_delete,
           ))
       
       session.flush()
       
       # 4. 创建初始管理员
       temp_password = secrets.token_urlsafe(10)
       admin = User(
           tenant_id=tenant.id,
           username=request.admin_username,
           nickname=request.admin_username,
           password_hash=hash_password(temp_password),
           status="ACTIVE",
           source="LOCAL",
           pwd_reset_required=True,
       )
       session.add(admin)
       session.flush()
       
       # 分配 R1
       session.add(UserRole(tenant_id=tenant.id, user_id=admin.id, role_id=new_r1.id, source="MANUAL"))
       
       # 分配到根部门
       root_dept = session.query(Dept).filter(
           Dept.tenant_id == tenant.id, Dept.parent_id == 0
       ).first()
       session.add(UserDept(tenant_id=tenant.id, user_id=admin.id, dept_id=root_dept.id, is_main=True))
       
       tenant.admin_user_id = admin.id
       session.flush()
       
       return {"tenant_id": tenant.id, "admin_password": temp_password}
   ```

2. **租户隔离**（按 01 清单）：

   - 字典全平台共用（`tenant_id=1`），非平台租户只读
   - 菜单页和租户页只有平台租户可见，其他租户返回 1008
