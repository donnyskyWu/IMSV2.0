## 1. 边界

### 2.1 改密与设置密码：只作废其他会话

两条都复用 main 上已有的 `AuthService.change_password(user_id, new_password, keep_session_id)`，传入当前会话 id。成功后：

- 当前 token 仍然有效
- 其他 token 返回 **1002**
- `pwd_reset_required` 清掉

不要用用户级 `token_version += 1` 把当前会话一起判死。main 上这个函数现在在删其他会话的同时给 `user.token_version` 加 1。#26 v1.3 的 UT-B2-PC-03-01 也写成 `token_version += 1`。#26 还计划在 `verify_token` 里比对用户级 `token_version`，那样加 1 会让当前 token 也变成 1002。设密和改密不走这一下，只按 `keep_session_id` 作废其他会话。

测试（用例名，不写行号）：

- 已有：`TestPasswordChange.test_current_session_survives_password_change`、`TestPasswordResetGate.test_change_endpoint_requires_user_and_keeps_session`、`test_real_lock_freeze_and_password_change`
- 规则与 1214 / 1001：`TestPasswordChange.test_rules_and_persistence`。旧密码也错且新密码过短时，现码先 1214，不改这个顺序
- 设密成功：UT-B2-PC-03-01 断言当前 token 仍成功、其他 token 为 1002、`pwd_reset_required=0`。不断言 `token_version` 增加

### 2.2 只接受允许字段

| 接口 | 允许字段 |
|---|---|
| `POST /auth/password/change` | `oldPassword`、`newPassword` |
| `POST /auth/password/set` | `newPassword` |

`roleIds`、`tenantId`、`status`、`deptId` 静默忽略，返回成功，不因这些键返回 1001。PC-01 没有更新资料接口。

测试：UT-B2-PC-03-03 夹带 `roleIds`，`user_role` 不变；UT-B2-PC-03-04 夹带 `tenantId` / `status` / `deptId`，对应用户列不变。改密请求同样忽略，用请求之外的连接查库。

### 2.3 逻辑删除、冻结、离职

不新造错误码。实时权限用 `permVersion`（B0a FP-D03-04）。

| 情形 | 结果 | 用例名 |
|---|---|---|
| 管理员删除用户（逻辑删除）。#26 写的「停用用户」就是这一条 | 会话作废，旧 token **1002** | E2E-B2-U-10a、UT-B2-BG-07-02a |
| 冻结或离职 | 旧 token **1216** | E2E-B2-U-10b、E2E-B2-U-10c、UT-B2-BG-07-02b、UT-B2-BG-07-02c |
| 权限变化（角色、菜单、套餐） | 下一次请求 **1008** 或 **1216** | 沿用 #26 的角色 / 套餐用例名 |
| 改密、设密作废的其他会话，或下线他人会话 | **1002** | E2E-B2-PC-03、UT-B2-PC-04-06 |

E2E 断言响应码，并断言旧 token 再请求被拒绝。个人中心不实现删除用户。

### 2.5 钉钉设置密码

扫码与免登已在 main（#20，`6ce0a0c`）：`login-options`、`sso/dingtalk/authorize-params`、`sso/dingtalk/callback`、`sso/dingtalk/h5-login`，实现在 `ims-backend/app/services/dingtalk_login.py`。

`password_hash` 为空时显示「设置密码」，没有当前密码。成功后可账号密码登录，并按 §2.1 保留当前会话、作废其他会话。

E2E-B2-PC-02 需要种子「钉钉甲」。实现时改已有 `ims-backend/tools/seed/users.py`：`password_hash` 为空，能被扫码登录命中。本提交不改种子。

## 5. 与 #26 v1.3 仍不一致

行为以本文为准。

1. #26 §0.2.1 和 UT-B2-PC-03-01 写设置密码 `token_version += 1`。本文要求复用 `change_password` 的 `keep_session_id`，当前 token 保持有效，不用用户级 `token_version` 把当前会话判死。
2. #26 §1.7 的「停用用户（U-09）」按产品口径改称管理员逻辑删除，返回 1002。冻结、离职返回 1216。
3. 顶栏。#26 早期写过不存在的 `ims-frontend/src/layouts/AppLayout.vue`。v1.3 已改为 `ims-web/src/components/layout/AppLayout.vue`，入口仍归 #26。
4. #26 把部分 E2E 放在 `ims-web/tests/b2-system/`。本线三条放在已有目录 `ims-web/tests/b2-profile.spec.ts`。#26 写的 `ims-web/.eslintrc.cjs` 不存在，现文件是 `ims-web/eslint.config.js`。本线不新增 lint 规则。
5. P0 门禁是 `ims-backend/scripts/check_p0_branch_coverage.py`。不引用不存在的 `scripts/coverage_check.py`、`scripts/check_empty_tests.py`。
