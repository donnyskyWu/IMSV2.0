## 1. 边界

本线做 `/profile` 页内三个 Tab（基本信息、修改密码 / 设置密码、我的会话）和 E2E-B2-PC-01～03。权限 `LOGIN_ONLY`，不设权限码。

顶栏头像下拉〔个人中心〕〔退出登录〕归 **#26**（产品裁定）。本线不改 `ims-web/src/components/layout/AppLayout.vue`。E2E-B2-PC-01 步骤 1 的下拉点击依赖 #26 把〔个人中心〕链到 `/profile`；页内断言直接打开 `/profile`。

`POST /admin-api/ims/auth/password/set`、`GET /admin-api/ims/auth/session/my`、`DELETE /admin-api/ims/auth/session/my?sid=` 的后端按 #26 §2.9 由 #26 实现。本线只调用。不第二套改密。`/me` 的 `mobileMasked`、`roleNames` 也由 #26 加到 `UserInfo`。

须改密时路由守卫仍把 `/profile` 带回 `/password-reset`（B0b FP-R-04）。强制改密只走已有 `ims-web/src/views/ChangePassword.vue`。

### 2.1 改密与设置密码

`AuthService.change_own_password`（#16，不改顺序，不并行实现）：用户不存在 1002；旧密码不匹配（空哈希也算）**1214**；新密码过短、含空格、缺字母或数字、或与当前密码相同 **1001**。旧密码也错且新密码过短时，现码先 1214。

`password/change` 与 `password/set` 成功后的会话语义与 #16 相同：其他会话作废，当前会话保留，`pwd_reset_required` 清掉。被作废的会话下一次请求 **1002**。

### 2.2 只接受允许字段

| 接口 | 允许字段 |
|---|---|
| `POST /auth/password/change` | `oldPassword`、`newPassword` |
| `POST /auth/password/set` | `newPassword` |

请求里的 `roleIds`、`tenantId`、`status`、`deptId` 静默忽略。允许字段照常保存，返回成功，不因这些键返回 1001。PC-01 没有更新接口。测试用请求之外的连接查库，这四列以及角色、部门归属与保存前一致。

### 2.3 权限、停用、冻结

不新造错误码。实时权限仍用 `permVersion`（B0a FP-D03-04）：Redis `ims:perm:<userId>:<permVersion>`，变更时 `permVersion+1`（大批量用 `tenantPermVersion+1`）。

| 情形 | 结果 |
|---|---|
| 权限变化（角色、菜单、套餐） | 下一次请求 **1008** 或 **1216** |
| 停用：会话作废 | 旧 token **1002** |
| 冻结或离职 | 旧 token **1216** |
| 改密 / 设置密码作废的其他会话、下线他人会话 | **1002** |

E2E 断言响应码，并断言旧 token 再请求被拒绝。个人中心不改权限，只消费这个结果。

### 2.4 我的会话

`GET` 返回上面六个字段，没有 `loginMethod`。`current` 表示这条是当前令牌的会话。

`DELETE`：

| 情形 | 结果 |
|---|---|
| `sid` 是当前会话 | 与退出登录相同，成功（`code=0`），当前会话结束 |
| `sid` 为空 | **1001** |
| `sid` 不存在 | **1504** |
| `sid` 属于别人 | **1504**（UT-B2-PC-04-01）。响应不含对方身份 |

非当前会话下线后，那个窗口的旧 token 得 **1002**，E2E-B2-PC-03 表现为回登录页。

### 2.5 钉钉设置密码

main 已含 #20（`6ce0a0c`）。扫码与免登：

- `GET /admin-api/ims/auth/login-options`
- `GET /admin-api/ims/auth/sso/dingtalk/authorize-params`
- `GET /admin-api/ims/auth/sso/dingtalk/callback`
- `POST /admin-api/ims/auth/sso/dingtalk/h5-login`

实现在 `ims-backend/app/services/dingtalk_login.py`。`password_hash` 为空时 Tab 显示「设置密码」，无当前密码项。设置成功后可用账号密码登录，并按 §2.1 作废其他会话、清 `pwd_reset_required`。

E2E-B2-PC-02 用种子用户「钉钉甲」。该账号今天不在 `ims-backend/tools/seed/users.py`，实现时加进这个已有文件（见 §3），本提交不改种子。
