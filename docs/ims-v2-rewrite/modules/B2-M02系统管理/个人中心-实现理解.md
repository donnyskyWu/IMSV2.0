### 2.1 改密与设置密码：只作废其他会话

两条都复用 main 上已有的 `AuthService.change_password(user_id, new_password, keep_session_id)`，传入当前会话 id。成功后：

- 当前 token 仍然有效
- 其他 token 返回 **1002**
- `pwd_reset_required` 清掉

作废会话只做三件事：删会话键 `ims:session:<sid>`、写入 `ims:token_blacklist:<sid>`、从 `ims:user_sessions:<userId>` 移除。不用 `token_version`。

main 上 `change_password` 现在还会给 `user.token_version` 加 1。这一行由 #26 从 `ims-backend/app/services/auth.py` 去掉。本线依赖 #26 合入后再写设密和改密的会话断言，本线的改动清单不含 `auth.py`。

测试（用例名，不写行号）：

- 已有：`TestPasswordChange.test_current_session_survives_password_change`、`TestPasswordResetGate.test_change_endpoint_requires_user_and_keeps_session`、`test_real_lock_freeze_and_password_change`
- 规则与 1214 / 1001：`TestPasswordChange.test_rules_and_persistence`。旧密码也错且新密码过短时，现码先 1214，不改这个顺序
- 设密成功：UT-B2-PC-03-01 断言当前 token 仍成功、其他 token 为 1002、`pwd_reset_required=0`。不断言 `token_version` 增加

### 2.3 删除、冻结、离职与权限

用户状态只有三种：`ACTIVE`、`FROZEN`、`RESIGNED`。删除是操作，不是状态。

删除规则（main 上 `UserService.delete_user` 已按此实现，会话清理补上 `_drop_sessions`）：只有从未登录的用户可删除（`last_login_time` 为空）。写入 `deleted = user.id`，并调用 `UserService._drop_sessions`。已删除用户的旧 token 返回 **1002**。个人中心不实现删除用户。

`perm_version` 放在 Redis（B0a 键 `ims:perm:<userId>:<permVersion>`，大批量用租户级 `tenantPermVersion`）。不进数据库列，不进 JWT。权限变化后下一次请求返回 **1008**。冻结、离职返回 **1216**。

会话缺失或已在黑名单时，先按 JWT 的 `sub` 查用户，再决定错误码：

| 查到的情况 | 结果 |
|---|---|
| `deleted <> 0`，或没有这个用户 | **1002** |
| `deleted = 0` 且状态为 `FROZEN` 或 `RESIGNED` | **1216** |
| 其余（含在职用户的会话已被删掉） | **1002** |

| 情形 | 结果 | 用例名 |
|---|---|---|
| 管理员删除用户（逻辑删除，不是状态） | 旧 token **1002** | E2E-B2-U-15、UT-B2-BG-07-02 |
| 冻结 | 旧 token **1216** | E2E-B2-U-10、UT-B2-BG-07-03 |
| 离职 | 旧 token **1216** | E2E-B2-U-14、UT-B2-BG-07-04 |
| 权限变化（角色、菜单、套餐） | 下一次请求 **1008** | 沿用 #26 的角色 / 套餐用例名 |
| 改密、设密作废的其他会话，或下线他人会话 | **1002** | E2E-B2-PC-03、UT-B2-PC-04-06 |

E2E 断言响应码，并断言旧 token 再请求被拒绝。

### 2.4 我的会话

`GET` 的 `data.list` 只有六个字段：`sid`、`deviceName`、`ip`、`loginTime`、`lastActiveTime`、`current`。页面不显示登录方式。最多 3 条，沿用 main `AuthService.MAX_SESSIONS = 3`：登录时挤掉最旧的一条。个人中心不再做第二套上限。

`DELETE`：

| 情形 | 结果 | 用例名 |
|---|---|---|
| `sid` 为空 | **1001** | UT-B2-PC-04-02 |
| 会话不存在 | **1504** | UT-B2-PC-04-03 |
| 会话属于别人 | **1504** | UT-B2-PC-04-04 |
| 当前会话 | **code 0**，与退出相同 | UT-B2-PC-04-05 |
| 其他会话 | **code 0**，该会话失效，其 token **1002** | UT-B2-PC-04-06、E2E-B2-PC-03 |

02 里「窗口 2 刷新」这一步允许 `page.reload()`。刷新只用于这一步，不能拿来代替等待。其余等待用断言。不用 `waitForTimeout` / `sleep`，不靠加大超时或 `retries` 变绿。

## 5. 与已读取的 #26 正文（`cbb7938`，文件头 v1.4）仍不一致
