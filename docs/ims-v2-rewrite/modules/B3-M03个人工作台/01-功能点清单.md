## 1. 工作台首页（WB）

### FP-B3-WB-01 菜单、路由与登录落地
- **入口**：侧栏“个人工作台”；登录成功默认落地。
- **角色权限**：`ims:workbench:query`。
- **规则**：
  1. 前端注册 `/ims/workbench`、`/ims/workbench/todos`、`/ims/workbench/messages`；后两者 `meta.menuless`，不进侧栏，面包屑“个人工作台 / 待办中心（消息中心）”。
  2. 侧栏只渲染“我的菜单树”且过滤未注册路由（B0b）；本批注册后 R10 的 `/me` 返回工作台节点，侧栏显示且只显示该项（B1 LG-10）。
  3. 登录落地按 B1 LG-08：redirect（在菜单树中）→ `/ims/workbench` → 第一个菜单 → 无权限提示；本批起第 ② 步生效。
  4. 菜单名称改“个人工作台”，根级，排序 0（Q8）。
- **错误码**：无菜单直接访问 → 无权限页（前端），接口 1008。
- **依据**：【AUTH 规格】0、P4.1；B1 LG-08、LG-10；B0a 种子 `menus.py`；TC WB-NAV-01。

### FP-B3-WB-02 问候区与摘要
- **页面线框**：`早上好，{姓名}（{主部门}·{角色}）  [消息 icon+红点]`。
- **规则**：问候按北京时间（5–11 早上 / 11–13 中午 / 13–18 下午 / 其余晚上）；多角色时显示角色名用“、”连接；数据取 `/me` 与 dashboard。
- **接口**：★ `GET /auth/workbench/dashboard` → `{todoCount, unreadMessageCount, myAccountCount, myAssetCount, myCertCount, myCertWarningCount, myLiveSessionCount}`。
- **依据**：【AUTH 规格】P4 §2、§3；【AUTH 契约】2.4.1。**须核实**：问候时段划分原型未给，按上述实现，评审可改。

### FP-B3-WB-03 数据卡片
- **规则**：一行最多 4 卡，本批只显示“待办事项”“未读消息”两卡；`myAccountCount` 等字段返回 `null`，前端 `null` 不渲染（Q4）；卡片点击：待办 → 待办中心，消息 → 消息中心；各区独立加载失败“加载失败，重试”。
- **依据**：【AUTH 规格】P4 §4.1、§4.2 B、§8；00 Q4。

### FP-B3-WB-04 待办预览卡（左 60%）
- **规则**：Tab 全部 / 审批 / 归还 / 审核 / 确认 / 预警 / 告警（Tab 角标取 TD-05）；预览 10 条（`pageSize=10, status=PENDING`），排序同 TD-02；行显示类型 tag、标题、来源模块、截止时间、〔去处理〕〔关闭〕；〔查看更多〕带当前 Tab 进入待办中心；无数据显示空状态“暂无待办”。
- **依据**：【AUTH 规格】P4 §2、§4.2 A；原型 workbench；TC WB-01、WB-04、WB-05；00 Q2。

### FP-B3-WB-05 消息预览卡（右 40%）
- **规则**：未读角标 + 〔全部已读〕；预览 10 条（全部，时间倒序），行：类型 tag、标题、摘要（1 行省略）、时间；点击 → MS-02 详情；〔查看更多〕→ 消息中心。
- **依据**：【AUTH 规格】P4 §4.2 C；TC WB-01、WB-09。

## 2. 待办中心（TD）

### FP-B3-TD-01 列表与筛选
- **入口**：WB-04〔查看更多〕或 WB-03 卡片；〔返回工作台〕。
- **页面线框**：类型 Tab；QueryBar：标题关键词、状态（待处理 / 已过期 / 已处理）；表头 类型、标题、截止时间、状态、操作；分页 20。
- **规则**：只返回本人为处理人（`ims_sys_todo_assignee.user_id = 当前用户` 且 `closed=0`）的待办；状态“已过期” = PENDING 且 `due_time < now`（不入库，Q3）；默认状态待处理；〔重置〕回默认。DONE / CANCELLED / 已过期行只显示〔查看〕（详情抽屉，不跳转）——已过期仍可〔去处理〕【本清单裁定：已过期只是逾期未办，单据仍待处理】。
- **错误码**：1008（须改密）。
- **接口**：★ `GET /todo/my/page`。
- **依据**：【AUTH 规格】P4a、§5、§6；B0a FP-G02-02；TC WB-05、WB-08。

### FP-B3-TD-02 排序与逾期高亮
- **规则**：PENDING 按 `due_time` 升序，无截止时间排最后；逾期行红底置顶并显示“逾期 X 天”（不足 1 天显示“逾期 X 小时”）；其他状态按 `done_time` / `update_time` 倒序。
- **依据**：PRD-V1 WB-R1；【AUTH 规格】§6；TC WB-06。

### FP-B3-TD-03 去处理
- **规则**：点击先调 `GET /todo/my/get?id=` 校验仍为 PENDING，再跳 `route`（由投递模块写入，工作台不写死路由表）；`route` 不在本人菜单树 → toast“暂无权限”不跳转（B0b FP-L05）；已非 PENDING → toast“待办已处理”并刷新列表；目标页返回 1504 时按 Q9 处理。
- **错误码**：1504（他人 / 不存在）。
- **接口**：★ `GET /todo/my/get`。
- **依据**：【AUTH 规格】§4.2 A、§8；B0b FP-L05；TC WB-03。

### FP-B3-TD-04 关闭待办
- **规则**：〔关闭〕→ 确认框“确认关闭该待办？关闭后不再提醒” → 成功 toast“已关闭”，从待处理列表消失；只对本人生效，不改来源单据（Q6）；类型审批 / 审核不显示〔关闭〕。
- **错误码**：1504；1001（非 PENDING 或审批 / 审核类，Q6/Q10）。
- **接口**：★ `PUT /todo/my/close {id}`。
- **依据**：【AUTH 规格】§4.2 A-4、§7；【AUTH 契约】2.4.3；TC WB-07。

### FP-B3-TD-05 待办计数
- **规则**：返回 `{total, byType:{审批:n,…}, overdue:n}`，只计本人 PENDING 且未关闭；CANCELLED 不计（B0a 第 4 条）；工作台 Tab 角标与待办卡共用。
- **接口**：★ `GET /todo/my/count`。
- **依据**：B0a FP-G02-02；B0b FP-L05；TC HOME-04（数字一致）。

## 3. 消息中心（MS）

### FP-B3-MS-01 列表与筛选
- **页面线框**：〔全部已读〕〔返回工作台〕；Tab 全部 / 未读 / 已读；标题 / 摘要搜索；行：类型 tag、标题、摘要、来源模块、时间；分页 20。
- **规则**：只返回本人消息，时间倒序；未读行加粗。
- **接口**：★ `GET /message/my/page`。
- **依据**：【AUTH 规格】P4b；B0a FP-G01-02；TC WB-09。

### FP-B3-MS-02 消息详情与标记已读
- **规则**：点击行 → 详情 Drawer 520px（标题、类型 tag、时间、正文）；打开即调已读（未读时），未读数 -1；重复调用幂等。
- **错误码**：1504（他人 / 不存在消息 id）。
- **接口**：★ `GET /message/my/get`、★ `POST /message/my/read {ids}`。
- **依据**：【AUTH 规格】§4.2 C-1、§7；【AUTH 契约】2.4.5；TC WB-10。

### FP-B3-MS-03 全部已读
- **规则**：只置本人未读为已读，返回 `{updated}`；toast“已全部标记为已读”；未读数归 0，铃铛红点消失。
- **接口**：★ `POST /message/my/read-all`。
- **依据**：【AUTH 契约】2.4.6；TC WB-11。

### FP-B3-MS-04 未读数与顶栏铃铛抽屉
- **规则**：顶栏铃铛显示未读数（>99 显示 99+，0 不显示红点）；页面切换和每 60 秒刷新一次【本清单裁定：规格未定刷新频率，可改】；点击打开 420px 抽屉，与消息中心同源列表（pageSize=20），点击条目同 MS-02。
- **接口**：★ `GET /message/my/unread-count`。
- **依据**：【AUTH 规格】P4 §2、§4.2 C-3、§7；TC WB-15。

### FP-B3-MS-05 查看来源
- **规则**：消息有 `route` 时详情底栏〔查看来源〕跳转；路由不在本人菜单树 → toast“暂无权限”。钉钉推送由服务端完成，前端不重复推。
- **依据**：【AUTH 规格】§4.2 C-4；TC WB-10。
