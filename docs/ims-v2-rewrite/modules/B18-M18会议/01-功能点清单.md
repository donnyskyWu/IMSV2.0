# B18-M18 会议 · 01 功能点清单

> 规格：MEET 页面规格 P4、API 契约 §2.4；PRD §5.7 MEET-004。决策见 00 第 4 节。

## 0. 通用口径

### 0.1 页面
| 页面 | 路由 | 菜单权限 |
|---|---|---|
| 会议纪要 | `/ims/meet/minutes` | `ims:meet:minutes:query` 或 `ims:meet:minutes:query-self` |

### 0.2 状态
- 纪要：`REGISTERED`（已登记）→ `MINUTES_RECORDED`（纪要已录入）→ `ARCHIVED`（已归档，终态）。
- 行动项：`OPEN`（进行中）/ `OVERDUE`（已逾期，由定时任务置）→ `CLOSED`（已闭环，终态）。

### 0.3 权限码（种子只补缺，只授 R1，Q-D1）
| 权限码 | 说明 |
|---|---|
| `ims:meet:minutes:query` | 按数据范围查看 |
| `ims:meet:minutes:query-self` | 仅看本人参会 / 记录 / 负责的会议 |
| `ims:meet:minutes:add` | 登记会议 |
| `ims:meet:minutes:edit` | 编辑范围内任意未归档纪要（记录人编辑本条无需此码） |
| `ims:meet:minutes:archive` | 归档范围内任意纪要（记录人归档本条无需此码） |
| `ims:meet:minutes:delete` | 删除未归档纪要 |
| `ims:meet:minutes:appendix` | 已归档纪要追加附录说明（记录人本条无需此码） |
| `ims:meet:minutes:supervise` | 接收 48h 未归档与行动项 3 天逾期升级；看留痕率 |

### 0.4 错误码（不新增）
| 码 | 场景 |
|---|---|
| 1001 | 参数校验失败（主题超 128、期限早于今天、URL 格式错、closeRemark 空或超 512 等） |
| 1008 | 缺权限码；非记录人且无对应权限码 |
| 1116 | 超 24h 录纪要 / 超 48h 归档的软提示，只放在 `warnings`，不阻断 |
| 1117 | 已归档纪要修改、删除、重复归档；未归档纪要追加附录 |
| 1118 | 非行动项责任人回填 |
| 1500 / 1501 | 未登录 / 令牌失效 |
| 1504 | 纪要或行动项不存在、跨租户、超出可见范围 |

### 0.5 表结构（Alembic 只增）
- `ims_meeting_minutes`：id、tenant_id、code（MM+yyyyMMdd+3 位流水）、title(128)、meeting_date、meeting_room(64, 可空)、dept_id（记录人主部门，数据范围用）、recorder_user_id、attendees(JSON：内部 user_id 列表 + 外部姓名列表)、summary(TEXT, 可空)、import_from_ai_minutes(bool, 预留)、status、archived_at、archived_by、remind_24h_at、remind_48h_at、通用审计字段、del_flag。
- `ims_meeting_decision`：id、minutes_id、seq、content(512)。
- `ims_meeting_action_item`：id、minutes_id、description(256)、assignee_user_id、due_date、status、close_remark(512)、evidence_url(512)、closed_at、todo_id、notified_at、escalated_at。
- `ims_meeting_appendix`：id、minutes_id、content(1024)、created_by、created_at。
- 字典：`meet_minutes_status`、`meet_action_status`。

## 1. 纪要（MN）

### FP-B18-MN-01 纪要列表
- 筛选：主题（模糊）、会议时间区间（默认近 30 天）、状态；分页 10/20/50。
- 列：编号、主题、会议时间、参会人（前 3 名 + “等 N 人”）、行动项“N 项（M 已闭环）”、状态、记录人、归档时间、操作。
- 范围：`query` 按数据范围；仅有 `query-self` 时只返回本人为参会人 / 记录人 / 责任人的会议（Q-D11）；两者都无 → 1008。
- 操作按钮按状态与权限显示：编辑（未归档）、归档（`MINUTES_RECORDED`）、附录（已归档）、删除（未归档且有 delete）。

### FP-B18-MN-02 登记会议
- 720px 抽屉；必填：主题 ≤128、会议时间、至少 1 名参会人（内部多选 + 外部手填，Q-D13）；可选：会议室文本（Q-D14）、记录人（默认本人，Q-D10）。
- 正文为空 → `REGISTERED`；生成编号；内部参会人收到会议通知（站内 + 钉钉，B0a notify；MEET-04）。

### FP-B18-MN-03 录入纪要
- 填写正文（富文本 ≤ 20000 字）、决议（动态列表，每条 ≤512）、行动项（描述 ≤256 / 责任人为内部人员 / 期限 ≥ 今天）。
- 正文非空 → `MINUTES_RECORDED`（Q-D3）；每条新行动项生成待办（Q-D6）。
- 会后 > 24h 才录入 → 成功，`warnings` 带 1116。

### FP-B18-MN-04 编辑纪要
- 未归档可改全部字段；已归档 → 1117。
- 行动项增删改：新增建待办；删除未闭环项取消待办；改责任人 / 期限同步待办；已闭环项不可改。
- 权限：记录人或 edit 码，否则 1008。

### FP-B18-MN-05 归档
- 仅 `MINUTES_RECORDED`；`REGISTERED` → 1001（提示“请先录入纪要”）；已归档 → 1117。
- 二次确认“归档后不可修改，行动项继续跟踪”；写 archived_at/by；会后 > 48h 归档 → `warnings` 1116。

### FP-B18-MN-06 附录说明
- 仅已归档；未归档 → 1117（提示“未归档纪要请直接编辑”）；内容 1～1024 字；只追加，不可改删；详情按时间倒序展示。

### FP-B18-MN-07 删除
- 仅未归档；已归档 → 1117；逻辑删除；取消全部未闭环待办；写操作日志。

### FP-B18-MN-08 详情
- 70% 抽屉，Tab：纪要正文（含附录）、决议事项、行动项跟踪（状态、逾期天数、已推送 / 已升级）、操作留痕（B0a 操作日志，按本条过滤）。
- 不可见 → 1504。

## 2. 行动项（AI）

### FP-B18-AI-01 行动项待办
- 规则见 Q-D6；责任人在工作台待办看到“会议行动项：<描述>”，点开定位到回填抽屉。

### FP-B18-AI-02 回填闭环
- 480px 抽屉：closeRemark 必填 ≤512；evidenceUrl 可选，须 http(s) URL；非责任人 → 1118；已闭环 → 1001。
- 成功 → `CLOSED`、完成待办；纪要已归档也可回填。

### FP-B18-AI-03 逾期推送与升级
- 规则见 Q-D7、Q-D8；任务幂等，同项同级只推一次；`CLOSED` 不处理。

## 3. 统计与提醒（ST）

### FP-B18-ST-01 留痕率与未归档清单

### FP-B18-ST-02 24h / 48h 提醒
- 规则见 Q-D9，每级每条只发一次。
