### 2.2 接口明细与错误码

#### 2.2.1 POST /admin-api/ims/meet/minutes — 登记会议/录入纪要

**请求体**:
```typescript
interface MeetingMinutesCreateReq {
  title: string;              // 必填，≤128 字
  meetingDate: string;        // 必填，ISO 8601
  meetingRoom?: string;       // 可选，≤64 字
  recorderUserId?: number;    // 可选，默认当前用户
  attendees: {
    internal: number[];       // 内部参会人 userId 列表
    external?: string[];      // 外部参会人姓名列表（≤32 字/人）
  };
  summary?: string;           // 纪要正文（富文本，≤20000 字）
  decisions?: Array<{
    content: string;          // ≤512 字
  }>;
  actionItems?: Array<{
    description: string;      // ≤256 字
    assigneeUserId: number;   // 责任人（须为内部用户）
    dueDate: string;          // yyyy-MM-dd，≥今天
  }>;
  clientToken: string;        // 幂等键
}
```

**响应**: `MeetingMinutesVO`

**逻辑**:
1. 参数校验：主题 ≤128、至少 1 名参会人、行动项期限 ≥ 今天 → 1001
2. 记录人未指定时取当前用户；记录人主部门写入 `dept_id`
3. 正文为空 → `status=REGISTERED`；正文非空 → `status=MINUTES_RECORDED`（Q-D3）
4. 生成编号 `MM + yyyyMMdd + 3 位流水`
5. 内部参会人发送会议通知（B0a `notify`，渠道 INBOX + DINGTALK）
6. 每条行动项调用 `todo.create(type=确认, source_type=MEET_ACTION_ITEM)`（Q-D6）
7. 会后 > 24h 录入 → `warnings` 带 1116（不阻断）

**错误码**:
| 码 | 场景 |
|----|------|
| 1001 | 参数校验失败 |
| 1008 | 缺少 `add` 权限码 |
| 1500/1501 | 未登录/令牌失效 |

#### 2.2.2 GET /admin-api/ims/meet/minutes/list — 纪要列表

**Query 参数**:
- `pageNo`, `pageSize` (必填)
- `title` (可选，模糊匹配)
- `meetingDateStart`, `meetingDateEnd` (可选，默认近 30 天)
- `status` (可选)

**响应**: `PageResult<MeetingMinutesVO>`

**数据范围**（Q-D11）:
- 持有 `query` → 按角色数据范围（`dept_id` 过滤）
- 仅有 `query-self` → 本人为参会人 / 记录人 / 行动项责任人
- 两者都无 → 1008

#### 2.2.3 GET /admin-api/ims/meet/minutes/{id} — 纪要详情

**响应**: `MeetingMinutesVO`（含 decisions、actionItems、appendices）

**错误码**:
| 码 | 场景 |
|----|------|
| 1504 | 纪要不存在、跨租户、超出可见范围（不泄漏存在性） |

#### 2.2.4 PUT /admin-api/ims/meet/minutes/{id} — 编辑纪要

**请求体**: 同创建

**逻辑**:
1. 已归档 → 1117
2. 权限：记录人可编辑本条；其他人需 `edit` 权限码
3. 行动项变更处理：
   - 新增 → `todo.create`
   - 删除（未闭环）→ `todo.cancel`
   - 改责任人/期限 → 更新待办
   - 已闭环项不可改 → 1001
4. 会后 > 24h → `warnings` 带 1116

**错误码**:
| 码 | 场景 |
|----|------|
| 1001 | 参数校验/已闭环行动项修改 |
| 1008 | 非记录人且无 `edit` 权限 |
| 1117 | 已归档不可修改 |
| 1504 | 纪要不存在 |

#### 2.2.5 PUT /admin-api/ims/meet/minutes/{id}/archive — 归档

**逻辑**:
1. 仅 `MINUTES_RECORDED` 可归档
2. `REGISTERED` → 1001（提示"请先录入纪要"）
3. 已归档 → 1117
4. 写 `archived_at`、`archived_by`
5. 会后 > 48h → `warnings` 带 1116

**错误码**:
| 码 | 场景 |
|----|------|
| 1001 | 状态为 REGISTERED |
| 1008 | 非记录人且无 `archive` 权限 |
| 1117 | 已归档重复归档 |
| 1504 | 纪要不存在 |

#### 2.2.6 POST /admin-api/ims/meet/minutes/{id}/appendix — 附录说明

**请求体**:
```typescript
interface AppendixReq {
  content: string;  // 1～1024 字
}
```

**逻辑**:
1. 仅已归档可追加
2. 未归档 → 1117（提示"未归档纪要请直接编辑"）
3. 追加记录到 `ims_meeting_appendix`

**错误码**:
| 码 | 场景 |
|----|------|
| 1001 | 内容为空或超长 |
| 1008 | 非记录人且无 `appendix` 权限 |
| 1117 | 未归档纪要 |
| 1504 | 纪要不存在 |

#### 2.2.7 DELETE /admin-api/ims/meet/minutes/{id} — 删除

**逻辑**:
1. 仅未归档可删
2. 已归档 → 1117
3. 逻辑删除（`deleted = id`）
4. 取消全部未闭环行动项待办（`todo.cancel`）
5. 写操作日志

**错误码**:
| 码 | 场景 |
|----|------|
| 1008 | 无 `delete` 权限 |
| 1117 | 已归档不可删 |
| 1504 | 纪要不存在 |

#### 2.2.8 PUT /admin-api/ims/meet/minutes/action-item/{itemId} — 行动项回填

**请求体**:
```typescript
interface ActionItemCloseReq {
  closeRemark: string;    // 必填，≤512 字
  evidenceUrl?: string;   // 可选，须 http(s) URL
}
```

**逻辑**:
1. 非责任人 → 1118
2. 已闭环 → 1001
3. 写 `close_remark`、`evidence_url`、`closed_at`
4. `status = CLOSED`
5. 调用 `todo.complete`
6. 纪要已归档仍可回填（行动项跟踪独立于归档状态）

**错误码**:
| 码 | 场景 |
|----|------|
| 1001 | closeRemark 空/超长、URL 格式错、已闭环 |
| 1118 | 非行动项责任人 |
| 1504 | 行动项不存在 |

#### 2.2.9 GET /admin-api/ims/meet/minutes/archive-rate — 留痕率统计

**Query 参数**:
- `dateRangeStart`, `dateRangeEnd` (可选，默认近 30 天)

**响应**:
```typescript
interface ArchiveRateResp {
  totalMeetings: number;       // 分母：会议时间已过的会议数
  archivedCount: number;       // 分子：已归档数
  archiveRate: number;         // 留痕率（目标 100%）
  unarchivedList: Array<{
    minutesNo: string;
    meetingTitle: string;
    meetingDate: string;
    recorderName: string;
    hoursSinceMeeting: number; // > 48 红标
  }>;
}
```

**权限**: 仅 `supervise` 权限码持有者可访问

**错误码**:
| 码 | 场景 |
|----|------|
| 1008 | 无 `supervise` 权限 |

### 4.2 交互流程

#### 4.2.1 列表页

1. 顶部指标卡（仅 `supervise` 可见）：本期会议数、已归档数、留痕率（目标 100%），点击"未归档"打开清单抽屉
2. 查询条件：主题（模糊）、会议时间区间（默认近 30 天）、状态
3. 表格列：编号、主题、会议时间、参会人（前 3 + "等 N 人"）、行动项（N 项（M 已闭环））、状态、记录人、归档时间、操作
4. 操作按钮按状态与权限显示：
   - 未归档：编辑、归档（仅 `MINUTES_RECORDED`）、删除

#### 4.2.2 登记/录入抽屉（720px）

字段：
- 主题*（≤128）
- 会议时间*
- 参会人*（内部多选 + 外部手填）
- 会议室（可选，纯文本）
- 记录人（默认当前用户，可改）
- 纪要正文（富文本，≤20000）
- 决议事项（动态列表）
- 行动项（描述/责任人/期限）

#### 4.2.3 详情抽屉（70%）

4 Tab：
1. **纪要正文**: 正文 + 附录列表（时间倒序）
2. **决议事项**: 决议列表
3. **行动项跟踪**: 状态、逾期天数、已推送/已升级、回填入口
4. **操作留痕**: B0a 操作日志，按 `biz_type=MEETING_MINUTES` + `biz_id` 过滤

底部按钮：编辑（未归档）、归档（`MINUTES_RECORDED`）、附录（已归档）

#### 4.2.4 回填抽屉（480px）

从工作台待办或详情页进入：
- closeRemark*（≤512）
- evidenceUrl（URL 格式）

## 7. 定时任务

### 7.1 meeting_reminder_job（24h/48h 提醒）

- **调度**: 每小时执行
- **规则**（Q-D9）:
  1. 会后超 24h 仍 `REGISTERED` → 给记录人发消息（`remind_24h_at` 为空时才发，发后写入时间）
  2. 会后超 48h 未归档 → 给记录人 + `supervise` 用户发消息（`remind_48h_at` 为空时才发）
- **幂等**: 按 `remind_24h_at` / `remind_48h_at` 判断，同一纪要同一级只发一次

### 7.2 meeting_overdue_job（逾期推送与升级）

- **调度**: 每日 09:00（北京时间）
- **规则**（Q-D7, Q-D8）:
  1. 扫描 `due_date < 今天` 且 `status != CLOSED` 的行动项
  2. 标记 `status = OVERDUE`
  3. 逾期满 1 天（`notified_at` 为空）→ 推送责任人，写入 `notified_at`
  4. 逾期满 3 天（`escalated_at` 为空）→ 推送 `supervise` 用户（数据范围覆盖该会议），写入 `escalated_at`
- **升级接收人**: 持有 `ims:meet:minutes:supervise` 且数据范围覆盖该会议的用户（Q-D7 不按角色名）
