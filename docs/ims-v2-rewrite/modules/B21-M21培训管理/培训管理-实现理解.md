## 3. 错误码

按 `00-工作包.md` Q-D27，只使用已定义错误码：

| 码 | 场景 | 中文提示 |
|----|------|----------|
| 1001 | 参数校验失败 | 标题超长、类别有资料不可删、文档转换中不可发布、题目选项不足等 |
| 1008 | 权限不足 | 缺权限码、越权查他人数据、须改密白名单外 |
| 1101 | 分类/资料不存在或未发布 | 指派时资料未发布、AI 生成时资料无效 |
| 1102 | 截止时间早于当前 | 创建/编辑任务时 |
| 1103 | 学员访问不可见资料 | 草稿/已下架/非本岗位 |
| 1104 | 确认条件未满足 | 学时未达标、问卷未配置、已结束任务编辑 |
| 1105 | 非被指派人 | 上报/作答/确认时非本人 |
| 1106 | 培训AI调用失败 | 外部服务异常 |
| 1107 | 培训AI超时 | 生成超时（90秒） |
| 1108 | 题量为0 | AI 返回无有效题目 |
| 1109 | 培训AI未配置 | B10 未配置或未启用 |
| 1500 | 引用不存在 | 未登录 |
| 1501 | 引用已停用 | 令牌失效 |
| 1504 | 资源不可用 | 跨租户、不存在 |
| 5005 | 文件类型/大小不符 | 上传场景校验 |

**不新增错误码**。

## 4. 前端页面结构

### 4.1 路由与菜单

| 页面 | 路由 | 菜单权限 | 组件 |
|------|------|----------|------|
| 岗位资料库 | `/ims/train/material` | ims:train:material:query | 左树右表（UI-C13） |
| 学习任务 | `/ims/train/task` | ims:train:task:query | 列表页（UI-L01） |
| 学习中心 | `/ims/train/study` | ims:train:study:query | 列表+执行页 |
| 学习执行 | `/ims/train/study/{taskId}` | ims:train:study:query | 二级页（UI-L07） |
| 培训统计 | `/ims/train/stat` | ims:train:stat:query | Tab看板 |

### 4.2 页面组件复用

- **UI-C13 左树右表**：资料库左侧分类树 + 右侧资料列表
- **UI-C19 分步向导**：AI 生成试卷四步向导
- **UI-C33 FileUpload**：资料上传（场景 TRAIN_DOC/TRAIN_VIDEO）
- **UI-L07 作答页**：学习执行与问卷作答

### 4.3 抽屉规格

| 抽屉 | 宽度 | 内容 |
|------|------|------|
| 上传资料 | 640px | 分类、标题、类型、文件/链接、岗位 |
| 资料详情 | 60% | 基础信息 + 版本历史 + 预览区 |
| 创建任务 | 720px | 表单 + 资料选择 + 问卷编辑器 |
| 学习记录 | 70% | 记录表格 + 筛选 |
| AI向导 | 720px | 4步向导 |

## 附录 B：视频心跳防刷规则（Q-D12）

```
有效秒数 = min(两次心跳实际间隔, 20)
去重规则 = 按 (record_id, material_id, stat_date) 累加，同一秒区间不重复计
快进检测 = 当前位置 - 上次位置 > 心跳间隔 * 1.5 时，该区间不计入
```

## 附录 C：完成率口径（Q-D21）

```
完成率 = 已完成人次 / 应完成人次
应完成人次 = 统计截至前已创建任务的指派人次（不含已删除任务的实时值）
已完成人次 = confirm_status = CONFIRMED 的记录数
逾期标记 = 完成时间 > 截止时间 或 截止已过且未完成
```
