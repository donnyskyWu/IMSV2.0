### 5.2 数据范围详细规则（按 Q-D5、TK-01，阻断修复）

**核心问题**：TK-01 规定 DEPT = "创建人部门 OR 被指派人在本部门"，SELF = "本人创建 OR 被指派"，这是复合条件，**`__scope_fields__` 单字段无法表达**。

**解决方案**：采用 Repo 层显式过滤或自定义 scope 函数，不使用 `__scope_fields__`。

**资料（无数据范围）**：
- `material:query`：全量可见
- `study:query`：只见本岗位 + 全员通用 + 在本人被指派任务中的资料

#### 5.2.1 任务列表 `GET /task/list`（复合条件）

| 数据范围 | SQL 过滤条件 | 实现方式 |
|----------|-------------|----------|
| ALL | `tenant_id = :tenant_id` | 无额外过滤 |
| DEPT | `(creator_dept_id IN :dept_ids) OR (id IN (SELECT task_id FROM ims_train_task_record WHERE user_dept_id IN :dept_ids AND deleted=0))` | `TrainTaskRepo.list_by_scope_dept(ctx.dept_ids)` |
| SELF | `(creator = :user_id) OR (id IN (SELECT task_id FROM ims_train_task_record WHERE user_id = :user_id AND deleted=0))` | `TrainTaskRepo.list_by_scope_self(ctx.user_id)` |

**代码实现**：
```python
# app/domains/train/repo.py

async def list_tasks_with_scope(
    self, 
    ctx: RequestContext, 
    filters: TaskListFilters
) -> list[TrainTask]:
    """
    按数据范围查询任务列表。
    复合条件不用 __scope_fields__，显式 SQL 过滤。
    """
    query = select(TrainTask).where(
        TrainTask.tenant_id == ctx.tenant_id,
        TrainTask.deleted == 0
    )
    
    if ctx.data_scope == DataScope.ALL:
        pass  # 无额外过滤
    elif ctx.data_scope == DataScope.DEPT:
        # DEPT: 创建人部门 OR 被指派人在本部门
        subquery = select(TrainTaskRecord.task_id).where(
            TrainTaskRecord.user_dept_id.in_(ctx.dept_ids),
            TrainTaskRecord.deleted == 0
        )
        query = query.where(
            or_(
                TrainTask.creator_dept_id.in_(ctx.dept_ids),
                TrainTask.id.in_(subquery)
            )
        )
    elif ctx.data_scope == DataScope.SELF:
        # SELF: 本人创建 OR 被指派
        subquery = select(TrainTaskRecord.task_id).where(
            TrainTaskRecord.user_id == ctx.user_id,
            TrainTaskRecord.deleted == 0
        )
        query = query.where(
            or_(
                TrainTask.creator == ctx.user_id,
                TrainTask.id.in_(subquery)
            )
        )
    
    return await self.session.scalars(query)
```

    query: Select, 
    ctx: RequestContext
) -> Select:
    """
    根据用户数据范围构建任务查询条件。
    P0 函数，分支覆盖 90%。
    
    复合条件不用 __scope_fields__：
    - DEPT: creator_dept_id IN dept_ids OR 存在被指派人在 dept_ids
    - SELF: creator == user_id OR 本人被指派
    """
    if ctx.data_scope == DataScope.ALL:
        return query
    
    if ctx.data_scope == DataScope.DEPT:
        assigned_in_dept = select(TrainTaskRecord.task_id).where(
            TrainTaskRecord.user_dept_id.in_(ctx.dept_ids),
            TrainTaskRecord.deleted == 0
        ).distinct()
        return query.where(or_(
            TrainTask.creator_dept_id.in_(ctx.dept_ids),
            TrainTask.id.in_(assigned_in_dept)
        ))
    
    if ctx.data_scope == DataScope.SELF:
        self_assigned = select(TrainTaskRecord.task_id).where(
            TrainTaskRecord.user_id == ctx.user_id,
            TrainTaskRecord.deleted == 0
        ).distinct()
        return query.where(or_(
            TrainTask.creator == ctx.user_id,
            TrainTask.id.in_(self_assigned)
        ))
    
    return query

#### 7.1.2 校验流程（必须全部通过）

```python
# app/domains/train/upload.py

TRAIN_DOC_EXTENSIONS = {"pdf", "doc", "docx", "ppt", "pptx", "xls", "xlsx"}
TRAIN_VIDEO_EXTENSIONS = {"mp4", "mov"}

FILE_SIGNATURES = {
    "pdf": [b"%PDF"],
    "docx": [b"PK\x03\x04"],  # ZIP-based Office
    "xlsx": [b"PK\x03\x04"],
    "pptx": [b"PK\x03\x04"],
    "doc": [b"\xd0\xcf\x11\xe0"],  # OLE Compound
    "xls": [b"\xd0\xcf\x11\xe0"],
    "ppt": [b"\xd0\xcf\x11\xe0"],
    "mp4": [b"ftyp", b"\x00\x00\x00\x18ftyp", b"\x00\x00\x00\x20ftyp"],
    "mov": [b"ftyp", b"moov", b"free"],
}

async def validate_train_upload(file: UploadFile, scene: str) -> None:
    """
    完整的上传校验流程（B21 自行实现，不依赖 B0a）：
    
    1. 扩展名白名单校验
    2. 文件头魔数校验（真实类型与扩展名匹配）
    3. MIME 类型校验
    4. 文件大小校验（100MB DOC / 1024MB VIDEO）
    
    任一失败 → 5005
    """
    filename = file.filename or ""
    ext = filename.rsplit(".", 1)[-1].lower() if "." in filename else ""
    
    # 1. 扩展名白名单
    allowed_exts = TRAIN_DOC_EXTENSIONS if scene == "TRAIN_DOC" else TRAIN_VIDEO_EXTENSIONS
    if ext not in allowed_exts:
        raise BizError(5005, msg=f"不支持的文件类型: .{ext}")
    
    # 2. 文件头魔数校验
    header = await file.read(32)
    await file.seek(0)
    valid_signatures = FILE_SIGNATURES.get(ext, [])
    if not any(sig in header for sig in valid_signatures):
        raise BizError(5005, msg="文件内容与扩展名不符")
    
    # 3. MIME 类型校验
    content_type = file.content_type or ""
    if scene == "TRAIN_DOC":
        if not (content_type.startswith("application/") or content_type == ""):
            raise BizError(5005, msg=f"不支持的 MIME 类型: {content_type}")
    else:  # TRAIN_VIDEO
        if not (content_type.startswith("video/") or content_type == ""):
            raise BizError(5005, msg=f"不支持的 MIME 类型: {content_type}")
    
    # 4. 文件大小校验
    max_size = 100 * 1024 * 1024 if scene == "TRAIN_DOC" else 1024 * 1024 * 1024
    content = await file.read()
    await file.seek(0)
    if len(content) > max_size:
        raise BizError(5005, msg=f"文件超过大小限制: {max_size // (1024*1024)}MB")
```

## 8. 视频进度防刷规则（Q-D11、Q-D12）

### 8.1 核心规则（按 Q-D11、Q-D12、E2E-B21-27）

**观看完成判定**：按播放区间去重并校验覆盖 ≥ 95%（不是简单累计时长）

**心跳计时规则**：
- 前端每 15 秒发送一次心跳，上报当前播放位置
- **单次计入有效秒数 = min(两次心跳实际间隔, 实际位置增量, 20)**
- 存储已观看区间 `watched_intervals` JSON 数组 `[[start, end], ...]`
- **区间去重**：相邻或重叠区间合并，防止重复计时

**快进防刷规则**（按 Q-D12）：
- **单次增量 ≤ 实际间隔 且 ≤ 20s**，不是 ×1.5
- 位置跳跃超过实际间隔时，该段不计入有效区间

### 8.2 覆盖率计算（区间去重）

```python
def merge_intervals(intervals: list[tuple[int, int]]) -> list[tuple[int, int]]:
    """合并重叠/相邻区间，实现去重。"""
    if not intervals:
        return []
    sorted_intervals = sorted(intervals)
    merged = [sorted_intervals[0]]
    for start, end in sorted_intervals[1:]:
        last_start, last_end = merged[-1]
        if start <= last_end:  # 重叠或相邻
            merged[-1] = (last_start, max(last_end, end))
        else:
            merged.append((start, end))
    return merged

def calculate_coverage(intervals: list[tuple[int, int]], total_duration: int) -> float:
    """
    计算区间覆盖率（去重后）。
    intervals: [(0, 30), (45, 60), ...]
    返回: 0.0 ~ 1.0
    """
    merged = merge_intervals(intervals)
    covered = sum(end - start for start, end in merged)
    return covered / total_duration if total_duration > 0 else 0.0
```

### 8.3 快进检测（单次增量 ≤ 实际间隔且 ≤ 20s）

**规则**：当前上报位置 - 上次位置 > min(两次心跳实际间隔, 20) 时，为快进，该区间不计入有效时长。

```python
def validate_video_progress(
    current_pos: int, 
    last_pos: int, 
    interval_seconds: float
) -> tuple[bool, int]:
    """
    校验视频进度上报。
    返回: (is_valid, effective_seconds)
    - 单次增量 ≤ 实际间隔 且 ≤ 20s 才有效
    - 快进时 effective_seconds = 0
    """
    if current_pos <= last_pos:
        return True, 0  # 回退或暂停，不计时
    
    delta = current_pos - last_pos
    max_allowed = min(interval_seconds, 20)  # 单次最多 20s 或实际间隔
    
    if delta > max_allowed:
        # 快进：不计入有效时长
        return False, 0
    
    return True, int(delta)
```

**E2E-B21-27 验证**：
- 拖到末尾 → 有效学时只按实际间隔增加（≤20 秒/次）
- 直调心跳传超额秒数 → 资料未完成
- 正常观看 5 分钟视频 → 区间覆盖 ≥ 95% 才判定完成

## 附录 B：视频心跳防刷规则（Q-D11、Q-D12）

```
有效秒数 = min(两次心跳实际间隔, 位置增量, 20)
区间存储 = watched_intervals JSON [[start, end], ...]
区间去重 = 合并重叠/相邻区间，重复观看同一段只计一次
快进检测 = 当前位置 - 上次位置 > min(两次心跳实际间隔, 20)
         → 快进时该区间不计入有效时长
完成判定 = 去重后区间覆盖率 ≥ 95%（不是简单累计时长）
```

**E2E-B21-27 验证场景**：
- 拖到末尾 → 有效学时只按实际间隔增加（≤20s/次）
- 直调心跳传超额秒数 → 资料未完成
- 正常观看 → 覆盖率 ≥ 95% 才完成

## 附录 C：完成率口径（Q-D21）

```
完成率 = 已完成人次 / 应完成人次
应完成人次 = 统计截至前已创建任务的指派人次（不含已删除任务的实时值）
已完成人次 = confirm_status = CONFIRMED 的记录数
逾期标记 = 完成时间 > 截止时间 或 截止已过且未完成
```
