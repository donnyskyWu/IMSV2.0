## 0. 通用口径

### 0.1 页面

### 0.2 状态
- 资料：`DRAFT` → `PUBLISHED` → `OFFLINE`；`PUBLISHED` / `OFFLINE` 编辑发布 → `PUBLISHED` 且 version+1。文档转换状态 `PENDING` / `DONE` / `FAILED`。
- 任务：`IN_PROGRESS` → `FINISHED`（截止时间到）。
- 学习记录：`NOT_CONFIRMED` → `CONFIRMED`；`isOverdue` 为派生标记。

### 0.3 权限码（种子只补缺，只授 R1，Q-D1）
| 权限码 | 说明 |
|---|---|
| `ims:train:material:query` | 资料库管理视图（全量） |
| `ims:train:material:add` / `:edit` / `:offline` | 上传 / 编辑与发布 / 下架 |
| `ims:train:cate:edit` | 类别增改删 |
| `ims:train:task:query` | 任务与学习记录（按数据范围） |

| `ims:train:study:do` | 上报进度、暂存作答、确认完成（另校验本人被指派，否则 1105） |
| `ims:train:stat:query` | 统计看板（按数据范围） |
| `ims:train:stat:export` | 逾期清单导出 |

### 0.5 表结构（Alembic 只增）
- `ims_train_material_cate`：id、tenant_id、parent_id、position_code（顶层）、cate_name(64)、sort、审计、del_flag。
- `ims_train_material`：按 PRD §5.1.2 字段（material_no、title、cate_id、material_type、file_key、link_url、position_codes JSON、version、status、uploader_user_id、updated_at）+ convert_status、page_count、duration_seconds、published_at、tenant_id、del_flag。
- `ims_train_material_version`：material_id、version、title、file_key、pdf_key、link_url、page_count、duration_seconds、editor_user_id、created_at（只增不改）。
- `ims_train_task`：按 PRD §5.2.2 字段 + required_minutes、quiz JSON、pass_score、source（MANUAL / ONBOARDING）、source_position_code、client_token（唯一）、dept_id、tenant_id、del_flag、deleted_at。
- `ims_train_task_record`：按 PRD（task_id、user_id、progress、material_progress JSON、confirm_status、confirm_score、started_at、finished_at）+ effective_seconds、quiz_draft JSON、attempt_count、todo_id、remind_due_at、remind_overdue_at、dept_id。唯一 `task_id+user_id`。
- `ims_train_study_log`：record_id、material_id、stat_date、effective_seconds、last_heartbeat_at（时长排行、热度、去重）。
- `ims_train_stat_daily`：按 PRD §5.3.2 + tenant_id；`ims_train_dept_alert`：dept_id、week_start、notified_at。
- 字典：`train_material_type`、`train_material_status`、`train_task_status`、`train_confirm_type`、`train_assign_scope`。

## 1. 岗位资料库（MT）

### FP-B21-MT-01 分类树
- 两级：岗位（岗位字典启用项 + 固定“全员通用”）→ 类别；节点带已发布资料数；学员视图只显示本岗位与“全员通用”。

### FP-B21-MT-02 类别增改删
- 名称 1～64，同岗位下不重名（1001）；挂在岗位节点下；有资料（任意状态）不可删 → 1001；岗位节点不可编辑。

### FP-B21-MT-03 资料列表
- 筛选：分类、标题、类型、状态、岗位；列：编号、标题、类型、版本、关联岗位（>3 显示 +N）、状态、更新人、更新时间、操作。
- 只有 study:query 时：只返回 `PUBLISHED` 且（关联本人岗位或“全员通用”或在本人被指派任务中）的资料，状态筛选锁定（TRN-M-R1）。

### FP-B21-MT-04 上传 / 存草稿
- 640px 抽屉：类别*、标题* ≤128、类型*、DOC/VIDEO 文件（B0a 场景）或 LINK 地址（http(s)）、关联岗位* ≥1；〔存草稿〕→ `DRAFT`，编号 MT+日期+流水。

### FP-B21-MT-05 发布
- 〔发布〕确认框汇总类型 / 岗位数 / 可见范围；文档转换未完成 → 1001；成功 `PUBLISHED`、version=1、写版本表。

### FP-B21-MT-06 编辑生成新版本
- 规则见 Q-D14；提交提示“将生成新版本 V{n+1}，旧版本留档”；版本快照不可改。

### FP-B21-MT-07 详情与版本历史
- 60% 抽屉：基础信息、版本历史（可预览）、预览区（视频播放、文档按 PDF 预览、外链新窗口）；文件地址 60 秒签名；学员不可见 → 1103。

### FP-B21-MT-08 下架
- 规则见 Q-D15；已下架再下架 → 1001。

### FP-B21-MT-09 文档转换与视频时长
- 规则见 Q-D12、Q-D13；列表显示“转换中 / 转换失败”。

### FP-B21-MT-10 周更新率与未更新清单
- 规则见 Q-D16；卡片 本周应更新、已更新、周更新率（<100% 黄标）；〔未更新清单〕抽屉列编号、标题、负责人（最后更新人）、最后更新，〔复制清单〕复制文本。

## 2. 学习任务（TK）

### FP-B21-TK-01 任务列表
- 筛选：任务名称、状态（默认进行中）、确认方式；列见规格 P2 §6，完成率三色（>90 绿 / 70～90 黄 / <70 红）；截止 <24h 黄、已过红；自动指派行灰色角标与来源岗位。
- 数据范围：全部 / 本部门（创建人部门或被指派人在本部门）/ 仅本人（本人创建或被指派）。

### FP-B21-TK-02 创建任务（按人）
- 720px 抽屉：名称* ≤128、资料* ≥1（仅已发布，弹窗多选）、指派对象*、截止*（>当前，否则 1102）、确认方式*、要求学时（DURATION）；clientToken 防重；未发布资料 → 1101；编号 TT+日期+流水；建记录与待办（Q-D19）。

### FP-B21-TK-03 按岗位指派与预览
- 选岗位后调预览接口显示“预计指派 N 人”；范围与目标不匹配 → 1001；展开规则见 Q-D17。

### FP-B21-TK-04 问卷编辑
- QUIZ：题目 ≥1、每题 ≤256 字、单选选项 2～6、答案必填、及格分 1～100（Q-D8）；缺失 → 1001。

### FP-B21-TK-05 AI 生成试卷向导
- 4 步：① 选资料（至少 1 份已发布，否则提示“请至少选择 1 份已发布资料”）② 题量、题型比例、难度 ③ 生成中（≤90 秒）④ 预览，可删改单题，〔采纳到问卷编辑器〕追加到题目列表 / 〔丢弃〕。
- 错误码 1101、1106～1109（Q-D6、Q-D7）；不落库，采纳后随任务保存。

### FP-B21-TK-06 编辑任务
- 仅 `IN_PROGRESS` 且截止前；否则 1104；已产生的记录不回滚；对象变更见 Q-D17；改截止同步待办。

### FP-B21-TK-07 删除任务
- 逻辑删除；作废全部未完成待办；实时统计不再计入，日汇总历史保留（Q-D21）。

### FP-B21-TK-08 学习记录
- 70% 抽屉：说明“逾期仍可补学，计入完成率分母”；列 用户、部门、进度、单资料进度、确认状态、得分、开始、完成、逾期天数；按确认状态 / 逾期筛选；按数据范围。

### FP-B21-TK-09 待办与提醒
- 规则见 Q-D19；同一记录每类提醒只发一次。

### FP-B21-TK-10 任务结束与逾期
- 规则见 Q-D20。

### FP-B21-TK-11 入职自动指派
- 规则见 Q-D18。

## 3. 学习中心（ST）

### FP-B21-ST-01 学习中心
- Tab：我的任务（进行中 / 已完成 / 已逾期，含进度、截止倒计时）、本岗位资料（同 MT-03 学员视图，可预览）、本人完成率卡片；无管理按钮。

### FP-B21-ST-02 执行页加载与断点续学
- `GET /task/{id}`：被指派人返回不含答案的题目、资料清单（签名地址、页数、时长）与本人进度；非被指派且无 task:query → 1105；资料清单按进度着色，定位第一个未完成资料，视频 / 文档回到上次位置；逾期显示红色横幅“本任务已逾期 N 天，补学仍计入完成率统计”。

### FP-B21-ST-03 视频进度
- 15 秒心跳，计时规则见 Q-D12；失败本地缓存后补报（按心跳时间幂等）。

### FP-B21-ST-04 文档进度
- 上报当前页 / 总页数，进度 = 已读最大页 / 总页数；读到最后一页即完成。

### FP-B21-ST-05 外链进度
- 〔打开外链〕后页内计时心跳上报，≥1 分钟视为完成。

### FP-B21-ST-06 学时达标确认
- 条件见 Q-D11；未满足时按钮置灰并提示差多少，强行调用 → 1104；成功 `CONFIRMED`、关闭待办、完成率实时更新。

### FP-B21-ST-07 问卷作答与暂存
- 显示题数、满分 100、及格分、不限时可回改；〔暂存退出〕保存草稿（Q-D10）；未答完提交提示“还有 N 题未作答”。

### FP-B21-ST-08 问卷提交判分
- 服务端判分；≥及格分 → `CONFIRMED`；否则显示得分与及格分，可重答（Q-D9）；QUIZ 未配置 → 1104。

## 4. 统计看板（SS）

### FP-B21-SS-01 完成率总览
- 指标卡：总完成率（目标 >90%，达标绿 / 否则红）、逾期未完成数、统计截至（时分）；按任务 Top10 柱状图、按部门表（<85% 黄标）、按个人表（前端分页）；默认近 30 天；口径见 Q-D21；只有 study:query 时只返回本人。

### FP-B21-SS-02 部门统计
- 日汇总表（日期降序）+ 趋势折线；连续 2 周 <85% 红标 + “已推送负责人”；点部门行打开明细抽屉；汇总延迟黄条（Q-D23）。

### FP-B21-SS-03 时长排行
- 维度 部门 / 个人，Top 10/20/50；时长来自学习日志，格式“X 小时 Y 分钟”。

### FP-B21-SS-04 逾期督办与导出
- 任务 / 部门筛选，逾期天数降序红色；〔去督办〕打开对应任务学习记录；〔导出 Excel〕异步导出（Q-D24）。

### FP-B21-SS-05 资料热度
- 学习人次 Top10（人次按人去重），点行打开资料详情。

### FP-B21-SS-06 每日汇总与低完成率推送
- 规则见 Q-D22；任务幂等，重跑同日覆盖当日行。
