# 功能测试用例 · 10 竞品分析（竞品作品 / 竞品账号 / 竞品库）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：日常运营 → 竞品分析 → 竞品作品（Tab 全部/爆款/低分）、竞品账号（Tab 全部/高粉/低粉）、竞品库（V3 COMP-003 审核入库）
- 依据：V1 COMP 规格（M7 监测）、V3 COMP-竞品管理规格（COMP-001 提交 / 002 审核 / 003 资产库，BR-201/202/203，错误码 1171～1177）；原型 compWork/compAccount/comp（compAdd/compAudit/compResubmit/compCompare）
- **v0.3 口径（C-26）**：按 V3 PRD COMP-001～003：提交模板（竞品对象、分析周期、**数据来源**、维度字段 销售/GMV/价格带/内容策略/投放策略、结论与可借鉴点）由 R5/R6 提交；**初审 R8 → 终审 R4** 两级审核，未通过退回补充；入库后进竞品资产库，支持对比。缺字段、单级审核、缺对比 → 不通过。
- 竞品作品/账号数据来自外部采集（TC-08 EXT-T1、KW-T1），无采集数据时取环境既有数据。

**本文件产出数据**：CP-T1（竞品 `TC竞品库A`，审核通过入库）、CP-T2（被驳回后重新提交）。
