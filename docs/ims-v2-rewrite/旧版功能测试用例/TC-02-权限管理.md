# 功能测试用例 · 02 权限管理（组织架构同步 / 岗位-角色供给规则 / 数据范围）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：系统与权限 → 权限管理：组织架构同步（AUTH-002）、岗位-角色供给规则（AUTH-003）；跨模块权限/数据范围总则（BR-305、ADR-IMS-008）
- 依据：完整 PRD §3A-01、§4.1～4.2.1（G1～G7、FR/AC-AUTH-019～022）、§6.1；V1 PRD ORG-R1～R4、§4.2 矩阵；原型 authOrg / authPosition；`产品规格/V1/AUTH-权限管理-页面规格.md` P2/P3；`SYS-系统管理-页面规格.md` P2A
- 执行方式：同 TC-00 铁律。账号 admin（R1）；多角色账号来自 TC-01 SYS-USR-03。
- 钉钉真实事件（入职/调岗/离职、岗位同步）依赖钉钉测试企业，相关用例标「可能阻塞」。
