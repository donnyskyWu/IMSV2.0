# 功能测试用例 · 09 内部分析（内部账号 / 内部作品）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：日常运营 → 内部分析 → 内部账号（Tab 全部/高粉/低粉）、内部作品（Tab 全部/爆款/低分）
- 依据：V1 INT 规格；原型 intAccount/intWork；BR-003（爆款 播放 ≥100w）、BR-004（低分 完播率 <20%）、ADR-069（低粉 = 绝对值 + 7 日连降）；阈值只读引用 数据采集 → 阈值规则
- 数据来源：内部账号/作品数据由采集任务产生（TC-08）。**若测试环境采集无法真实运行，列表数据取环境既有数据；无数据则相关断言记「阻塞」**，空态用例照常执行。

**前置数据**：TC-08 JOB-T1 已执行成功并产生 ACC-DY-1 的作品数据（或环境既有采集数据）；TH-T1 阈值规则（TC-08）。
