# 功能测试用例 · 04 IP 组（IPG-001～005）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：日常运营 → IP 组（左树右详情：基本信息 / 成员管理 / 账号绑定 / 关联作者 / 统计）
- 依据：完整 PRD §3A-19a、§5.2-4；原型 ipg（ipgEdit/ipgMemberAdd/ipgAnchorAdd/ipgAccountBind/ipgDelete）；`产品规格/V1/IPG-IP组运营-页面规格.md`；错误码 1203（大组不可绑账号）、1501、1002（同父组名唯一）
- 执行方式：同 TC-00 铁律；账号 admin；成员用户来自 TC-01。
- 作者数据说明：作者来自 Football `author_user`（只读，ADR-051），IMS 无新建作者入口（作者管理 P2 不在原型侧栏）→ 允许使用环境中已有作者；若作者下拉为空，AU 相关用例记「阻塞」。

**本文件产出数据**：IPG-B1 大组 `TC大组1`；IPG-S1 小组 `TC小组1`、IPG-S2 小组 `TC小组2`（均在 IPG-B1 下）；成员 U-R5（直播运营·主职）、U-R5B（直播运营·兼职）、U-R6（编辑·主职）入 IPG-S1；作者 AU-1、AU-2 关联到 IPG-S1；账号池 ACC-DY-1/2、ACC-KS-1 绑定 IPG-S1。
