# 功能测试用例 · 01 系统管理（含登录）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：登录页；系统与权限 → 系统管理：用户 / 角色 / 菜单 / 字典 / 参数 / 日志 / 通知 / 租户套餐（SYS-001～008）
- 依据：`doc/产品PRD/IMS完整产品需求文档.md` §3A-01、§4、§5.1；`IMS第一期PRD-V1.md` §4.1/§4.2、AUTH-R1～R4；原型 `IMS-完整系统-UI原型.html`（sysUser/sysRole/sysMenu/sysDict/sysParam/sysLog/sysNotify/sysTenant）、`pages/login.html`；`产品规格/V1/SYS-系统管理-页面规格.md`；`产品规格/错误码映射表-附录.md`
- 执行方式（铁律）：从侧栏菜单进入，点按钮、在输入框/选择器里填写；禁止输入 URL 跳路由、禁止调接口代替被测步骤。接口/数据库只用于执行后核对。
- 账号：`admin / Admin@123`（R1）。本文件**负责造出后续所有模块要用的角色和用户**（见 §三、§四），其它文件的多角色用例引用这里的编号。
- 截图：进入页面、关键操作后、最终结果各一张；与原型同位置截图对比。结果记：通过 / 不通过（附截图+现象）/ 阻塞（写原因）。

> 本模块产出的测试数据（全局命名前缀 `TC`，执行完可删）：
> - 角色：ROLE-R2～ROLE-R11、ROLE-R5-IPG、ROLE-DEPT（见 SYS-ROLE-03～05）
> - 用户：U-R2、U-R3、U-R4、U-R5、U-R5B、U-R6、U-R7、U-R8、U-R8B、U-R9、U-R10、U-R11、U-NOROLE（见 SYS-USR-03、SYS-USR-04）
