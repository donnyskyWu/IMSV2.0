# 功能测试用例 · 20 预警中心（预警规则 / 实时预警：实时预警·处置记录·去重合并）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：数据决策 → 预警中心 → 预警规则（alertRule）、实时预警（alertLive，页内 Tab：实时预警 / 处置记录 / 去重合并）
- 依据：V2 PRD ALERT-001～004、BR-112（响应率 ≥90%）、BR-113（三级升级 30/60 分钟）、BR-114（30 分钟去重）；`产品规格/V2/ALERT-预警中心-页面规格.md`（错误码 1165～1167、1009）；原型 alertRule（alertRuleAdd/alertRuleEdit）、alertLive（alertHandle/alertDedupView/alertDedupMerge/alertRecordDetail）
- **v0.3 口径（C-36）**：全部按 V2 PRD ALERT-001～004 判定：
  1. 级别：**提示 / 警告 / 严重**（level 1/2/3；规格 L1/L2/L3 对应），原型 红/橙/黄 仅可作颜色，不可替代级别名；
  2. 升级：一级（责任人）30 分钟未响应 → 二级（部门负责人）；再 60 分钟未响应 → 三级（运营总监 + 系统管理员）；严重级直接从二级起跳；升级链路时限 R1 可配；
  3. 去重：同规则 + 同对象 30 分钟窗口合并，计数累加，只推一条；
  4. 必须有升级中心（P3）与统计看板（P4：总量、级别分布、命中排行、响应率 BR-112、送达率 BR-111、平均响应时长、误报率、升级率）；
  5. 首批启用 5 条规则：资产(证件)到期、账号未归还、直播风险联动、采集异常、成本未录入（随 V3 财务启用）；规则不可物理删除，只能停用。
  缺失或不一致记不通过。
- 阈值配置统一在 数据采集 → 阈值规则（TC-08），本页只配级别与升级链。

**前置数据**：TC-03 CERT-B（证件 +5 天）、TC-05 LS-2 风控结果、TC-08 TH-T1、TC-16 FL-T2 超时流程、TC-06 低毛利场次；U-R4（处置人）、其主管。
