# 功能测试用例 · 18 数据指标（指标管理 / 指标分析）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：数据决策 → 数据指标 → 指标管理（bi0Metric）、指标分析（bi0Analysis）
- 依据：V1 BI0 规格 FR-M6-001；原型 bi0Metric（bi0MetricEdit、结果查询 non-goal 说明）、bi0Analysis（bi0AnalysisRun/Reset）
- 约定：「结果查询」（DW mt-result）本期 non-goal，点击只显示说明与「前往数据报表」。

**前置数据**：U-R9；采集/内容数据（TC-07/08）使指标有值。
**本文件产出数据**：MET-T1（基础指标 `TC_PLAY`）、MET-T2（复合指标 `TC_RATE`）。
