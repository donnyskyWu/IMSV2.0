# 功能测试用例 · 21 AI 资源中心（技能库 / 专家库 / 知识库 / 模型连接·提示词）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：AI 资源中心 一级菜单四叶：技能库（airSkill）、专家库（airExpert）、知识库（airKb）、模型连接 / 提示词（airCfg）
- 依据：完整 PRD AIR 范围说明（Key 管理、审计监控为 **Deferred**，不出侧栏，访问重定向到技能库；知识库**仅文件管理，不含检索**，v2.6.34）；V2 AIR 规格；原型 airSkill（skillAdd/skillAudit/skillGrant/airSkillDetail）、airExpert（expertDetail/expertGrant）、airKb（kbAdd/kbCatManage/kbUpload/kbTransfer/kbAudit/kbDetail）、airCfg（airModelEdit/airModelTest/airPromptEdit）
- AI 模型真实连通依赖外部（Football jingcai / OpenAI 兼容），「测试连接」标**可能阻塞**。

**前置数据**：U-R11（AI 资产管理员）、U-R4（审核人）、U-R6（被授权者）；TC-07 CT-T1 已发布内容（用于系统转入）；TC-14 MAT-T1（培训资料，系统转入来源）。
**本文件产出数据**：SKL-T1（技能 `TC卖点提炼`，审核通过并授权 U-R6）、SKL-T2（被驳回）、KB-T1（知识库 `TC知识库` 内部）、KB-T2（机密库，审批）、MOD-T1（模型连接）、PRM-T1（提示词）。
