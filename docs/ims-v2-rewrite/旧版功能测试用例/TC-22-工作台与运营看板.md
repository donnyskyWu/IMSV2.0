# 功能测试用例 · 22 工作台（运营看板 / 个人工作台 / 待办中心 / 消息中心）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：侧栏「工作台」分组：运营看板（home）、个人工作台（workbench，含隐藏页 待办中心 workbenchTodos、消息中心 workbenchMsgs）；页头消息铃铛
- 依据：V1 HOME 规格（篇幅小）、AUTH-004 工作台（WB-R1 逾期高亮置顶、WB-R2 钉钉推送去重 ≤3 次、WB-R3 外协仅指派任务）；BR-305 数据范围；原型 home（homeRefresh）、workbench、workbenchTodos（todoGo/todoClose）、workbenchMsgs（markAllRead/wbMsgQuery）
- 本文件建议**最后执行**：待办/消息的数据来自前面各模块的业务动作（领用审批、内容审核、日报审阅、培训任务、预警等）。

**前置数据**：TC-03 领用申请（审批待办）、TC-07 内容待审（U-R8 审核待办）、TC-12 日报待审阅、TC-14 学习任务、TC-20 预警、TC-16 催办。
