# 功能测试用例 · 06 财务（账号财务 COST + 场次财务 FIN：成本核算 / 利润反查）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：账号财务 → 账号成本与 ROI（Tab：成本登记 / 账号 ROI / Football 订单）；场次财务 → 成本核算（Tab：结算单 / 成本单据 / 分成规则）、利润反查（Tab：利润列表 / 聚合下钻 / 异常清单）
- 依据：完整 PRD BR-302（COST 与 FIN 分菜单、营收口径不同）；V3 PRD BR-107/108/109/118；原型 cost、finCost、finProfitTrace（costAdd/finAdd/finCalc/finCostAdd/finCostAudit/finRuleEdit/finRuleSave/finRuleAdd/finProfitTraceRow）；`V1/COST-账号财务-页面规格.md`；`V3/FIN-财务核算-页面规格.md`；错误码 1141～1150、1231～1240
- 说明（v0.3，C-23）：场次财务按 V3 PRD FIN-001～004 + FIN 规格 P1～P5 判定：按场次录入成本（GMV/退款从直播台账只读带出）、财务核准、三级利润自动计算与重算版本、分成规则引擎（基数/对象/阶梯/范围/优先级）与分成单双审、利润看板、48h 未录入督办、期间结账。原型的「发起结算（手填总收入+单一比例）」不符合 PRD，出现手填收入即不通过。缺 PRD 功能入口记不通过。
- 利润口径（BR-108 / FIN-002）：毛利 = GMV − 退款 − 平台佣金；经营利润 = 毛利 − 投放成本 − 冲话费摊销；净利润 = 经营利润 − 场次固定成本 − 达人分成 − 实名人分成；分成金额（BR-109）= 分成基数 × 比例，阶梯逐档求和。
- 本文件计算样例（LS-1，v0.3.1 佣金基数已裁定 = GMV − 退款）：GMV 50000、退款 2000（TC-05 LIVE-END-05 带出）、佣金率 5% → 佣金 = (50000 − 2000) × 5% = 2400；投放成本 5000（带出）、冲话费摊销 1000、固定成本 3000、达人分成按 SR-T1 = 毛利 × 10%、实名人分成按 SR-T2 = GMV × 2% = 1000 → 毛利 45600；经营利润 39600；达人分成 4560；净利润 31040；净利率 62.08%。

**前置数据**：ACC-DY-1 在用（TC-03）；LS-1 已下播录入并 R4 核准（TC-05 LIVE-END-08）。
**本文件产出数据**：COST-1（ACC-DY-1 采购成本）、CB-1/CB-2（成本单，CB-1 审核通过）、FI-1（LS-1 成本录入与利润结果）、SR-T1（达人·毛利 10%）、SR-T2（实名人·GMV 2%）、SR-T3（阶梯）、SH-1（LS-1 分成单）。
