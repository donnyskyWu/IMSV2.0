# 功能测试用例 · 14 培训管理（岗位资料库 / 学习任务 / 完成率统计）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：协同与成长 → 培训管理 → 培训资料库（岗位资料库）、学习任务（学习任务管理，含 AI 生成试卷、进入作答）、完成率统计（培训统计看板）
- 依据：V2 PRD TRAIN-001～004、BR-101（资料周更新率）、BR-102（完成率 >90%）；`产品规格/V2/TRAIN-培训管理-页面规格.md`（TRN-M-R1～R3、TRN-T-R2/R3、TRN-S-R1，错误码 1101～1105）；原型 trainMaterial/trainTask/trainStat（trainMatUpload/trainMatOffline/taskAdd/trainAiQuizOpen/taskRecords/quizDo/quizSubmit）
- **v0.3 口径（C-38）**：学员端按规格 P4「学习中心」判定（我的学习任务、资料学习、学时、自测作答、本人完成率）；必须有独立学员入口（菜单或页面），只能经工作台待办进入记不通过。岗位来自钉钉岗位字典（AUTH-003），无岗位时按人指派。
- AI 出卷依赖 AI 资源中心模型（TC-21），标**可能阻塞**。

**前置数据**：U-R2（行政，培训管理员）；学员 U-R6、U-R7；岗位字典至少 1 个岗位（TC-02 AUTH-POS）。
**本文件产出数据**：MAT-T1（已发布 DOC 资料）、MAT-T2（草稿）、LT-T1（学时达标任务，指派 U-R6）、LT-T2（QUIZ 任务，指派 U-R6/U-R7）、QZ-T1（AI 试卷）。
