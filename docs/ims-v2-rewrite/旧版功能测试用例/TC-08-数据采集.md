# 功能测试用例 · 08 数据采集（采集任务 / 采集日志 / 竞品账号配置 / 竞品关键字配置 / 元数据维护 / 阈值规则）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：数据采集 一级菜单下 6 个子页
- 依据：V1 COLLECT 规格（ADR-047/052：配置行禁止 Cookie，平台账号凭证仅在账号详情「采集 Tab」）、ACCT-平台账号采集Tab-OPS对齐；原型 collectTask/collectLog/collectExtAccount/collectExtKeyword/collectMetadata/collectThreshold；错误码 1241～1250、1261
- 说明：真实采集依赖平台 Cookie/Collector 与外网，执行结果类用例标注**可能阻塞**；页面配置类用例必须可执行。平台账号 Cookie/扫码/绑定 Collector 已在 TC-03 CA-DT（采集 Tab）覆盖。
- 采集平台（v0.3，C-25）：按完整 PRD 凭证铁律，内部采集平台 = 抖音 / 快手 / 视频号（WECHAT_CHANNELS）；企微/奥创为「内部例外」，不走采集任务。新增任务平台下拉出现「企业微信」或缺「视频号」→ 不通过。

**前置数据**：ACC-DY-1 已在采集 Tab 绑定凭证（TC-03 CA-DT-07 系列），U-R4/U-R6。
**本文件产出数据**：JOB-T1（单账号任务）、EXT-T1（竞品账号 `tc_comp_a`）、KW-T1（关键词 `TC跑鞋`）、META-T1（元数据实体）、TH-T1（阈值规则「TC爆款播放」）。
