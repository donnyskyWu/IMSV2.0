# 功能测试用例 · 13 数据上报（上报模板 / 填报单管理 / 完成率统计）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：协同与成长 → 数据上报 → 上报模板、填报单管理、完成率统计
- 依据：V2 PRD REPORT-001～004、BR-106；`产品规格/V2/REPORT-数据上报-页面规格.md`（FR-REPORT-011 作者+账号归因、RPT-T-R2/R3、RPT-A-R1/R2，错误码 1121～1127）；原型 reportTpl/reportSub/reportRate
- 说明：数据上报 ≠ 日报（日报见 TC-12）。**v0.3 口径（C-29）**：模板设计按 PRD REPORT-001 与规格三 Tab（字段定义含字段键/类型/校验、**勾稽规则**、填报人）判定；勾稽在配置时即时校验（1121）、提交时强制执行（RPT-T-R2）。原型「名称/频率/部门/初始字段数 + 字段列表」只作布局参考，缺勾稽或填报人配置记不通过。

**前置数据**：作者 AU-1 属于 IPG-S1，ACC-DY-1 绑定在 IPG-S1（TC-04 IPG-ACC/IPG-AU）；ACC-KS-1 未绑定 IPG-S1；U-R4 为审核人；U-R6 为填报人。
**本文件产出数据**：RT-T1（模板 `TC上报模板`）、UP-T1（填报单，审核通过）、UP-T2（被退回重报）。
