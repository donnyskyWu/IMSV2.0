# 功能测试用例 · 05 直播管理（场次中心 LIVE-001～004）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：日常运营 → 直播管理（Tab：场次列表 / 待录入督办 / 风险告警；场次详情 Tab：基本信息 / 直播数据 / 风控登记 / 下播与 GMV / 关联）
- 依据：完整 PRD §3A-10、§5.4、§6.4；V1 PRD BR-006/007/011/013/014、§4.2 LIVE 矩阵；原型 live（liveReg/liveRiskResult/liveSessionDetail/liveEndEntryForm/liveCorrectionDrawer/liveReportConfirm/liveToReview）；`产品规格/V1/LIVE-直播管理-页面规格.md`；错误码 1041～1049、1004、1005
- 执行方式：同 TC-00 铁律。Football `live_room` 为只读共用表，无数据时「直播数据」Tab 为空属正常（同步相关用例可能阻塞）。
- 状态口径（v0.3，C-19）：按 PRD `session_status` **待风控 / 已放行 / 直播中 / 已下播 / 已取消**判定；绿级自动「已放行」，黄级经 R4 审批后「已放行」，红级禁止开播。原型「待复核」（转人工复核）PRD 未定义，保留为附加状态。原型「待开播/已结束」名称出现即记不通过。

**前置数据**：ACC-DY-1（RN-A，证件有效）、ACC-DY-2（RN-B，证件 T−5 红）、ACC-DY-3（RN-C，证件已过期）均由 U-R5 领用至「在用」（按 TC-03 CA-FL-01～03 操作）；AS-LV-A、AS-SH-A（TC-03 CD-DEV-03）。
**本文件产出数据**：LS-1（ACC-DY-1，低风险，完整走到下播核准）、LS-2（ACC-DY-2，黄/红级）、LS-3（被取消场次）、LS-4（历史补录）。
