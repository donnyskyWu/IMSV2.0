# 功能测试用例 · 12 会议 / 日报中心（MEET-001～004）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：协同与成长 → 会议（会议管理：预约 + 纪要）；日报中心 → 我的日报、团队日报、待我审阅、提交率统计
- 依据：V2 PRD MEET-001～004、BR-103（按时提交率 >95%，默认截止 22:00）、BR-104（人月口径）；`产品规格/V2/MEET-会议日报管理-页面规格.md`（MEE-D-R1～R4、MEE-R-R1～R3、MEE-M-R1～R3，错误码 1111～1118）；原型 meet（meetAdd/meetDetail/meetMinGen/meetMinManual/meetMinEdit/meetMinArchive）、dailyMine/dailyTeam/dailyReview/dailyStat（reportWrite/reportApprove/reportReject/reportRvwBatch）
- **v0.3 口径（C-27、C-28）**：会议按 PRD MEET-004 判定：会议登记（主题/时间/参会人）→ 纪要录入（决议事项、行动项=描述+责任人+期限）→ 行动项待办与完成回填（1118）→ 归档；状态 会议已登记 / 纪要已录 / 已归档；会后 24h 录纪要、48h 归档（BR-116 留痕率）；行动项逾期 1 天提醒责任人、3 天升级行政。原型的会议室预约 PRD 未定义，保留为附加功能。日报审阅按 PRD MEET-002：直属上级（一级）→ 部门负责人（二级）逐级；动作 **已读 / 点评 / 标记跟进**（跟进项转待办）；一级 24h 时限。原型「通过/退回」PRD 未定义，存在不判不通过，但缺 PRD 动作记不通过。
- AI 听记（钉钉）依赖外部，标**可能阻塞**。

**前置数据**：U-R6、U-R5 的直属主管 = U-R4（来自组织架构同步或系统管理→用户部门设置；无法构造则审阅类用例阻塞）；U-R2（行政）。
**本文件产出数据**：MT-T1（会议，手动纪要并归档）、MT-T2（AI 纪要）、DR-T1（U-R6 今日日报，审阅通过）、DR-T2（U-R5 日报，被退回）。
