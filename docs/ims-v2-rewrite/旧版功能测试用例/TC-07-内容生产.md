# 功能测试用例 · 07 内容生产（SOP / 计划 / 工作任务登记 / 我的任务 / 任务执行 / 内容管理 / 公推模板库 / 内容审核）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：内容生产 一级菜单下 SOP 管理、计划管理、工作任务登记（Tab：任务登记 / 任务执行情况 / 任务管理）、我的任务、任务执行（隐藏页，从我的任务进入）、内容管理、公推模板库、内容审核（一级 / 二级）
- 依据：完整 PRD §5.5（内容生产独立一级菜单、主路径 工作任务登记→确认出任务→我的任务执行→提交审核→内容审核→完成，ADR-079 完成门禁）；V1 CONTENT / CONTENT-OPS 并入补充规格；参数 content.review.levels=2；原型 contentSop/contentPlan/contentWork/contentTask/contentTaskExecute/contentList/contentLayout/contentReview；错误码 1051～1058、1007
- 约定：v2.6.33 起 SOP 模板**无需审核**（完整 PRD v2.6.33 变更，原 SOP 审核菜单已移除，PRD 与原型一致，C-24）。Football 赛程（MatchSelect）、AI 生成、Football 同步/下架依赖外部接口，相关步骤**可能阻塞**。

**前置数据**：IPG-S1（TC-04），U-R6 为 IPG-S1 成员；作者 AU-1（TC-04）；ACC-DY-1 已授权可作发布账号（TC-03）；U-R4（运营总监）、U-R8/U-R8B（内容审核员，两人）。
**本文件产出数据**：SOP-T1、PLAN-T1、WT-T1（工作任务行）、TK-T1（生成任务）、CT-T1（内容，审核通过）、CT-T2（被驳回内容）、LY-T1（版式模板）。
