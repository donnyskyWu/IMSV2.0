# 功能测试用例 · 23 跨模块业务主线（E2E，纯页面操作）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 目的：把各模块用例串成真实业务链，验证「前一模块产出的数据，在后一模块页面上能看到、能用、数字一致」。
- 执行方式：每条主线由一个人按步骤从侧栏菜单逐页操作完成，步骤中引用的用例编号表示「按该用例的操作完成这一步」；每一步都要截图。**任何一步失败，后续步骤标「阻塞」并记录卡点。**
- 依据：完整 PRD §5（模块边界与联动）、业务用户故事 A～F/QT、各模块规格；具体断言来自引用用例。
- 主线数量：**12 条**（ML-01～ML-12）。
