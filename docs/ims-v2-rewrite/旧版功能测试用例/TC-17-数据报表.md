# 功能测试用例 · 17 数据报表（报表管理 / 报表设计器 / 发布与分享 / 订阅 / 报表中心）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：数据决策 → 数据报表 → 报表管理（biList，含隐藏页 报表设计器 biDesign、订阅与分享 biShare）、报表中心（bi0Report，M6 八张标准报表）
- 依据：完整 PRD 数据决策四个 L2 结构；V3 PRD BI-001～003（BIR-R1～R4、BIS-R1/R3、BR-204/211/212，错误码 1191～1197）；V1 BI0 规格（M6 标准报表）；原型 biList（biAdd/biImportJson/biCatDlg/biOpenDesigner/biOpenPublish/biRowMore）、biDesign、biShare（biSubscribe/biSubEdit/biSubToggle/biSnapshotDlg）、bi0Report（bi0OpenReport）
- **冲突/约定**：报表设计器为隐藏路由，只能从 报表管理「新建报表 / 编辑」进入；订阅与分享按 V3 PRD BI-003 必须可达（订阅 日/周/月、钉钉+工作台推送附快照、快照留档、带权限校验的分享链接、含成本/利润分享须 R4 审批、有效期默认 7 天最长 30 天、推送失败补发 1 次）；入口位置 PRD 未规定，可在报表「更多 ▾」或独立页，**任何页面都找不到 = 不通过**（C-34）。

**前置数据**：U-R9（数据分析师）、U-R4（审批敏感发布）、U-R6（被授权查看者）；LS-1/FI-1 等业务数据使报表有值（TC-05/06）。
**本文件产出数据**：CAT-T1（分类 `TC分类`）、BR-T1（报表 `TC运营日报`，已发布）、BR-T2（含成本字段报表，敏感发布待审批）、SUB-T1（订阅）。
