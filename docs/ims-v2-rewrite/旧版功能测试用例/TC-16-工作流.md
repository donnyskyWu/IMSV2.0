# 功能测试用例 · 16 工作流（流程列表 / 看板视图 / 模板管理）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：协同与成长 → 工作流（流程管理：类型 Tab 全部/请假/领用/报销/开播审批/内容审核；视图 看板视图、模板管理）
- 依据：V2 PRD FLOW-001～003；`产品规格/V2/FLOW-工作流管理-页面规格.md`（FLO-T-R1/R3、FLO-I-R1，错误码 1131～1140）；原型 flow（flowAdd/flowUrgeBatch/urge/flowTplTab/flowTplDesign/flowNodeConfig/flowNodeAdd/flowNodeReorder/flowDiff/flowTplRollback/flowTplNew/flowKanbanTab/flowKbNext）
- **v0.3 口径（C-33）**：实例处理按 PRD FLOW-002：任务处理 **通过 / 退回（驳回）/ 转交（一次一跳，留痕）**，发起人可**撤销**进行中实例，实例状态 进行中/已完成/已撤销/异常；入口缺失记不通过。原型看板「流转/完成」、催办保留。超时规则：超 24h 未流转自动升级提醒至上级（原型横幅）。

**前置数据**：U-R4（审批人/主管）、U-R6（发起人）、U-R3（财务复核）。
**本文件产出数据**：FT-T1（模板 `TC请假流`）、FL-T1（U-R6 发起的请假流程，走完归档）、FL-T2（报销流程，用于催办/超时）。
