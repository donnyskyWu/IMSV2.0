# 功能测试用例 · 15 绩效考核（考核方案 / 执行考核 / 考核结果 / 在线考试）（v0.3.1 待审核 · PRD 口径）

> **v0.3.1 判定口径（zhang wu 2026-10-11 裁定）**：功能、字段、流程、业务规则、权限以 PRD（含产品规格，产品规格视同 PRD）为准；PRD 已定义而实现缺失或不一致记「不通过」（不是「阻塞」）。原型只约束 PRD 未规定的纯布局/视觉细节。「阻塞」仅用于外部依赖不可用或前置数据无法产生。

- 被测范围：协同与成长 → 绩效考核 → 考核方案、执行考核、考核结果、在线考试（Tab 题库管理 / 试卷管理 / 成绩管理）
- 依据：V2 PRD PERF-001～004、BR-117（综合得分排名，<60 预警）、BR-031（同周期同员工不可重复）；`产品规格/V2/PERF-绩效考核-页面规格.md`、`PERF-绩效考试-页面规格.md`（PER-C-R3/R4、PER-E-R2，错误码 1151～1164）；原型 perfScheme/perfExec/perfResult/perfExam（perfAdd/perfLaunchCycle/perfExecCreate/perfExecCalculate/perfExecScore/perfExecConfirm/perfPIP/examPaperAdd/examAssign/examTake/examGrade）
- **v0.3 口径（C-31、C-32）**：按 PRD PERF-001 + 规格 P1 必须有独立「指标配置」页（指标编码/名称/取数来源 系统自动·手工·考试成绩/取数映射/得分规则/权重/状态；岗位指标集权重合计 = 100，1151～1154；竞品分析提交率 BR-110 默认禁用；自动取数覆盖率 >80% BR-105）；员工可查看本人已发布结果（PERF-002/004 R5/R6/R7=R 本人）；题库可新增题目（PERF-003）。缺失记不通过。评级阈值 PRD 未规定 → **保留原型**：S ≥95、A ≥85、B ≥75、C ≥60、D <60（<60 预警为 BR-117 硬规则）。

**前置数据**：U-R4（考核人）、被考核人 U-R6、U-R7；U-R2（试卷管理员）；TC-14 已产生培训/考试成绩可作为指标来源（可选）。
**本文件产出数据**：PS-T1（方案 `TC考核方案`）、PR-T1（U-R6 本周期考核，确认）、PE-T1（试卷）、ER-T1（U-R6 成绩）。
